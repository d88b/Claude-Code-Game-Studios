## 定价依据

### 市场分析

| 参考游戏 | 价格 | 相似度 |
|----------|------|--------|
| **亿万僵尸** | $29.99 | 塔防机制相似 |
| **泰拉瑞亚** | $9.99 | 建造挖掘相似，但更成熟 |
| **重装机兵系列** | ¥50-100 (移动版) | 战车改装相似 |
| **RimWorld** | $34.99 | 复杂度参考（本项目更简单） |

**定价区间**: $9.99 - $29.99
**建议定价**: $14.99 (中端定价，避免过低低估价值)

### 定价因素

| 因素 | 影响 |
|------|------|
| **游戏规模** | 中型 (6周开发，首款) → 支持中端定价 |
| **目标受众** | Hardcore survival玩家 → 接受付费购买 |
| **美术风格** | Pixel art 2D → 价格敏感度低 |
| **平台** | Steam/Epic → Premium model 标准 |
| **首发状态** | Early development build → 可能考虑折扣 |

## 价格更新策略

### 价格上涨条件

| 条件 | 说明 |
|------|------|
| **重大更新** | 新增大 DLC 或功能扩展 |
| **评价积累** | 正面评价超过 100 条 |
| **功能完善** | 从 Early Access 到 Full Release |

**建议**: 发售 6 个月后，如游戏功能完善可考虑涨价至 $19.99

### 价格下降条件

| 条件 | 说明 |
|------|------|
| **销量不佳** | 长期销量低于预期 |
| **负面评价** | 评价过多影响购买意愿 |
| **竞品降价** | 市场竞争压力 |
