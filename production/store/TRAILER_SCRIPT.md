## Trailer 结构

### Phase 1: Hook (0:00-0:10)

**画面**: 战车引擎启动，驶出地堡大门
**镜头**: 从地堡内部视角，战车冲入地表阳光
**音频**: 引擎启动音效 → 渐强背景音乐
**文字**: 无 (纯视觉冲击)

```
镜头: 战车静止在地堡出口
动作: 引擎轰鸣，车轮转动
镜头: 战车冲出地堡，进入地表废土
效果: 阳光照射，尘土飞扬
时长: 10秒
```

---

### Phase 2: Exploration (0:10-0:25)

**画面**: 战车探索地表，收集资源
**镜头**: 侧面跟随镜头，战车穿越废墟
**音频**: 背景音乐节奏加快
**文字**: "EXPLORE THE WASTELAND"

```
镜头: 战车侧面跟随
动作: 战车行驶、转向
画面: 资源掉落出现
动作: 战车经过拾取资源
文字叠加: EXPLORE THE WASTELAND (中英双语)
时长: 15秒
```

---

### Phase 3: Combat (0:25-0:40)

**画面**: 战车射击僵尸敌人
**镜头**: 战车炮塔瞄准 → 开火 → 僵尸消灭
**音频**: 战斗音乐高潮
**文字**: "MAGITECH BATTLE WAGON"

```
镜头: 僵尸群出现
镜头: 战车炮塔转向瞄准
动作: 开火，子弹轨迹
效果: 僵尸被消灭，粒子爆炸
文字叠加: MAGITECH BATTLE WAGON
时长: 15秒
```

---

### Phase 4: Building (0:40-0:50)

**画面**: 挖掘方块，放置炮塔设施
**镜头**: 快速剪辑：挖掘 → 放置 → 设施激活
**音频**: 建造音效叠加
**文字**: "BUILD YOUR FORTRESS"

```
镜头: 地堡内部
动作: 挖掘方块动画 (加速剪辑)
动作: 放置炮塔设施
效果: 设施发光激活
文字叠加: BUILD YOUR FORTRESS
时长: 10秒
```

---

### Phase 5: Defense (0:50-0:65)

**画面**: 尸潮波次攻击地堡防线
**镜头**: 俯视镜头，僵尸群涌入，炮塔自动射击
**音频**: 防守音乐紧张高潮
**文字**: "DEFEND AGAINST TIDES"

```
镜头: 地堡俯视全景
画面: 夜幕降临，红色危险色调
画面: 僵尸群从边缘涌入
动作: 炮塔自动开火，爆炸效果
效果: 尸潮冲击防线
文字叠加: DEFEND AGAINST TIDES
时长: 15秒
```

---

### Phase 6: Day/Night (0:65-0:75)

**画面**: 日夜循环快速对比
**镜头**: 同一位置白天 → 黄昏 → 夜晚
**音频**: 音乐节奏变化
**文字**: "DAY/NIGHT CYCLE"

```
镜头: 固定位置
画面: 白天 (明亮色调) → 快速过渡 → 黄昏 (橙色调) → 夜晚 (暗色调)
效果: 天空颜色变化，光线变化
文字叠加: DAY/NIGHT CYCLE
时长: 10秒
```

---

### Phase 7: Title & Call-to-Action (0:75-0:90)

**画面**: 游戏标题 + Steam/Epic 预购链接
**镜头**: 黑色背景，标题动画出现
**音频**: 音乐结束，Logo 音效
**文字**: 游戏标题 + 发售信息

```
画面: 黑色背景
动画: 游戏标题 "RUST MAGIC TIDE / 铁锈魔潮" 飞入
文字: "COMING TO STEAM & EPIC"
文字: 发售日期/预购信息
Logo: Steam Logo + Epic Games Logo
时长: 15秒
```
