## Key Art 设计构思

### 核心元素

| 元素 | 位置 | 重要性 |
|------|------|--------|
| **战车** | 前景中央 | 核心主体 |
| **僵尸群** | 背景边缘 | 氛围元素 |
| **废土地形** | 背景 | 环境设定 |
| **魔导光芒** | 战车周围 | 特色表现 |
| **游戏标题** | 上部/下部 | 必需元素 |

### 颜色方案

| 色调 | 用途 |
|------|------|
| **主色调** | 暗棕色/锈红色 — 废土氛围 |
| **强调色** | 魔导蓝色 — 战车/魔能 |
| **对比色** | 僵尸暗红色 — 危险提示 |
| **背景色** | 灰褐色 — 地表废土 |

## Key Art 版本

### 版本 A: 战车探索

```
场景: 战车驶入地表废土
主体: 战车侧面视角，炮塔瞄准
背景: 废墟建筑、僵尸远处游荡
色调: 白天明亮，魔导蓝色光芒
标题: 上部居中，中英双语
```

### 版本 B: 尸潮防守

```
场景: 地堡入口防线
主体: 战车面向僵尸群
背景: 僵尸波次涌入，炮塔开火
色调: 夜晚暗色，红色危险感
标题: 下部居中，中英双语
```

### 版本 C: 双面对比

```
场景: 左右分割
左侧: 战车探索（白天）
右侧: 尸潮防守（夜晚）
中间: 战车跨越分割线
标题: 顶部居中
```

**建议版本**: 版本 A — 清晰展示核心玩法（战车探索）

## 文字叠加规范

### 标题位置

| 版本 | 标题位置 | 字体建议 |
|------|----------|----------|
| **Main Capsule** | 上部20%区域 | Bold, 48-60pt |
| **Small Capsule** | 上部或底部 | Bold, 20-24pt |
| **Header Capsule** | 下部或居中 | Bold, 36-48pt |

### 标题内容

| 语言 | 文字 |
|------|------|
| **英文** | RUST MAGIC TIDE |
| **中文** | 铁锈魔潮 |

**双语显示建议**:
- 英文为主，中文为辅
- 中文可在英文下方小字显示
- 或左右分布显示
