## 截图拍摄指南

### 拍摄时机

| 场景 | 最佳时机 | 原因 |
|------|----------|------|
| **战车探索** | 白天、开阔区域 | 视野清晰、光线充足 |
| **挖掘建造** | 放置设施动画播放时 | 动态反馈、交互感 |
| **尸潮防守** | 第一波僵尸接近防线 | 紧张感、敌群视觉 |
| **战车改装** | 改装确认界面 | 清晰展示选项 |
| **日夜对比** | 黄昏过渡时刻 | 颜色变化明显 |

### 拍摄技巧

- **清除 HUD**: 截图前可隐藏不必要的 UI 元素（如果功能允许）
- **避免遮挡**: 确保关键内容不被 UI 遮挡
- **动态捕捉**: 拍摄动画/粒子效果时等待最佳帧
- **对比展示**: 同一场景白天 vs 夜晚拍摄
- **清晰文字**: 确保 UI 文字清晰可读

### 避免的内容

- **空场景**: 没有交互的空地图
- **调试信息**: 开发者工具、调试输出
- **占位符**: 未完成的 placeholder 素材
- **错误状态**: bug 或异常画面
- **过暗/过亮**: 曝光不当影响观感

---

## 截图后期处理

### 允许的处理

- 轻微亮度/对比度调整
- HUD 文字清晰化
- 锐化处理提升清晰度

### 禁止的处理

- 添加不存在的功能
- 修改游戏外观误导玩家
- 过度滤镜失真真实效果
- 添加虚假内容
