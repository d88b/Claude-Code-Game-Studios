## 设计构思

### 版本 A: 战车探索 (推荐)

```
主题: 战车驶入地表废土

布局:
- 前景: 战车侧面视角，炮塔瞄准前方
- 中景: 废墟建筑、荒漠地形
- 背景: 天空、远景僵尸游荡
- 标题: 上部居中 "RUST MAGIC TIDE / 铁锈魔潮"

色调:
- 主色: 锈红/暗棕色 (废土氛围)
- 强调色: 魔导蓝 (战车光芒)
- 背景: 灰褐色渐变

元素:
- 战车: 像素风格，64x48 基础，放大展示
- 僵尸: 远景小尺寸，增加危险感
- 魔导光芒: 战车周围蓝光效果
```

### 版本 B: 尸潮防守

```
主题: 地堡防线防守

布局:
- 前景: 战车面向僵尸群
- 中景: 炮塔设施、障碍物
- 背景: 夜晚暗色，僵尸波次涌入

色调:
- 主色: 深蓝/暗紫 (夜晚)
- 强调色: 红色/橙色 (危险、火焰)
```

## 核心元素规格

### 战车设计

| 元素 | 规格 |
|------|------|
| 主体 | 灰色金属质感，方形车身 |
| 炮塔 | 圆形炮塔，魔导蓝光 |
| 轮子 | 两个圆形轮子 |

### 僵尸设计

| 类型 | 规格 |
|------|------|
| Basic | 红色调，人形轮廓 |
| Fast | 浅红色，更瘦小 |
| Tank | 深红色，更大 |

### 废土背景

| 元素 | 规格 |
|------|------|
| 地面 | 砂土纹理，裂纹 |
| 建筑 | 破损废墟，方块结构 |
| 天空 | 渐变，有太阳/月亮 |

## 标题设计

### 英文标题

```
RUST MAGIC TIDE

Font: Bold Sans-serif (Impact/Bebas Neue)
Size: Main Capsule ~48pt, Small Capsule ~20pt
Color: White with black shadow
Position: Top center, 20% from top
```

### 中文标题

```
铁锈魔潮

Font: 黑体/粗体
Size: 英文标题下方，稍小
Color: 同英文
```

### 双语排列

```
        RUST MAGIC TIDE
            铁锈魔潮

或左右分布:

    RUST MAGIC TIDE    铁锈魔潮
```

## 尺寸适配

### Main Capsule (616x353)

```
比例: 16:9 横幅
布局: 战车居中偏左，标题居中偏上
僵尸群在右侧边缘
```

### Small Capsule (200x112)

```
比例: 缩放 Main Capsule
注意: 标题必须仍然可读
可能需要简化背景细节
```

### Header Capsule (460x215)

```
比例: 宽幅横幅
布局: 可裁剪 Main Capsule 或重新设计
标题可放在底部
```

### Epic Main (1920x1080)

```
比例: 全高清 16:9
布局: 扩展 Main Capsule 设计
更多背景细节
战车可更大展示
```

### Epic Small (256x256)

```
比例: 方形
布局: 战车居中，标题简化或仅英文
去除多余背景元素
```

## 设计流程

### Step 1: 草稿

- 确定构图布局
- 勾勒主要元素位置
- 确定标题位置

### Step 2: 战车绘制

- 参考 placeholder: `assets/sprites/vehicle/vehicle_body.svg`
- 像素风格，灰金属色
- 添加魔导蓝光效果

### Step 3: 背景

- 绘制废土地面
- 添加破损建筑
- 天空渐变

### Step 4: 僵尸群

- 远景小尺寸僵尸
- 红色调，危险感

### Step 5: 标题叠加

- 添加中英双语标题
- 检查清晰度

### Step 6: 多尺寸导出

- 导出 5 个不同尺寸
- 检查每个尺寸清晰度

## 输出检查清单

| 检查项 | 要求 |
|--------|------|
| 分辨率正确 | 5 个尺寸全部匹配 |
| 标题可读 | 所有尺寸标题清晰 |
| 战车可见 | 核心元素突出 |
| 颜色协调 | 符合废土风格 |
| 文件格式 | PNG |
| 文件大小 | ≤ 2MB (capsules), ≤ 5MB (epic) |
