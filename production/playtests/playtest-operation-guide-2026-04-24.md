# Playtest 操作指南 — Vertical Slice MVP

**测试目标**: 验证核心循环是否可玩且体验良好
**测试时间**: 约 5-10 分钟
**测试环境**: Godot 4.6 Editor

---

## 测试前准备

### 1. 启动游戏

1. 打开 Godot 4.6 Editor
2. 在项目列表中选择 "Claude-Code-Game-Studios"
3. 等待项目加载完成
4. 按 **F5** 或点击右上角 ▶️ 播放按钮
5. 等待游戏启动（约 2-3 秒）

**预期结果**: 游戏窗口打开，显示 HUD 界面

---

### 测试 1.3: WASD 移动 (1:00-2:00)

**操作步骤**:
1. 按 **W** 键向上移动 2-3 秒
2. 按 **S** 键向下移动 2-3 秒
3. 按 **A** 键向左移动 2-3 秒
4. 按 **D** 键向右移动 2-3 秒
5. 同时按 W+D 测试斜向移动

**检查清单**:
| 检查项 | PASS 条件 | FAIL 条件 |
|--------|-----------|-----------|
| W 向上移动 | 车辆向上移动 | 按键无响应 |
| S 向下移动 | 车辆向下移动 | 按键无响应 |
| A 向左移动 | 车辆向左移动 | 按键无响应 |
| D 向右移动 | 车辆向右移动 | 按键无响应 |
| 移动方向正确 | 方向与按键一致 | 方向相反或错位 |
| 加速流畅 | 车辆平滑加速而非瞬间全速 | 移动卡顿或瞬间启动 |
| 最大速度合理 | 速度有上限，不会无限加速 | 速度过快或过慢 |

**主观感受记录**:
- 移动是否流畅自然？ ______________
- 加速是否感觉舒适？ ______________

|--------|-----------|-----------|
| MP 消耗 | 移动时 MP 条下降 | MP 不变化 |
| 消耗速度合理 | 约 2-5 秒消耗 10% | 消耗过快或过慢 |
| 警告提示 | MP < 10% 时出现红色警告 | 无警告提示 |
| 速度下降 | MP 低时车辆速度明显变慢 | 速度不变 |

**主观感受记录**:
- 魔能消耗是否创造了紧张感？ ______________
- 警告提示是否清晰？ ______________
- 低魔能时减速是否合理？ ______________
