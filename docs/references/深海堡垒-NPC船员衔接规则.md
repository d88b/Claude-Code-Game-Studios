## 一、核心衔接原则

### 1.1 NPC与船员的关系定义

| 概念 | 说明 |
|------|------|
| **普通船员** | 抽象数量，无个体特征，仅贡献效率数值 |
| **NPC船员** | 有个体身份的招募NPC，除数量贡献外还提供特殊加成 |
| **衔接原则** | NPC招募后 **同时计入船员总数**，并 **额外叠加特殊加成** |

### 1.2 数量规则

```
船员总数 = 基础船员数 + 招募NPC数

其中：
- 基础船员数：港口招募/救援获得的普通船员（抽象数量）
- 招募NPC数：每个成功招募的NPC = 船员总数 +1
- 上限：受居住舱等级限制（Lv1=10, Lv2=15, Lv3=20, Lv4=25, Lv5=30）
```

### 1.3 NPC船员与普通船员的区别

| 对比项 | 普通船员 | NPC船员 |
|--------|---------|---------|
| **数量贡献** | +1（抽象数值） | +1（具体个体） |
| **效率加成** | 基础效率（100%） | 基础效率 + 特殊加成（额外10%-50%） |
| **特殊技能** | 无 | 每种NPC有独特船上技能 |
| **死亡处理** | 随机死亡（数量减少） | 有死亡保护机制，需剧情触发 |
| **可打捞** | MVP不做打捞 | 可打捞（剧情重要性） |
| **士气影响** | 无 | 影响其他船员士气（+5~+15） |
| **结局影响** | 无 | 直接关联6种结局走向 |

## 三、NPC招募完整流程

### 3.1 招募流程图

```

│                    NPC招募完整流程                            │
└─────────────────────────────────────────────────────────────┘

       │
       ├── 好感度达标？ ──否──▶ [提升好感度]
       │     │                    ├── 完成NPC任务 (+5~15)
       │     │                    ├── 赠送礼物 (+3~10/次)
       │     │                    ├── 频繁交易 (+1~3/次)
       │     │                    └── 选择正确对话 (+2~5)
       │     │
       │    是
       │     │
       ├── 任务/物品要求满足？ ──否──▶ [完成前置任务]
       │     │                          ├── 收集指定物品
       │     │                          ├── 完成指定任务
       │     │                          └── 达成特定条件
       │     │
       │    是
       │     │
       ├── 舱位可用？ ──否──▶ [升级/建造对应舱位]
       │     │                   └── 消耗建材+金币升级居住舱
       │     │
       │    是
       │     │
       ▼
  [阶段2：招募对话]
       │
       ├── 触发特殊对话（好感度≥招募阈值时出现招募选项）
       │     ├── NPC表达意愿（根据好感度不同反应）
       │     │     ├── 好感度70-80：谨慎同意
       │     │     └── 好感度81-100：欣然同意
       │     └── 玩家选择：招募 / 暂不招募
       │
       └── 选择招募 ──▶ 进入阶段3
       │
       选择暂不 ──▶ NPC返回原位置，好感度不变
                    可后续再次触发
       │
       ▼
  [阶段3：登船仪式]
       │
       ├── 播放简短过场动画
       │     ├── NPC从当前位置移动到玩家船只
       │     ├── NPC登船动画（根据NPC类型不同）
       │     └── NPC在船上指定位置就位
       │
       ├── 系统提示：「[NPC名称] 已加入你的船员队伍！」
       │
       ├── 船员总数 +1
       │
       └── 解锁NPC船上功能 ──▶ 进入阶段4
       │
       ▼
  [阶段4：船上运营]
       │
       ├── NPC提供特殊功能加成（见第四节）
       ├── NPC可参与船内事件对话
       ├── NPC可触发羁绊事件（好感度继续提升时）
       └── NPC影响最终结局走向
```

```
5. 完成海伯的交易任务3 → +10 → 79 ✅
```

## 五、NPC船员死亡/受伤处理

### 5.1 与普通船员的区别

| 对比项 | 普通船员 | NPC船员 |
|--------|---------|---------|
| **死亡概率** | 按公式随机计算 | 死亡概率 × 30%（大幅降低） |
| **可打捞** | MVP不可打捞 | 可打捞（打捞成功率+50%） |
| **剧情保护** | 无 | 关键NPC（信号源）免疫死亡 |
| **死亡影响** | 数量减少，效率降低 | 数量减少 + 特殊加成消失 + 结局影响 |
| **复活可能** | 不可复活 | 部分NPC可通过特殊任务复活 |

### 5.2 NPC死亡处理规则

```
NPC船员死亡处理：

1. 死亡判定：
   - NPC死亡概率 = 普通船员死亡概率 × 0.3
   - 例：深水区潜艇被击毁，普通船员50%死亡概率
         NPC船员 = 50% × 0.3 = 15%

2. 死亡后果：
   - 船员总数 -1
   - 该NPC特殊加成消失
   - 船员士气 -10（持续3游戏天）
   - 结局关联NPC死亡 → 对应结局无法达成

3. 打捞机制（NPC专属）：
   - NPC死亡后可尝试打捞
   - 打捞成功率 = 基础50% + 深海贝壳加成
   - 打捞成功 → NPC回到船上（虚弱状态，效率50%，持续1游戏天）
   - 打捞失败 → NPC永久死亡

4. 复活机制（部分NPC）：
   - 信号源（N08）：完全免疫死亡（剧情关键）
   - 铁锚（N03）：可通过避难所救援任务复活
   - 红帆（N05）：可通过海盗阵营任务复活
```

### 5.3 NPC船员受伤处理

```
NPC船员受伤处理：

1. 受伤判定：
   - NPC受伤概率 = 普通船员受伤概率 × 0.5
   - 铁锚在场 → 全员受伤概率额外-10%

2. 受伤后果：
   - NPC暂时无法提供特殊加成
   - 船员总数不变（仍计入）
   - 效率加成暂时失效

3. 恢复方式：
   - 自然恢复：10-15分钟（比普通船员长）
   - 医疗室加速：5-8分钟（贝壳在场可进一步缩短至3-5分钟）
   - 赠送医疗类礼物：立即恢复（每日限1次）
```

## 八、常见问题 FAQ

### Q1: NPC招募后船员数量怎么算？
**A**: 每个成功招募的NPC = 船员总数 +1。例如原本有10个普通船员，招募海伯后船员总数变为11。

### Q2: NPC船员会占用普通船员的位置吗？
**A**: 是的。NPC和普通船员共享同一个船员容量上限。如果居住舱Lv1（上限10），已有10个普通船员，则需先升级居住舱才能招募NPC。

### Q3: NPC船员死亡后可以复活吗？
**A**: 部分可以。信号源（N08）免疫死亡；铁锚（N03）可通过避难所救援任务复活；红帆（N05）可通过海盗阵营任务复活。其余NPC死亡后可打捞，打捞失败则永久死亡。

### Q4: NPC船员的效率加成和普通船员怎么叠加？
**A**: NPC先贡献 `+1` 数量（影响基础效率公式），再额外叠加各自的特殊加成百分比。两者是独立计算后叠加的。

### Q5: 好感度降低会影响已招募的NPC船员吗？
**A**: 会影响特殊加成强度。好感度降至60以下时，NPC的部分高级特殊技能会暂时失效，但船员数量贡献不变。
