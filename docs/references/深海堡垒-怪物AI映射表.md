**登船AI行为逻辑**：
1. **接近**：从水面接近船体，寻找防守薄弱区域
2. **登船**：选择防守薄弱区域登船
3. **入侵**：进入船内部，寻找关键设施
4. **破坏**：优先级：动力室 → 弹药库 → 指挥室 → 仓库 → 玩家
5. **撤退**：血量 < 20% 或目标无法达成时撤退
