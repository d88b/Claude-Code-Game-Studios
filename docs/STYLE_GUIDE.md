## 一、整体视觉风格

### 1.1 色调基调
- **主色调**：暗灰、铁锈色、深绿色（军事/废土感）
- **辅助色**：血红、警告橙、荧光绿（生化/感染感）
- **强调色**：金色金属光泽、蓝色能量特效（科技元素）
- **避免**：过于明亮的卡通色彩、彩虹色系

### 1.2 氛围特征
- 末日废土感：破旧、锈蚀、战损痕迹
- 生化危机感：感染标记、血迹、绿色生化烟雾
- 蒸汽朋克元素：齿轮、管道、机械结构（参考亿万僵尸）
- 高对比度：确保在暗背景下单位可辨识

### 1.3 光照风格
- 环境光：偏暗，模拟夜间/地下场景
- 单位光：自发光元素（能量武器、感染特效）
- 强调光源：火焰、爆炸、能量特效需高亮

## 二、技术规范

### 2.1 基础参数
| 属性 | 规范值 | 说明 |
|------|--------|------|
| 网格尺寸 | 32x32 px | 建筑底座标准 |
| 单位尺寸 | 16-32 px | 敌人/玩家大小 |
| 文件格式 | PNG (RGBA) | 必须透明背景 |
| 色彩模式 | RGBA | 禁止P模式/索引色 |
| 最大画布 | 64x64 px | 单个单位上限 |

### 2.2 像素密度
- 建筑底座：精确32x32对齐网格
- 建筑高处：可超出32px高度，但底座需对齐
- 小型单位：16x16 或 24x24
- 大型敌人：32x32 或 48x48

### 2.3 动画规范
| 类型 | 最少帧数 | 方向要求 |
|------|----------|----------|
| 敌人行走 | 4帧 | 单向+镜像 或 4方向 |
| 敌人死亡 | 3帧 | 单方向即可 |
| 塔楼攻击 | 2帧 | 单方向 |
| 特效（火/烟） | 4帧 | 无方向 |

## 三、分类素材规范

### 3.1 城墙素材 (Walls)
```
必需变体：
├── 石墙 (wall_stone) - 粗糙石头纹理，有裂缝
├── 钢墙 (wall_steel) - 金属板，锈蚀痕迹
└── 木墙 (wall_wood) - 破旧木板，有腐烂痕迹

风格要点：
- 边缘有战损/缺口效果
- 可添加血迹或感染绿斑（可选）
- 高度可超出网格，但碰撞底座为32x32
```

### 3.2 防御塔素材 (Towers)
```
必需变体：
├── 箭塔 (tower_arrow) - 机械弩炮风格，蒸汽朋克
├── 激光塔 (tower_laser) - 科技感，蓝色能量光
└── 火焰塔 (tower_flame) - 喷火装置，橙色火焰

风格要点：
- 底座：工业/军事风格（金属、管道）
- 顶部：武器装置明显可见
- 攻击时有发光/能量特效
```

### 3.3 敌人素材 (Enemies)
```
分类：
├── 普通僵尸 - 缓慢移动，灰绿皮肤
├── 快速僵尸 - 红眼/变异特征，动作敏捷
├── 变异体 - 大体型，有明显生化特征
└── 特殊感染者 - 有独特能力标记（发光器官等）

风格要点：
- 皮肤色调：灰白、灰绿、腐烂棕
- 眼睛：可为红色/绿色发光（感染特征）
- 动作：摇摇晃晃、不协调的姿态
- 可添加血迹、伤口细节
```

### 3.4 玩家素材 (Player)
```
角色类型：
├── 生存者 - 普通人类，有装备
├── 军事单位 - 武装士兵风格
└── 特殊角色 - 有科技/生化装备

风格要点：
- 清晰区别于僵尸（颜色、姿态）
- 装备：枪械、护甲、工具可见
- 动画帧数高于僵尸（更流畅）
```

### 3.5 地面/环境素材 (Environment)
```
地面类型：
├── 废土地面 - 灰褐色，有裂纹
├── 沙地 - 黄褐色，沙漠废土感
├── 水泥地 - 灰色，有裂缝和污渍
└── 血迹地面 - 可叠加的血迹/感染痕迹

风格要点：
- 不宜过亮（背景需衬托单位）
- 可有随机纹理变化（脏污、裂缝）
```
