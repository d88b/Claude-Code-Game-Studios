## 音效风格指南

### 整体风格

- **工业感**: 机械运转、金属碰撞
- **魔幻感**: 低沉神秘、能量波动
- **僵尸感**: 沙哑、腐烂、沉重
- **UI**: 清脆、简洁、不刺耳

### 工具推荐

| 工具 | 用途 |
|------|------|
| **Bfxr** | 快速生成 8-bit/retro 音效 |
| **sfxr.me** | 网页版音效生成器 |
| **Audacity** | 音效编辑和后期处理 |
| **FMOD/Wwise** | 专业音频中间件（可选） |
| **ElevenLabs/Suno** | AI 音效生成（可选） |

### 音效来源

| 来源 | 说明 |
|------|------|
| **Freepd.com** | 免费 CC0 公有领域音效 |
| **Incompetech.com** | Kevin MacLeod 免费 BGM |
| **OpenGameArt.org** | 游戏音效素材库 |
| **自制** | 使用 Bfxr/sfxr.me 生成 |
