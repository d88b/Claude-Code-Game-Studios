## 七、性能优化建议（🔴 全新补充）

### 7.1 渲染优化

| 优化项 | 方法 | 预期效果 |
|--------|------|---------|
| **对象池** | 子弹/粒子/敌人使用对象池 | 减少GC，提升流畅度 |
| **视锥裁剪** | 屏幕外对象不渲染 | 减少30-50%渲染负载 |
| **TileMap 优化** | 使用 Godot TileMap 层，合并静态tile | 减少draw call |
| **Sprite 批处理** | 同材质Sprite合并batch | 减少GPU调用 |
| **LOD 系统** | 远处物体用简化模型/贴图 | 减少渲染复杂度 |
| **粒子限制** | 根据画质预设限制粒子数 | 低画质<50，高画质<200 |
| **阴影优化** | 仅关键物体投射阴影 | 减少阴影计算 |
| **后处理按需开启** | HDR/模糊/景深默认关闭 | 减少后处理开销 |

### 7.2 内存优化

| 优化项 | 方法 | 预期效果 |
|--------|------|---------|
| **资源按需加载** | 海域/敌人按需加载，不预加载全部 | 减少初始内存占用 |
| **纹理压缩** | 使用 Godot VRAM 压缩（ETC2/ASTC） | 纹理内存-50% |
| **音频流式加载** | 背景音乐流式播放，音效预加载 | 减少音频内存 |
| **场景卸载** | 离开海域后卸载旧场景资源 | 释放不再使用的内存 |
| **字符串池化** | 常用字符串复用 | 减少字符串分配 |
| **对象池（复用）** | 频繁创建/销毁的对象使用池 | 减少内存碎片 |

### 7.3 CPU 优化

| 优化项 | 方法 | 预期效果 |
|--------|------|---------|
| **AI 更新频率** | 非活跃敌人降低AI更新频率 | 减少CPU占用 |
| **物理简化** | 远处物体简化物理计算 | 减少物理引擎开销 |
| **事件驱动** | 用信号替代每帧检查 | 减少无用计算 |
| **波次预计算** | 波次数据预计算，运行时直接使用 | 减少运行时计算 |
| **路径缓存** | AI路径结果缓存复用 | 减少重复寻路 |

### 7.4 Godot 特定优化

| 优化项 | Godot 实现 |
|--------|-----------|
| **使用 Callable 替代 func ref** | Godot 4 推荐方式 |
| **避免 `_process` 滥用** | 不需要每帧更新的用 `_physics_process` 或信号 |
| **使用 `@export` 暴露配置** | 编辑器中调整，减少硬编码 |
| **Resource 数据驱动** | 敌人/武器数据用 `.tres` 文件 |
| **多线程加载** | `ResourceLoader.load_threaded` 异步加载 |
| **CanvasLayer 分层** | UI 单独 CanvasLayer，减少重绘 |
| **VisibilityNotifier2D** | 屏幕外节点自动暂停处理 |
| **AnimationTree** | 用状态机管理动画，替代代码控制 |

```

│   └── user:// 路径（Godot 自动处理）

│   ├── 输入动作映射（Input Map）

├── 字体
│   ├── 中文字体体积大 → 考虑子集化
│   └── 各平台字体渲染差异
├── 性能
│   ├── 各平台画质预设
│   ├── 动态分辨率缩放
│   └── 内存预算分级
└── 平台特性
    ├── Steam: 成就/云存档/排行榜
    ├── 主机: 奖杯/暂停恢复
    └── 移动端: 通知/内购
```
