### 3.3 建议补充：温度/压力精确计算公式

```
温度计算：
  基础温度 = 海面温度 + (深度 × 温度衰减系数)
  海面温度 = 根据天气和海域变化 (-20°C ~ 40°C)
  温度衰减系数 = -0.02°C/m（正常海域）
  海底火山区域 = 基础温度 + 火山热力加成 (+50°C ~ +200°C)
  冰下洞穴 = 基础温度 - 寒冰加成 (-30°C ~ -10°C)
  
  潜艇实际温度 = 环境温度 - 保暖舱效果 - 耐热舱效果
  保暖舱 Lv1: 抵御 -10°C
  保暖舱 Lv2: 抵御 -20°C
  耐热舱 Lv1: 抵御 +60°C
  耐热舱 Lv2: 抵御 +120°C

压力计算：
  水压(大气压) = 1 + (深度m / 10)
  
  例：100m深 = 11大气压, 500m深 = 51大气压
  
  潜艇实际压力 = 环境压力 - 抗压舱效果
  抗压舱 Lv1: 抵御 10大气压（可到达100m）
  抗压舱 Lv2: 抵御 20大气压（可到达200m）
  抗压舱 Lv3: 抵御 50大气压（可到达500m）
  抗压舱 Lv4: 抵御 100大气压（可到达1000m）
```

### 3.4 建议补充：温度/压力叠加伤害

| 叠加条件 | 伤害公式 | 说明 |
|---------|---------|------|
| 极寒+高压 | 伤害 = (基础压力伤害 × 1.5) | 低温加剧压力影响 |
| 极热+高压 | 伤害 = (基础压力伤害 × 1.3) | 高温增加设备故障率 |
| 极寒+极热交替 | 伤害 = (温度差 × 0.1)/秒 | 温度骤变造成材料疲劳 |
| 温度正常+高压 | 伤害 = 基础压力伤害 | 正常叠加 |
| 压力正常+极端温度 | 伤害 = 基础温度伤害 | 正常叠加 |
| 极寒+极热+高压 | 伤害 = (基础压力 × 2) + (温度差 × 0.15) | 最恶劣条件 |

|------|---------|---------|

#### 6.3.4 市场波动机制

```
价格波动因素：
├── 供需关系
│   ├── 玩家大量出售某资源 → 价格下跌（-10%~-30%）
│   ├── 玩家长期不购买某资源 → 价格上涨（+5%~+20%）
│   └── 商人库存不足 → 价格大幅上涨（+30%~+100%）
├── 世界事件
│   ├── 风暴期间 → 氧气/弹药价格上涨
│   ├── 战争时期 → 武器/弹药价格翻倍
│   ├── 和平时期 → 建造资源价格下降
│   └── 遗迹发现潮 → 远古物品价格下降
├── 商人关系
│   ├── 好感度高 → 个人折扣（-5%~-20%）
│   ├── 好感度低 → 个人加价（+10%~+50%）
│   └── 长期客户 → 额外优惠
└── 时间因素
    ├── 每日价格小幅波动（±5%）
    ├── 每周价格重置基准
    └── 特殊节日/事件 → 特价商品
```
