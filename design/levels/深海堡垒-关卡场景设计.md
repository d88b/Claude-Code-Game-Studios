# 深海堡垒 - 关卡场景设计

> **核心目标**：设计2D横向视角的关卡场景结构、房间布局、敌人/物品分布、氛围效果。
> **视角**：2D 横向（类似泰拉瑞亚），左右移动，上下分层
> **核心概念**：最下面是深不可测的海水

---

## 一、场景总体结构

### 1.1 纵向分层（从上到下）

```
Y轴（深度）
↑ 负值 = 上方（天空/水面）
↓ 正值 = 下方（深海/深渊）

第1层（水面）    Y=-800~-600  暗蓝灰色，偶尔闪电亮一下
第2层（上层）    Y=-600~-300  人造结构为主，灯光可闪烁
第3层（中层）    Y=-300~0     灯光逐渐减少，应急灯
第4层（下层）    Y=0~150      几乎无光，手电筒是唯一光源
第5层（深渊）    Y=150+       全黑，不可见区域，有生物眼睛
```

## 五.5 场景迷雾系统

### 5.5.1 迷雾设计理念

2D 横版恐怖游戏的核心体验是**"看不清"**。迷雾系统负责：
- **限制视野**：玩家只能看到手电筒照射范围内的区域
- **制造悬念**：远处隐约可见的轮廓/影子/眼睛
- **控制节奏**：进入新区域时视野受限，逐步探索
- **深度感**：雾气让 2D 画面有纵深感

### 5.5.2 迷雾分层结构

```
Layer 0: 全局黑暗遮罩（CanvasModulate）
         ↓ 所有区域的基础亮度
Layer 1: 区域基础雾（ColorRect + Shader）
         ↓ 每个区域的固定雾密度
Layer 2: 动态粒子雾（GPUParticles2D）
         ↓ 漂浮的雾气粒子，增加立体感
Layer 3: 手电筒锥形光（Light2D + 阴影）
         ↓ 唯一的光源，切割黑暗
```

### 5.5.3 各区域迷雾配置

| 区域 | 雾密度 | 可见距离 | 雾颜色 | 说明 |
|------|--------|---------|--------|------|
| A1 水面平台 | 20% | 全屏可见 | 灰白 | 安全区域，轻度雾气 |
| A2 警戒塔 | 30% | 80% | 灰白 | 稍微浓一些 |
| B1 走廊入口 | 40% | 60% | 灰蓝 | 开始看不清远处 |
| B2 主走廊 | 50% | 50% | 灰蓝 | 走廊尽头模糊 |
| B3 实验室 | 55% | 45% | 灰绿 | 培养罐区域有绿色雾气 |
| C1 生活区 | 45% | 55% | 灰白 | 宿舍角落有暗影 |
| D1 引擎室 | 35% | 70% | 灰红 | 高温蒸汽，能见度较好但红色 |
| E1 货舱 | 60% | 40% | 深灰 | 集装箱之间雾很重 |
| F1 深海区 | 85% | 15% | 深蓝黑 | 几乎看不见，手电筒是关键 |
| F2 深渊 | 95% | 5% | 纯黑 | 全黑，只有手电筒锥形光 |

```
F1 深海区：     ██░░░░░░░░░░░░░░░░░░ （只有手电筒前方一小圈）
```

### 5.5.5 迷雾与 gameplay 的关系

| 效果 | 对玩法的影响 |
|------|-------------|
| 走廊尽头看不清 | 玩家不敢贸然前进，增加紧张感 |
| 集装箱之间的浓雾 | 敌人可能从任何方向出现 |
| 深海区极低能见度 | 必须依赖手电筒，电池管理变得关键 |
| 敌人从雾中出现 | 惊吓效果最大化 |
| 物品半隐在雾中 | 探索感，"那里有什么？" |

### 5.5.6 动态雾效

| 效果 | 触发条件 | 说明 |
|------|---------|------|
| 雾气飘动 | 持续 | GPUParticles2D 漂浮雾气粒子 |
| 雾浓度波动 | 随机 | 偶尔一阵浓雾，然后散去 |
| 蒸汽喷出 | D1 引擎室 | 管道破裂喷出高温蒸汽，短暂遮挡视线 |
| 海水涌入 | F1 深海区 | 墙壁裂缝渗入海水，增加雾气 |
| 敌人扰动 | 敌人经过 | 敌人移动时搅动雾气，留下痕迹 |

### 5.5.7 Godot 2D 迷雾实现方案

```
level1.tscn
├── CanvasModulate               ← 全局调暗（颜色 = 雾颜色）
├── ParallaxBackground           ← 背景层（多层视差）
├── TileMap / 墙壁               ← 碰撞体
├── 玩家 (CharacterBody2D)
│   └── Light2D (手电筒)         ← 锥形光，60° 角度
│       └─ texture = 锥形渐变纹理
│       └─ energy = 1.0
│       └─ range = 按区域调整
├── 敌人 (CharacterBody2D)
├── GPUParticles2D (雾气粒子)    ← 每个区域一套
│   └─ 数量/速度/大小按区域调整
└── LightOccluder2D             ← 墙壁遮挡光线
```

**手电筒 Light2D 设置**：
```
Light2D:
  texture: 锥形渐变纹理（中间亮，边缘渐透明，60°角）
  energy: 1.0（可动态调整）
  range: 300px（走廊）/ 100px（深海区）
  color: 白色/区域色调
  shadow: enabled（墙壁遮挡）
```

**迷雾粒子参数**：
```
GPUParticles2D:
  amount: 50-200（按区域浓度）
  lifetime: 3-8 秒
  speed: 5-20 px/s（缓慢飘动）
  scale: 0.5-2.0
  color: 灰白/深蓝/纯黑（按区域）
```

```
│   └── area_deepsea.tscn      # F1-F2 深海+深渊
└── main_menu.tscn        # 主菜单
```

### 6.2 核心节点类型

| 元素 | Godot 2D 节点 | 说明 |
|------|--------------|------|
| 玩家 | `CharacterBody2D` | 2D 角色，左右移动+上下 |
| 敌人 | `CharacterBody2D` | 2D 敌人 AI |
| 墙壁/地板 | `StaticBody2D` + `CollisionShape2D` | 碰撞体 |
| 物品 | `Area2D` + `Sprite2D` | 拾取检测 |
| 出口门 | `Area2D` + `Sprite2D` | 交互检测 |
| 相机 | `Camera2D` | 跟随玩家 |
| 背景 | `ParallaxBackground` + `ParallaxLayer` | 多层视差 |
| 灯光 | `PointLight2D` | 2D 点光源（手电筒/应急灯） |
| 迷雾遮罩 | `CanvasModulate` | 全局亮度控制（配合 Light2D 做明暗） |
| 区域雾 | `ColorRect` + Shader | 半透明雾层，可调密度和颜色 |
| 动态雾粒子 | `GPUParticles2D` | 漂浮雾气，增加立体感 |
| 手电筒锥形光 | `Light2D` + `CanvasItem` 阴影 | 60° 锥形，切割黑暗 |
| 粒子 | `GPUParticles2D` | 气泡/蒸汽/灰尘 |
| UI | `CanvasLayer` + `Control` | HUD/提示 |

### 6.3 相机设置

```
Camera2D:
  - position_smoothing_enabled: true
  - position_smoothing_speed: 5.0
  - limit_left: 0
  - limit_right: 关卡总宽度
  - limit_top: -900   # 水面以上限制
  - limit_bottom: 200  # 深渊边界
```

```
ParallaxBackground:

```
