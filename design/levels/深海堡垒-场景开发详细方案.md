# 深海堡垒 — 场景开发详细方案

> **目标**：从零到第一个可玩场景，让玩家能在 2D 横版关卡中行走
> **策略**：先用代码/占位符搭出场景骨架，再逐步替换美术
> **前提**：用户不会 Godot 编辑器 → AI 直接写所有文件

---

## 总览：场景开发 5 步

```
Step 1    项目骨架        → 能导入 Godot 的空项目
Step 2    背景层          → 能看到天空/海水/视差背景
Step 3    房间结构+玩家   → 能走、能跳、相机跟随
Step 4    迷雾+灯光       → 手电筒切割迷雾，氛围拉满
Step 5    内容填充        → 敌人/物品/出口门/深渊边界
          ────────────
          ★ 验收：完整跑通 "出生→走廊→货舱→开门"
```

### 2.4 各层实现

| 层 | Godot 节点 | 实现方式 | 说明 |
|----|-----------|---------|------|
| 1 天空 | `ColorRect` + Shader | 渐变 Shader（上深蓝→下浅蓝） | 全屏覆盖 |
| 2 远景 | `ParallaxLayer` + `Sprite2D` | 大建筑轮廓（先用 ColorRect） | motion_scale: 0.1 |
| 3 中景 | `ParallaxLayer` + `Sprite2D` | 墙壁轮廓（ColorRect） | motion_scale: 0.3 |
| 4 近景 | `ParallaxLayer` + `Sprite2D` | 管道/电缆（Line2D） | motion_scale: 0.8 |
| 5 海水 | `ColorRect` + Shader | 动态波浪 Shader | 正弦波动画 |
| 6 深海 | `ColorRect` | 深蓝/纯黑纯色 | 背景底色 |

### 2.5 天空渐变 Shader

```glsl
shader_type canvas_item;

uniform vec4 top_color : source_color = vec4(0.05, 0.1, 0.2, 1.0);
uniform vec4 bottom_color : source_color = vec4(0.15, 0.25, 0.4, 1.0);

void fragment() {
    COLOR = mix(bottom_color, top_color, UV.y);
}
```

### 2.6 海水 Shader

```glsl
shader_type canvas_item;

uniform float wave_height = 10.0;
uniform float wave_speed = 1.5;
uniform vec4 water_color : source_color = vec4(0.0, 0.15, 0.3, 0.8);

void vertex() {
    VERTEX.x += sin(VERTEX.x * 0.02 + TIME * wave_speed) * wave_height;
}

void fragment() {
    COLOR = water_color;
}
```

### 2.7 验收

1. 打开游戏 → 看到暗蓝色天空 + 深海背景
2. 海水有微弱的波浪动画
3. 移动相机 → 远景层有视差效果

### 4.3 实现架构

```
main.tscn
├── CanvasModulate              ← 全局调暗（颜色=雾颜色）
├── ParallaxBackground          ← 背景层（Step 2 已有）
├── 房间结构                     ← Step 3 已有
├── 玩家 (CharacterBody2D)
│   ├── Sprite2D               ← 玩家外观

└── LightOccluder2D             ← 墙壁遮挡光线
```

### 4.4 手电筒 Light2D

| 属性 | 值 | 说明 |
|------|-----|------|
| texture | 锥形渐变纹理 | 中间亮→边缘渐透明，60°角 |
| energy | 1.0 | 亮度 |
| range | 300px（走廊）/ 100px（深海） | 照射距离 |
| color | 白色 | 光色 |
| shadow | enabled | 墙壁能遮挡光线 |

**锥形纹理生成**（代码生成，不需要图片）：
```gdscript
# 生成一个锥形渐变纹理
func create_cone_texture() -> Texture2D:
    var img = Image.create(256, 256, false, Image.FORMAT_RGBA8)
    var center = Vector2(128, 128)
    for x in range(256):
        for y in range(256):
            var pos = Vector2(x, y) - center
            var dist = pos.length()
            var angle = pos.angle()
            # 锥形：60度范围（-30° 到 +30°）
            if abs(angle) < PI/6 and dist < 128:
                var brightness = 1.0 - dist / 128.0
                img.set_pixel(x, y, Color(1, 1, 0.9, brightness))
            else:
                img.set_pixel(x, y, Color(0, 0, 0, 0))
    return ImageTexture.create_from_image(img)
```

### 4.5 迷雾系统

| 层 | 实现 | 参数 |
|----|------|------|
| 全局暗度 | `CanvasModulate` | color = 深灰/深蓝（按区域） |
| 区域基础雾 | `ColorRect` + Shader | 半透明，透明度按区域调整 |
| 动态雾粒子 | `GPUParticles2D` | 50-200个粒子，缓慢飘动 |

**各区域雾密度**：

| 区域 | 雾密度 | CanvasModulate 颜色 |
|------|--------|-------------------|
| A1 水面 | 20% | (0.8, 0.82, 0.85) |
| B2 走廊 | 50% | (0.5, 0.52, 0.55) |
| C1 生活区 | 65% | (0.35, 0.36, 0.38) |
| E1 货舱 | 70% | (0.3, 0.3, 0.32) |
| F1 深海 | 85% | (0.05, 0.05, 0.1) |
| F2 深渊 | 95% | (0.02, 0.02, 0.02) |

### 4.6 动态灯光

| 效果 | 实现 | 位置 |
|------|------|------|

## 执行顺序

**推荐按顺序执行**，因为每一步都依赖上一步：

```
Step 1 → Step 2 → Step 3 → Step 4 → Step 5
  ↓        ↓        ↓        ↓        ↓
 能导入   有画面   能行走   有氛围   能玩
```

但也可以 **并行**：
- Step 2（背景）和 Step 3（房间结构）可以一起做
- Step 4（迷雾）必须等 Step 3 完成
- Step 5（内容）必须等 Step 3 和 Step 4 完成
