| 类别 | 具体内容 | 数量估算 | 优先级 |

| **背景** | 天空层、海洋层、海底层 | 9组（9个海域） | 🔴 P0 |

## 二、素材制作方案对比

| 方案 | 成本 | 质量 | 速度 | 适合做什么 |
|------|------|------|------|-----------|
| **AI生成** | 低（免费/低价） | 中等 | 快 | 背景、场景艺术图、部分Sprite |
| **免费素材包** | 免费 | 中等 | 极快 | 基础元素、占位符 |
| **手绘（像素）** | 时间成本 | 高（像素风） | 慢 | 小精灵、UI图标 |
| **手绘（矢量）** | 时间成本 | 高 | 很慢 | 船体、潜艇等核心元素 |
| **外包** | $$$ | 高 | 中 | Boss、关键角色 |
| **程序生成** | 开发时间 | 程序化 | 一次性开发 | 地形、波浪、粒子 |

### 🎯 推荐混合方案

**不要只用一种方式！** 组合使用：

| 素材类型 | 推荐方案 | 原因 |
|---------|---------|------|
| 背景（天空/海洋/海底） | **AI生成 + Shader动画** | AI画静态分层，Godot用Shader做动画 |
| 船体/潜艇 | **免费素材包为基础 + AI修改** | 有现成船体素材，修改风格即可 |
| 敌人 | **AI生成 + 程序化变色** | AI生成基础怪物，用Godot调色调/大小 |
| 物品图标 | **AI生成 或 手绘像素** | 小图标，AI或手绘都很快 |
| UI元素 | **Godot内置 + CSS风格** | 用Godot的StyleBox做，不需要外部素材 |
| 特效 | **Godot粒子系统** | 程序生成，不需要外部素材 |
| 音效 | **免费音效库 + AI生成** | freesound.org + AI音乐生成 |

## 三、第一批素材：海洋/天空/陆地/船只

### 3.1 天空层素材

#### 方案A：AI生成 + Godot视差滚动（推荐）

**需要生成的图片**：
| 图片 | 尺寸 | 说明 |
|------|------|------|
| sky_far.png | 3840×600 | 远景天空（最慢滚动） |
| sky_mid.png | 3840×400 | 中景天空（中速滚动） |
| sky_near.png | 3840×200 | 近景天空/云（快速滚动） |

**AI生成提示词（中文）**：

```
远景天空（晴天白天）：
横向全景，广阔的天空，蓝天白云，
游戏背景素材，无缝水平平铺，
2D游戏风格，扁平化设计，高清

远景天空（风暴天）：
横向全景，乌云密布，闪电，暴风雨的天空，
游戏背景素材，无缝水平平铺，
2D游戏风格，暗色调，高清

远景天空（夜晚）：
横向全景，星空，月亮，深蓝色夜空，
游戏背景素材，无缝水平平铺，
2D游戏风格，高清
```

**Godot中设置视差滚动**：
```gdscript
# ParallaxBackground + ParallaxLayer
# 远景：motion_scale = Vector2(0.1, 0.1)
# 中景：motion_scale = Vector2(0.3, 0.3)
# 近景：motion_scale = Vector2(0.6, 0.6)
```

#### 方案B：免费素材包

推荐资源站：
- **itch.io**：搜索 "parallax sky game assets" 或 "2d game sky background"
- **OpenGameArt.org**：搜索 "sky background"
- **Kenney.nl**：免费游戏素材（有天空背景）
- **GameDev Market**：部分免费素材

#### 方案C：程序生成（最低成本）

用Godot Shader直接生成天空渐变，不需要图片：

```glsl
// sky_shader.gd
shader_type canvas_item;

uniform vec4 top_color : source_color = vec4(0.2, 0.5, 0.9, 1.0);
uniform vec4 bottom_color : source_color = vec4(0.6, 0.8, 1.0, 1.0);

void fragment() {
    COLOR = mix(bottom_color, top_color, UV.y);
}
```

### 3.2 海洋层素材

#### 方案A：Shader生成海面波浪（强烈推荐）

**不需要任何图片！** 直接用Godot Shader生成动态海面：

```glsl
// ocean_surface.gd
shader_type canvas_item;

uniform float time : hint_range(0, 100);
uniform vec4 water_color : source_color = vec4(0.0, 0.4, 0.7, 1.0);
uniform float wave_height = 15.0;
uniform float wave_speed = 2.0;

void vertex() {
    VERTEX.x += sin(VERTEX.x * 0.05 + TIME * wave_speed) * wave_height;
    VERTEX.y += cos(VERTEX.x * 0.03 + TIME * wave_speed * 0.7) * wave_height * 0.5;
}

void fragment() {
    COLOR = water_color;
}
```

**效果**：实时动态波浪，风暴天调高wave_height即可。

#### 方案B：AI生成海面Sprite

如果需要更风格化的海面：
| 图片 | 尺寸 | 说明 |
|------|------|------|
| ocean_surface.png | 1920×100 | 海面波浪线 |
| ocean_gradient.png | 1920×800 | 海水渐变（海面到海底） |

**AI提示词**：

### 3.3 陆地/海底层素材

#### TileMap方案（推荐）

海底地形用Godot的 **TileMap** 系统，只需要小图块：

| 图块 | 尺寸 | 数量 | 说明 |
|------|------|------|------|
| 沙地 | 64×64 | 4种变体 | 基础海底地面 |
| 岩石 | 64×64 | 6种变体 | 障碍物/掩体 |
| 珊瑚 | 64×64 | 4种 | 装饰物 |
| 洞穴墙壁 | 64×64 | 8种（带auto-tiling） | 洞穴系统 |
| 矿物点 | 64×64 | 3种 | 可采集资源 |

**获取方式**：
1. **免费素材包**（最快）：
   - itch.io搜索 "underwater tileset" 或 "cave tileset"
   - 推荐包：**"Underwater Tileset"** by limezu
   - 推荐包：**"Dungeon Tileset"** 改色为蓝色调

2. **AI生成图块**：
   - AI生成一张大图（512×512含多个64×64图块）
   - 用Godot的TileSet编辑器切割

**AI提示词**：
```
2D游戏Tileset素材，海底主题，
64x64像素图块网格，包含：
沙地、岩石、珊瑚、洞穴墙壁、矿物点，
侧视视角，像素风格，透明背景，
用于Godot引擎TileMap系统
```

#### 单层背景方案（MVP最快）

如果连TileMap都觉得复杂，MVP阶段用**单层渐变背景**：

```
从上到下：
海水渐变（浅蓝→深蓝） → 沙地 → 岩石装饰
```

用3张图搞定：
1. `bg_ocean_gradient.png`（1920×800）— 海水渐变
2. `bg_sand.png`（1920×200）— 海底沙地
3. `bg_rocks.png`（1920×100）— 海底岩石装饰（随机放置）

## 四、素材工作流建议

### MVP工作流（最快出效果）

```
1. 用Godot基本形状（ColorRect/Circle2D等）占位
   ↓
2. 用免费素材包替换占位符
   ↓
3. 用AI生成补充缺少的素材
   ↓
4. 统一色调和风格（Godot后期处理）
   ↓
5. 必要时找画师手绘关键素材
```

### AI生成素材的完整工作流

```
1. 用AI生成素材（AutoGLM / Midjourney / Stable Diffusion）
   ↓
2. 检查尺寸、格式、透明度
   ↓
3. 用GIMP/Krita/Photoshop微调（裁剪、调色、去瑕疵）
   ↓
4. 导入Godot
   ↓
5. 调整材质和Shader效果
```

### AI生成注意事项

| 注意事项 | 说明 |
|---------|------|
| **尺寸统一** | 同一类素材统一尺寸（如所有物品64×64） |
| **风格一致** | 用相同的AI提示词模板，保持风格统一 |
| **无缝平铺** | 背景素材需要水平无缝平铺 |
| **透明背景** | Sprite需要PNG透明背景 |
| **后期调色** | Godot里用ColorRect/Material统一色调 |
