## Overview

NPC系统设计了8个核心NPC（老船长·海伯/科学家·珊瑚/避难所长·铁锚/遗迹守护者·深渊之眼/海盗叛逃者·红帆/工程师·齿轮/海洋生物学者·贝壳/信号源·未知频率），每个NPC有独特性格、功能、好感度系统和故事线。NPC通过好感度（0-100，5级：敌对/冷淡/中立/友好/亲密）影响交易价格、可接任务数、招募可能性和最终结局。NPC支持对话树、日程移动、招募上船和羁绊事件，与任务系统、经济系统、船员系统、结局系统深度关联。

---

## Player Fantasy

玩家应感受到：
- **NPC个性鲜活的沉浸感** — 海伯的航海故事、珊瑚的学术腔、齿轮的技术术语，每个NPC有标志性台词和独特交互风格
- **好感度培养的成就感** — 从冷淡到亲密，交易折扣-20%、解锁隐藏商品、特殊剧情线，好感度带来实实在在的好处
- **招募上船的归属感** — NPC从固定位置搬到你的船上，提供服务加成和船内互动，"这支队伍是我建立的"
- **结局关联的权重感** — 招募的NPC数量和好感度直接决定6种结局走向，每个NPC选择都在塑造最终命运

### 对话系统

**对话框架**: 触发（主动接近/NPC发起/任务完成后/好感度变化）→ 内容（问候/常规/任务/里程碑/告别）→ 选项 → 状态记录。

**对话选项类型**:

| 类型 | 好感影响 | 示例 |
|------|---------|------|
| 友好型 | +2~5 | "谢谢你告诉我"、"我来帮你" |
| 中立型 | 0 | "知道了"、"我会考虑" |
| 挑衅型 | -5~10 | "你确定？"、"我没兴趣" |
| 信息型 | +0~3 | "能多说一些吗？" |
| 幽默型 | +1~3 | "你比我的船还唠叨" |
| 同情型 | +3~5 | "你一定很辛苦吧" |

**对话树示例（海伯）**:
- 初始: "有什么好货？"→交易 / "海况如何？"→情报(+2) / "讲航海故事？"→背景(+5)
- 好感61+: "深渊的秘密？"→隐藏情报(+3)
- 好感81+: "我需要你的帮助"→招募前置(+5)

### NPC日程与移动

| 移动类型 | NPC | 规则 |
|---------|-----|------|
| 固定 | 海伯、铁锚、深渊之眼 | 不离开固定位置 |
| 半固定 | 珊瑚、贝壳 | 在固定区域范围内活动 |
| 随机 | 红帆、齿轮 | 按概率在特定海域刷新 |
| 隐藏 | 信号源 | 仅在特定条件下出现 |

**日程示例**: 海伯全天在市场交易，20:00-22:00到酒馆讲故事；珊瑚08:00-18:00在实验室，18:00-20:00外出采集样本（可遭遇）。

**规则**: 半固定NPC风暴时返回室内；招募后NPC跟随玩家船只移动；NPC移动前播放简短动画/对话通知。

### 招募系统

**招募流程**: 前置条件满足（好感度+任务/物品）→ 招募对话 → 登船仪式（动画）→ 船上功能解锁。

**招募后效果**: 船内可对话互动、独特功能加成、影响船员士气、影响最终结局、解锁船上专属任务线、好感度提升触发羁绊事件。

### NPC与结局关联

| 结局 | 条件 |
|------|------|
| 结局1：新家园 | 至少招募3个NPC，平均好感≥60 |
| 结局2：深渊统治 | 招募红帆+深渊之眼，选择攻击路线，船员忠诚度≥60 |
| 结局3：海洋守护者 | 招募贝壳+珊瑚，好感≥80，完成生态守护者链 |
| 结局4：永恒漂泊 | 不招募任何NPC或仅1个，选择继续航行 |
| 结局5：远古觉醒 | 招募深渊之眼+信号源，好感≥50，完成所有隐藏链 |
| 结局6：悲剧沉没 | 所有NPC好感<30或全部拒绝招募 |

## Formulas

### 交易价格修正

```
final_price = base_price × affinity_modifier × supply_demand_modifier

affinity_modifier:
  0-20 (敌对):   1.50  (+50%)
  21-40 (冷淡):  1.15  (+15%)
  41-60 (中立):  1.00  (+0%)
  61-80 (友好):  0.90  (-10%)
  81-100 (亲密): 0.80  (-20%)
```

### 好感度变化计算

```
affinity_change = base_change × gift_quality_modifier × event_modifier

gift_quality_modifier:
  最爱礼物: 1.5
  次爱礼物: 1.0
  普通礼物: 0.5
  讨厌礼物: -1.0

# 示例: 赠送海伯朗姆酒(最爱)，base=7
affinity_change = 7 × 1.5 = 10.5 → round to 10
```

### 长期不互动衰减

```
weeks_without_interaction = (current_time - last_interaction) / 7_days
affinity_decay = weeks_without_interaction × random(1, 3)
new_affinity = max(0, current_affinity - affinity_decay)
```

### 结局判定权重

```
# 每个NPC对6个结局的权重: ★★★=3, ★★=2, ★=1, -=0
ending_score[ending_id] = sum(npc_weight[npc][ending_id] ×
                               (is_recruited[npc] ? 1 : 0) ×
                               (npc_affinity[npc] / 100))

final_ending = argmax(ending_score)
```

## Edge Cases

1. **NPC好感度降至0（敌对）**: NPC拒绝所有交互，可能主动攻击玩家或向其他NPC散布负面评价。需通过特殊任务（道歉/赔偿）恢复。
2. **招募后NPC死亡**: 船上功能永久消失，船员士气-15，触发"哀悼"事件。其他与该NPC好感度高的NPC额外-10好感。
3. **对话选项导致好感度跨越等级阈值**: 立即更新NPC表情/颜色/可用选项，对话树中新增/移除对应好感度等级的选项。
4. **半固定NPC在风暴中返回室内但玩家在室外等待**: NPC返回后显示"风暴太危险，我先回室内了"提示，风暴结束后恢复正常日程。
5. **招募条件与主线任务冲突**: 招募对话延迟到主线任务完成后弹出，避免分心。
6. **NPC日程时间与日夜系统不同步**: NPC日程使用游戏内时间，日夜系统变化时NPC行为相应调整（如夜晚返回休息）。
7. **多个NPC好感度同时变化**: 如救援事件影响多个NPC好感度，按NPC ID排序依次应用，每个变化弹出独立提示。
8. **信号源NPC（N08）首次接触**: 仅通过无线电声音和文字，不可见面，好感度0时为"未知"状态。
9. **NPC对话树已穷尽（所有对话已触发）**: 显示通用问候语，不再标记为新对话，但好感度变化后重新解锁。
10. **存档加载时NPC位置已改变**: 使用存档中的NPC位置数据恢复，不重新计算日程。

## Acceptance Criteria

- [ ] 8个核心NPC各有独立属性（名称/类型/位置/初始好感/招募条件/船上功能）
- [ ] 好感度5级：敌对(0-20)/冷淡(21-40)/中立(41-60)/友好(61-80)/亲密(81-100)
- [ ] 好感度影响交易价格：敌对+50%，冷淡+15%，中立0%，友好-10%，亲密-20%
- [ ] 每个NPC有独特的礼物偏好（最爱/次爱/讨厌），赠送后好感度变化正确
- [ ] 对话系统支持6种选项类型（友好/中立/挑衅/信息/幽默/同情）
- [ ] 对话树根据好感度等级动态新增/移除选项
- [ ] NPC按移动类型正确行为：固定不移动、半固定区域活动、随机海域刷新、隐藏条件出现
- [ ] 招募流程：前置条件→招募对话→登船动画→功能解锁
- [ ] 招募后NPC在船上可对话互动，提供独特功能加成
- [ ] 6种结局根据NPC招募数量和好感度正确判定
- [ ] 好感度长期不互动每周衰减1-3点
- [ ] NPC好感度<30时所有NPC拒绝招募触发结局6（悲剧沉没）
- [ ] NPC数据结构包含npc_id/name/type/location/affinity/recruitment/on_board_effects/gift_preferences/schedule
- [ ] 攻击NPC好感度-30~-50，可能变为敌对
- [ ] 存档加载时NPC位置和好感度正确恢复
