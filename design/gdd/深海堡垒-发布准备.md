## Overview

发布准备文档涵盖性能优化（渲染/内存/加载/AI/音效）、平台适配（PC/Steam Deck/主机/移动端）、发布准备清单（内容完整性/技术检查/法律合规/商店要求/市场推广/社区准备）和发布后支持计划。目标帧率PC 60FPS最低45FPS、Steam Deck 60FPS最低40FPS，游戏总大小<2GB，安装包<1GB。发布流程分Alpha→Beta→RC→Gold→发布5个阶段。

---

## Player Fantasy

玩家应感受到：
- **流畅的性能体验** — 60FPS稳定，加载时间<5秒，长时间游玩无内存泄漏
- **多平台的适配质量** — PC多分辨率支持、Steam Deck休眠恢复、主机平台30FPS稳定
- **无崩溃的稳定性** — 连续游玩2小时无崩溃，存档/加载正常，设置重启保留
- **发布后的持续支持** — 崩溃报告自动收集，1/3/6/9/12个月免费更新路线图

## Detailed Rules

### 性能优化

**渲染优化**:

| 优化项 | 方法 | Godot实现 | 预期效果 |
|--------|------|----------|---------|
| 对象池 | 子弹/粒子/敌人复用 | Node池+queue_free替代 | 减少GC停顿 |
| 视锥裁剪 | 屏幕外对象不渲染 | VisibleOnScreenNotifier2D | 减少30-50%渲染 |
| TileMap优化 | 合并静态tile | TileMap层，合并相邻tile | 减少30%+draw call |
| Sprite批处理 | 同材质自动合并batch | Godot默认支持 | GPU调用减少 |
| LOD系统 | 远处物体简化渲染 | 距离检测切换Sprite | 减少渲染复杂度 |
| 粒子限制 | 画质预设限制粒子数 | 低<50/中<100/高<200 | 防止卡顿 |
| 阴影优化 | 仅关键物体投射阴影 | 关闭非关键cast_shadow | 减少阴影计算 |
| 后处理按需 | HDR/模糊默认关闭 | 设置菜单控制 | 减少30%+开销 |

**内存管理**:

| 优化项 | 方法 | 预期效果 |
|--------|------|---------|
| 资源按需加载 | 海域/敌人按需加载 | 初始内存减少50% |
| 纹理压缩 | VRAM压缩(ETC2/S3TC) | 纹理内存减少50% |
| 音频流式加载 | BGM流式，小音效预加载 | 音频内存减少60% |
| 场景卸载 | 离开海域后卸载 | 释放不再使用内存 |
| 避免内存泄漏 | 定期检查未释放资源 | 长时间游玩内存稳定 |

**加载优化**:

| 阶段 | 目标时长 | 方法 |
|------|---------|------|
| 启动阶段 | 0-5秒 | 仅加载核心引擎+主菜单UI |
| 新游戏加载 | 5-15秒 | 异步加载第一海域资源 |
| 场景切换 | 1-3秒 | 异步预加载+淡入淡出 |
| 快速重试 | <2秒 | 仅重置状态，不重新加载 |

使用`ResourceLoader.load_threaded`异步加载，加载界面显示进度条和提示。

**AI优化**:

| 优化项 | 方法 | 预期效果 |
|--------|------|---------|
| AI更新频率分级 | 活跃每帧，远处0.5秒 | CPU减少30-40% |
| AI距离衰减 | 距离越远更新越慢 | 远离区域几乎不消耗 |
| 路径缓存 | 同区域不重复寻路 | 寻路计算减少50% |
| 信号驱动 | 信号替代每帧检查 | 减少无用计算 |
| 波次预计算 | 数据预计算 | 减少运行时计算 |

**音效优化**:

| 优化项 | 方法 | 预期效果 |
|--------|------|---------|
| 音效优先级 | 关键优先，低优先可被覆盖 | 防止重叠过多 |
| 同时播放限制 | 最多16个 | 防止音频系统过载 |
| 音频格式优化 | BGM用OGG，音效用WAV | 减少音频内存 |
| 音效池 | 重复音效实例复用 | 减少实例创建 |

## Formulas

### 内存预算计算

```
total_memory = (
    texture_memory +     # 纹理(压缩后)
    audio_memory +        # 音频(流式+预加载)
    scene_memory +        # 当前场景资源
    script_memory +       # GDScript编译后
    font_memory +         # 字体
    overhead             # Godot引擎开销
)

target: total_memory <= 512 MB (PC高配)
```

### AI更新频率计算

```
update_interval = clamp(
    base_interval * (distance_to_player / update_radius) ^ 2,
    base_interval,
    max_interval
)
# base_interval: 0.016s (每帧, 距离<10m)
# max_interval: 0.5s (距离>50m)
```

### 粒子数量限制

```
max_particles = {
    "low": 50,
    "medium": 100,
    "high": 200,
    "ultra": 400
}
# 超出限制时 oldest particles are recycled
```

### 同时播放音效限制

```
max_concurrent_sounds = 16
# 超出时: 最低优先级音效被停止
```

## Edge Cases

1. **低配PC加载时间超过8秒**: 自动降低画质预设到"低"，显示额外加载提示，不报错。
2. **Steam Deck休眠后恢复画面撕裂**: 恢复后等待1秒重新渲染当前帧，不显示撕裂画面。
3. **主机平台认证失败(TRC/XR)**: 记录失败条目，逐项修复后重新提交。不绕过认证检查。
4. **发布日首日崩溃率>5%**: 暂停营销推广，优先发布首日补丁修复崩溃，社区公告说明情况。
5. **游戏总大小超过2GB目标**: 优先压缩纹理(ETC2)、音频(OGG)、移除未使用资源，不删减内容。
6. **多语言UI溢出**: 最长语言(德语通常最长)作为UI宽度基准，确保所有语言不溢出。
7. **第三方素材许可到期**: 发布前确认所有素材为永久许可或买断许可，无期限限制。
8. **崩溃报告系统收集到敏感数据**: 崩溃报告仅包含堆栈追踪和设备信息，不包含玩家个人信息。
9. **MOD支持(v1.5)与反作弊冲突**: 单机游戏无在线排行，不需要反作弊。MOD仅影响本地游戏。
10. **DLC内容需要主线玩家才能体验**: DLC发布时提供独立购买选项，但不强制购买主线。
