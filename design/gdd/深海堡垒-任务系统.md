## Overview

任务系统通过主线任务（7章36个任务推进剧情）、支线任务（探索/收集/救援/防守/Boss）、日常任务（每日刷新）和隐藏任务链（7条）为玩家提供明确的游戏目标。任务通过自动/NPC/事件/地点/时间五种方式触发，完成后给予资源/蓝图/经验/NPC好感度等奖励。任务追踪系统提供列表/详情/进度提示三级UI，与门锁系统、NPC系统、剧情系统、结局系统深度关联。

---

## Player Fantasy

玩家应感受到：
- **主线推进的史诗感** — 从"建立基础"到"寻找新家园"，7章任务链层层递进，每章解锁新功能/海域
- **分支选择的策略深度** — 第三章海盗冲突可选武力/和平/暗中合作，每条路线奖励和后续不同，选择不可逆
- **隐藏任务的惊喜感** — 浓雾中追击幽灵船、深渊存活30分钟、全船员好感度满，每条隐藏链通向独特奖励
- **进度可视化的安心感** — 任务列表/详情/进度提示三级UI，60%进度、50/100单位，每一步清晰可见

## Detailed Rules

### 任务分类

**主线任务** — 推进剧情，必须完成才能进入下一章，奖励丰厚，解锁新功能/海域。

| 章节 | 章节名 | 任务数 | 核心内容 | 解锁 |
|------|--------|--------|---------|------|
| 第一章 | 启航 | 5个 | 基础建造、第一次下潜、第一次防守 | 基础功能 |
| 第二章 | 深海初探 | 5个 | 深海区探索、遗迹发现、商人接触 | 深海装备 |
| 第三章 | 暗流涌动 | 6个 | 海盗冲突、NPC招募、避难所发现 | 中级科技 |
| 第四章 | 深渊召唤 | 6个 | 深渊区进入、Boss挑战、神秘信号 | 深渊装备 |
| 第五章 | 远古秘密 | 5个 | 遗迹解密、远古文明揭示、信号解读 | 远古科技 |
| 第六章 | 终极威胁 | 5个 | 终极Boss、多线防守、船员考验 | 终极武器 |
| 第七章 | 新家园 | 4个 | 寻找新家园、最终选择、结局 | 游戏结局 |

**支线任务**:

| 任务类型 | 任务目标 | 任务奖励 |
|---------|---------|---------|

| 收集任务 | 收集特定资源 | 资源奖励 |

| 每日击杀 | 每天刷新 | 击杀30个敌人 | 生物样本×5 |

|---------|---------|---------|

### 任务触发机制

| 触发方式 | 说明 | 示例 |
|---------|------|------|
| 自动触发 | 达到条件自动触发 | 航行一定距离触发主线 |
| NPC触发 | NPC发布任务 | 商人NPC发布交易任务 |
| 事件触发 | 特定事件触发 | 发现遗迹触发遗迹任务 |
| 地点触发 | 到达特定位置触发 | 进入深渊区触发深渊任务 |
| 时间触发 | 特定时间触发 | 每日任务刷新 |

**触发条件**:

| 任务类型 | 触发条件 |
|---------|---------|
| 主线任务 | 完成前置主线任务 |
| 支线任务 | 到达特定海域/触发事件 |
| 日常任务 | 每日定时刷新 |
| NPC任务 | 与NPC交互 |

### 任务进度追踪

**任务列表UI**: 分主线/支线/日常三个区域，每个任务显示[进行中/已完成/未解锁]状态和进度条。

**任务详情UI**: 显示任务目标分步骤（1.发现遗迹入口 → 2.进入内部 → 3.探索全部 → 4.挖掘宝藏），每步独立标记完成状态。

**进度提示UI**: 屏幕顶部弹出，显示当前任务进度更新（"遗迹发现 - 探索遗迹全部区域 60%"），3秒后自动消失。

### 任务完成反馈

**完成界面**: 显示任务名、完成统计（探索时间、区域探索率、发现宝藏数）、奖励列表（资源/蓝图/经验值），[领取奖励]按钮。

**完成通知**: 弹出通知"任务已完成，奖励已领取"，提示点击查看下一任务。

### 任务分支设计

第三章"暗流涌动"海盗冲突分支:

```
主线：海盗冲突
├── 分支A：武力解决 → 歼灭海盗舰队 → 获得海盗宝藏，海盗阵营敌对 → 海盗任务线关闭 → 大量金币+海盗装备
├── 分支B：和平谈判 → 与海盗王谈判 → 获得贸易权，海盗阵营友好 → 解锁海盗任务线 → 贸易特权+海盗情报
└── 分支C：暗中合作 → 假意加入海盗 → 获得海盗内部情报 → 双面间谍任务线 → 稀有情报+双重奖励
```

分支影响：影响NPC好感度、后续可用任务、最终结局走向，选择不可逆（需多周目体验不同路线）。

## Formulas

### 任务进度计算

```
progress = completed_objectives / total_objectives
# 收集类: progress = min(1.0, collected / required)
# 探索类: progress = explored_area / total_area
# 防守类: progress = defended_waves / required_waves
# 击杀类: progress = min(1.0, killed / required)
```

### 任务奖励计算

```
reward_amount = base_reward × difficulty_modifier × chapter_modifier

difficulty_modifier:
  easy: 0.8
  normal: 1.0
  hard: 1.5
  nightmare: 2.0

chapter_modifier: 1.0 + (chapter_number - 1) × 0.15
# Ch1: 1.0x, Ch3: 1.3x, Ch5: 1.6x, Ch7: 1.9x
```

### 日常任务刷新

```
daily_reset_time = 04:00 (game time)
on_daily_reset():
    completed_daily_quests.clear()
    generate_new_daily_quests()  # 从每日任务池中随机选取4个
```

## Edge Cases

1. **主线任务与Boss战同时触发**: Boss战优先级更高，主线任务提示延迟到Boss战后显示。
2. **任务目标物品被出售**: 已接任务的目标物品出售时弹出确认"此物品为任务物品，出售后将无法完成任务"。
3. **日常任务刷新时玩家正在执行**: 已接日常任务不受刷新影响，完成后仍可领取奖励，未完成的不消失。
4. **任务分支选择后反悔**: 分支选择不可逆，需多周目体验其他路线。选择前弹出确认弹窗。
5. **隐藏任务触发条件在任务进行中达成**: 隐藏任务立即弹出通知，不打断当前任务流程。
6. **NPC任务发布时NPC已死亡/离开**: 任务不消失，转为"自动触发"类型，任务描述更新为NPC已离开。
7. **任务奖励背包已满**: 奖励存入仓库（非背包），玩家可在仓库查看领取。
8. **多任务共享同一目标**: 如"收集10深海矿"同时是收集任务和日常任务，收集一次两个任务同时更新进度。
9. **任务追踪UI与波次防守UI冲突**: 波次期间任务进度提示暂停，波次结束后恢复。
10. **任务存档与加载**: 任务数据（已接/进行中/已完成/进度/分支选择）全部存入存档系统。

## Tuning Knobs

| 参数 | 当前值 | 安全范围 | 影响 |
|------|--------|---------|------|
| 主线任务总数 | 36个 | 20-50个 | 影响游戏时长 |
| 章节数 | 7章 | 5-10章 | 影响剧情节奏 |
| 每章任务数 | 4-6个 | 3-8个 | 影响章节长度 |
| 日常任务数 | 4个 | 3-6个 | 影响每日活跃度 |
| 隐藏任务链数 | 7条 | 4-12条 | 影响探索深度 |
| 任务奖励经验(主线) | 200 | 100-500 | 影响升级速度 |
| 任务奖励经验(支线) | 50-100 | 30-200 | 影响支线吸引力 |
| 任务进度提示延迟 | 1秒 | 0.5-3秒 | 影响UI流畅度 |
| 任务完成界面停留 | 手动关闭 | 3-10秒自动 | 影响阅读时间 |
| 分支选择确认弹窗 | 必须确认 | 可选跳过 | 影响选择慎重性 |
| 日常任务刷新时间 | 04:00 | 00:00-06:00 | 影响刷新时机 |
| 多任务共享目标 | 支持 | 可选禁用 | 影响效率感 |

## Acceptance Criteria

- [ ] 主线任务7章共36个，每章任务完成后解锁下一章
- [ ] 支线任务包含探索/收集/救援/防守/Boss五种类型
- [ ] 日常任务4种类型每日刷新，完成奖励正确
- [ ] 任务通过自动/NPC/事件/地点/时间五种方式触发
- [ ] 任务列表UI分主线/支线/日常三个区域，显示状态和进度
- [ ] 任务详情UI显示分步骤目标和完成状态
- [ ] 任务完成时显示完成界面（统计+奖励），点击领取奖励
- [ ] 第三章海盗冲突有3个分支选择（武力/和平/合作），选择不可逆
- [ ] 7条隐藏任务链各有独立触发条件和奖励
- [ ] 任务奖励包含资源/蓝图/经验值/NPC好感度
- [ ] 任务进度数据存入存档系统（已接/进行中/已完成/进度/分支）
- [ ] 多任务共享同一目标时，收集一次所有任务同时更新
- [ ] 任务分支选择前弹出确认弹窗
- [ ] 任务奖励背包已满时存入仓库
- [ ] 波次防守期间任务进度提示暂停
