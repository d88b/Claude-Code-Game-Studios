## Overview

怪物进化系统为特定怪物类型提供3阶段进化路径（普通→强化→精英→Boss级），通过5种触发机制（击杀次数/存活时间/资源接触/环境适应/事件触发）驱动动态难度提升。进化后怪物能力增强（攻击力/护甲/速度/视野递增）、外观变化（体型增大20%/50%/100%、颜色变化、特效增加）、获得新特殊能力（隐形/追击/召唤/再生/分裂），掉落价值同步提升（+50%/+100%/+200%）。系统为长期游玩提供自适应挑战，体现游戏进度深度。

---

## Player Fantasy

玩家应感受到：
- **动态升级的挑战感** — 击杀同种怪物多次后，新出现的更强变种迫使玩家升级装备和策略
- **进化的视觉震撼** — 体型从+20%到+100%的递增变化，从基础颜色到发光Boss特效的视觉冲击
- **高风险高回报的抉择** — 进化怪物更难击杀但掉落稀有蓝图和终极材料，值得冒险挑战
- **长期进化的成就感** — 从最初只能打普通鱼群到最终击败Boss级鱼群王，见证自己与怪物同步成长

## Detailed Rules

### 进化阶段

| 阶段 | 能力倍数 | 体型变化 | 颜色变化 | 特效 |
|------|---------|---------|---------|------|
| 普通 | 1.0x | 基础 | 基础颜色 | 无特效 |
| 强化 | 1.5x | +20% | 略变化 | 初级发光 |
| 精英 | 2.0x | +50% | 显著变化 | 中级发光+光环 |
| Boss级 | 3.0x+ | +100% | 极显著变化 | Boss发光+特效+变异 |

### 5种进化触发机制

**1. 击杀次数进化** - 记录玩家击杀每种怪物的次数，达标后新出现的同类型怪物进化。

| 怪物类型 | 击杀条件 | 进化结果 |
|---------|---------|---------|
| 小型怪物 | 击杀50次 | 强化小型怪物 |
| 中型怪物 | 击杀30次 | 强化中型怪物 |
| 大型怪物 | 击杀20次 | 强化大型怪物 |

**2. 存活时间进化** - 怪物在场景中存活计时，超时自动进化，活跃攻击的怪物进化更快（加速系数1.5x）。

| 怪物类型 | 存活条件 | 进化结果 |
|---------|---------|---------|
| 小型怪物 | 存活10分钟 | 强化小型怪物 |
| 中型怪物 | 存活15分钟 | 强化中型怪物 |
| 大型怪物 | 存活20分钟 | 强化大型怪物 |

**3. 资源进化** - 怪物接触特殊资源区域后吸收能量进化。

| 资源类型 | 接触条件 | 进化结果 |
|---------|---------|---------|
| 深海矿 | 接触深海矿区域 | 深海强化怪物 |
| 深渊矿 | 接触深渊矿区域 | 深渊强化怪物 |
| 元素矿 | 接触元素矿区域 | 元素强化怪物 |
| 病毒样本 | 接触病毒区域 | 病毒变异怪物 |
| 融合样本 | 接触融合区域 | 融合怪物 |

**4. 环境进化** - 怪物进入特殊环境后适应进化。

| 环境类型 | 环境条件 | 进化结果 |
|---------|---------|---------|
| 深海 | 进入深海区 | 深海强化怪物 |
| 深渊 | 进入深渊区 | 深渊强化怪物 |
| 火山 | 进入火山区 | 火山强化怪物 |
| 冰区 | 进入冰区 | 冰强化怪物 |
| 遗迹 | 进入遗迹区 | 遗迹强化怪物 |

**5. 事件进化** - 特殊世界事件期间怪物获得事件能力进化。

| 事件类型 | 事件条件 | 进化结果 |
|---------|---------|---------|
| 风暴 | 风暴期间 | 风暴强化怪物 |
| 海啸 | 海啸期间 | 海啸强化怪物 |
| 极寒 | 极寒期间 | 极寒强化怪物 |
| 极热 | 极热期间 | 极热强化怪物 |
| EMP | EMP期间 | EMP强化怪物 |

### 融合进化

| 融合类型 | 融合条件 | 进化结果 |
|---------|---------|---------|
| 双怪物融合 | 两个同类怪物接触 | 融合强化怪物 |
| 三怪物融合 | 三个同类怪物接触 | 融合精英怪物 |
| 多怪物融合 | 多个同类怪物接触 | 融合Boss级怪物 |

融合后能力叠加（取最大值+20%额外加成），体型显著增大。

### 可进化怪物类型

| 怪物类型 | 可进化 | 进化路径 |
|---------|-------|---------|
| 鱼群 | ✅ | 鱼群→强化鱼群→精英鱼群→Boss鱼群王 |
| 鲨鱼 | ✅ | 鲨鱼→强化鲨鱼→精英鲨鱼→Boss鲨王 |

### 掉落价值

| 阶段 | 掉落类型 | 价值加成 | 稀有物品概率 | Boss物品概率 |
|------|---------|---------|-------------|-------------|
| 普通 | 基础材料/普通样本 | 1.0x | 5% | 0% |
| 强化 | 强化材料/强化样本 | 1.5x | 20% | 0% |
| 精英 | 精英材料/样本+稀有蓝图 | 2.0x | 50% | 10% |
| Boss级 | Boss蓝图+终极材料 | 3.0x | 80% | 30% |

### 进化冷却与限制

- 每种怪物最多进化3次（普通→强化→精英→Boss）
- 进化后有冷却时间（30秒），冷却期内不再进化
- 某些进化只能在特定区域触发（如深海进化仅深海区）
- 已进化怪物死亡后不保留进化状态，新生成的怪物重新计算

### UI显示

- **进化状态图标**：怪物血条旁显示进化等级图标（普通/强化/精英/Boss）
- **进化进度条**：击杀次数/存活时间进度可视化
- **进化预警**：怪物即将进化时发出警告提示
- **进化动画**：进化发生时播放变身动画（3秒）
- **进化记录**：记录每种怪物的进化历史，可在图鉴中查看

Godot实现：使用`Resource`配置每种怪物的进化参数，`Timer`追踪存活时间，`Signal`触发进化事件，`Tween`做体型/颜色渐变动画。

## Formulas

### 进化条件检查

```
func check_evolution(monster_data):
    # 1. 击杀次数检查
    if kill_count[monster_data.type] >= monster_data.kill_threshold:
        return true, "kill_count"

    # 2. 存活时间检查（活跃攻击加速1.5x）
    effective_time = alive_time * (1.5 if is_aggressive else 1.0)
    if effective_time >= monster_data.time_threshold:
        return true, "time"

    # 3. 资源接触检查
    if monster_data.current_zone in evolution_zones:
        return true, "resource"

    # 4. 环境进化检查
    if monster_data.current_environment == monster_data.evolution_environment:
        return true, "environment"

    # 5. 事件进化检查
    if current_world_event == monster_data.evolution_event:
        return true, "event"

    return false, null
```

```
stat_multipliers = {
```

## Edge Cases

1. **进化过程中怪物被击杀**: 进化动画中断，怪物死亡。掉落按"进化前"阶段计算（未完成进化）。
2. **多种进化条件同时满足**: 优先级：融合进化 > 事件进化 > 环境进化 > 资源进化 > 击杀次数 > 存活时间。只触发最高优先级的一种。
3. **Boss级怪物再次满足进化条件**: Boss级为最高阶段，不再进化。进化条件检查在Boss级返回false。
4. **融合进化时参与融合的怪物被玩家打断**: 融合过程需要3秒引导，被打断则融合失败，参与融合的怪物各自进入30秒冷却。
5. **进化怪物离开触发进化的区域**: 进化一旦开始不可中断，完成进化。但如果是环境进化且怪物离开该区域，进化暂停（不累积进度）。
6. **击杀计数器在进化后是否重置**: 击杀计数器不重置（追踪的是玩家总击杀数），但新怪物从普通开始，满足条件后再次进化。这意味着如果玩家击杀了50只小型怪物，之后每只新出现的小型怪物都是强化版。
7. **存档加载后进化状态丢失**: 存档中保存每种怪物的`kill_count`和`evolution_stage`。已进化怪物保存其当前阶段，击杀计数器持久化。
8. **不可进化怪物误触进化条件**: 不可进化怪物列表硬编码，`can_evolve`字段为false的怪物跳过所有进化检查。
9. **进化动画期间玩家切换目标**: 进化动画不影响战斗，玩家可继续攻击进化中的怪物。怪物在动画期间处于"易伤"状态（护甲-50%）。
10. **多怪物融合导致性能问题**: 融合进化限制最多5个怪物参与。融合后怪物数量减少，实际上改善性能。融合动画使用粒子特效，限制同时播放数量≤2。

## Acceptance Criteria

- [ ] 3阶段进化路径（普通→强化→精英→Boss级）正确工作
- [ ] 5种进化触发机制（击杀次数/存活时间/资源/环境/事件）独立触发
- [ ] 击杀次数计数器正确累加，达标后新怪物进化
- [ ] 存活时间计时正确，活跃攻击怪物1.5x加速
- [ ] 融合进化：2/3/多个同类怪物接触后融合，能力=max*1.2
- [ ] 可进化怪物（鱼群/鲨鱼/章鱼/螃蟹/水母）各有完整进化路径
- [ ] 不可进化怪物（幽灵/亡灵/元素/遗迹Boss/深渊Boss）不触发进化
- [ ] 基础能力增强：攻击力1.0→1.5→2.0→3.0x，护甲/速度/视野/氧气消耗正确

- [ ] 进化动画3秒，使用Tween平滑过渡，期间护甲-50%
- [ ] 多种条件同时满足时按优先级触发（融合>事件>环境>资源>击杀>存活）
