## Overview

玩家成长系统管理等级系统（1-50级）、30节点科技树、技能树和45个成就系统。玩家通过收集资源、击败敌人、完成任务和防守波次获取经验值和研究点数，逐步解锁新设施、武器、潜艇升级和海域。科技树分为建造/武器/探索/生存四大分支，技能树分为战斗/探索/生存三大分支，成就系统覆盖探索/战斗/建造/收集/特殊五个分类。

---

## Player Fantasy

玩家应感受到：
- **等级提升的持续正反馈** — 每次升级都有HP+5、体力+3的属性提升，每5/10/15级有明确的里程碑奖励
- **科技树解锁的策略选择** — 先升武器还是先升防御？四大分支让每个玩家有不同的科技路线
- **技能树个性化定制** — 暴击流、探索流、生存流，技能点有限迫使玩家做出有意义的选择
- **成就系统的收集驱动** — 45个成就从🥉铜牌到💎钻石难度，"深海传说"成就需完成全部44个成就后解锁

## Formulas

### 升级所需经验值

```
# 线性递增公式
exp_to_next_level = base_exp + (current_level - 1) × exp_increment

base_exp = 100
exp_increment = 20

# 示例:
Lv1→Lv2: 100 EXP
Lv2→Lv3: 120 EXP
Lv10→Lv11: 100 + 9×20 = 280 EXP
Lv50: 总需经验 = Σ(100 + (i-1)×20) for i=1 to 49 = 100×49 + 20×(0+1+...+48) = 4900 + 20×1176 = 28,420 EXP
```

### 科技解锁判定

```
can_research(tech) = has_prerequisites(tech) AND has_enough_points(tech)

has_prerequisites = 所有前置科技节点已解锁
has_enough_points = 当前研究点数 >= 所需研究点数
```

### 技能效果计算

```
final_crit_rate = base_crit_rate + skill_level × 5%   # 最大25%
final_damage = base_damage × (1 + skill_level × 10%)  # 最大+30%
final_move_speed = base_speed × (1 + skill_level × 10%)  # 最大+30%
final_scan_range = base_range × (1 + skill_level × 20%)  # 最大+60%
final_oxygen_consumption = base_consumption × (1 - skill_level × 10%)  # 最大-30%
```

### 成就检查

```
check_achievement(achievement):
    if condition_met(achievement) AND not unlocked(achievement):
        unlock(achievement)
        grant_reward(achievement)  # EXP + 技能点
        show_notification(achievement)
```

## Edge Cases

1. **科技树前置条件循环依赖**: 科技A需要科技B，科技B需要科技A — 使用拓扑排序验证，生成阶段检测，如有循环则回退。
2. **技能点超额使用**: 玩家打开技能树后分配了技能点但未确认，关闭技能树时未确认的分配不生效。
3. **等级50满级后经验处理**: 达到50级后继续获得的经验值不丢失，显示"已满级"但经验条继续累积（用于成就计数）。
4. **科技研究进行中被中断**: 研究进行中海域切换或船只受损，研究进度不中断，继续计时。
5. **成就条件瞬间满足**: 如"30秒内消灭一波敌人"，在最后一秒完成击杀时成就仍应触发，需要精确计时判定。
6. **深海传说成就（45号）**: 需完成前44个成就后自动解锁，前44个成就完成时立即检查并解锁。
7. **科技点数负数**: 如果某个效果消耗研究点数但玩家点数不足，科技解锁拒绝，不会变成负数。
8. **多分支科技同时研究**: 玩家可同时研究不同分支的科技（如同时研究建造和探索），但每个研究槽位独立计时。
9. **和平主义者成就（44号）与Boss战**: "不主动攻击"包括不攻击任何敌人，但Boss战中自卫反击是否算"主动攻击"需明确定义 — 被攻击后反击不算主动攻击。
10. **新游戏+保留成长进度**: 新游戏+模式保留等级和科技树进度，但技能点和成就可重新获取。

## Acceptance Criteria

- [ ] Lv1→Lv2需要100 EXP，Lv2→Lv3需要120 EXP，公式 = 100 + (level-1) × 20
- [ ] 每级提升HP+5、体力+3
- [ ] 5级解锁新设施类型，10级解锁新武器类型，20级解锁新海域
- [ ] 科技树30个节点完整可追溯，每个节点有明确的前置条件、研究点数和效果
- [ ] "终极武器"科技需要前置"武器强化"+"深渊探索"，研究点数500
- [ ] 技能暴击率最大5级共+25%，伤害加成最大3级共+30%
- [ ] 技能点每升1级获得1点，完成任务获得1-3点
- [ ] 45个成就覆盖5个分类（探索10、战斗10、建造10、收集10、特殊5）
- [ ] "深海传说"成就在完成前44个成就后自动解锁，奖励5000 EXP + 20技能点
- [ ] 成就解锁时显示通知（成就名称、图标、条件、奖励）
- [ ] 所有成长参数（经验值公式、科技树节点、技能效果、成就条件）可通过配置文件调整，无需修改代码
