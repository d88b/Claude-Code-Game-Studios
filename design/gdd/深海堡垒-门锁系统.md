## Overview

门锁系统作为游戏目标系统的核心组件，管理门状态变化（锁定→半完成→解锁→打开）、钥匙解锁机制、多类型锁（钥匙锁/密码锁/机关锁/等级锁/NPC锁/时间锁/Boss锁）、多层门关卡结构（入口门→核心门→Boss门→隐藏门）、门附近UI提示、视觉/音效反馈和通关成功后的存档清理。使用Godot BaseLock基类+子类继承架构，KeyManager单例管理钥匙库存，DoorStateMachine管理门状态流转。

---

## Player Fantasy

玩家应感受到：
- **目标明确的目标感** — 门作为清晰可见的终点，钥匙进度0/3→3/3，门灯红→黄→绿，每一步进展可视化
- **解锁瞬间的成就感** — 钥匙集齐时门灯变绿+悦耳嗡鸣+DOOR_UNLOCK音效，按E后门旋转90°打开
- **多类型锁的解谜深度** — 密码锁拨盘推理、机关锁顺序触发、时间锁等待特定时刻，每种锁带来不同挑战
- **隐藏门发现的惊喜感** — 墙壁裂缝、水压异常、声波共振、光影折射，隐藏门通向稀有资源

## Detailed Rules

### 门状态分类

| 状态 | 说明 | 视觉标识 |
|------|------|---------|
| **LOCKED** | 钥匙不足，无法打开 | 红色锁定灯(1.0, 0.3, 0.3) |
| **PARTIAL** | 钥匙部分收集 | 黄色/红色灯（亮度随进度增加） |
| **UNLOCKED** | 钥匙足够，可打开 | 绿色解锁灯(0.3, 1.0, 0.3) |
| **OPENING** | 正在打开 | 门旋转动画中 |
| **OPEN** | 门已打开，通关成功 | 门旋转90°完成 |
| **CLOSING** | 正在关闭 | 门关闭动画（时间锁用） |

### 钥匙收集机制

| 参数 | 值 | 说明 |
|------|-----|------|
| 所需钥匙数 | 3把 | required_keys |
| 已收集钥匙 | keys_collected | 动态增加 |
| 钥匙唯一标识 | key_id | 每把钥匙有ID |

**收集流程**: 玩家拾取钥匙 → 发送key_collected信号 → KeyManager记录 → 门接收信号 → keys_collected++ → 更新门灯颜色 → 更新钥匙进度条 → 检查是否解锁。

### 门状态变化规则

| 钥匙进度 | 门状态 | 门灯颜色 | 亮度 |
|---------|--------|---------|------|
| 0/3 | LOCKED | 红色(1.0, 0.3, 0.3) | 0.5 |
| 1/3 | PARTIAL | 红色（亮度增加） | 0.83 |
| 2/3 | PARTIAL | 黄色(1.0, 1.0, 0.3) | 1.17 |
| 3/3 | UNLOCKED | 绿色(0.3, 1.0, 0.3) | 1.5 |

**亮度公式**: `亮度 = 0.5 + (keys_collected / required_keys) × 1.0`

### 开门机制

**触发条件**: 玩家靠近门(player_in_range=true) + 门已解锁(door_locked=false) + 玩家按E键。

**开门流程**: 按E → try_open_door() → 检查门状态 → 解锁 → open_door() → 播放DOOR_OPEN音效(音量1.0) → Tween旋转动画(Y轴0→PI/2, 0.5秒) → 发送game_completed信号 → 通关成功。

**门尺寸**: 宽度2.5m，高度3.0m，厚度0.3m，交互范围3.0m。

### 门附近提示系统

| 状态 | 提示内容 | 状态标签 |
|------|---------|---------|
| 锁定 | "需要3把钥匙（已收集: X）" | LOCKED（红色） |
| 解锁 | "[E] 打开门 - 逃脱!" | EXIT（绿色） |

**UI位置**: 提示框在屏幕下方(anchor_top: 0.75)，状态标签在anchor_top: 0.6。

### 锁定尝试反馈

玩家钥匙不足时按E → try_open_door()返回false → 播放DOOR_LOCKED音效(音量0.6) → 提示"需要钥匙"。

### 通关成功与存档清理

门打开 → emit_signal("game_completed") → GameManager接收 → game_victory触发 → 游戏暂停 → 显示胜利界面 → SaveManager.delete()删除存档 → 鼓励重新挑战。

### 多类型锁系统

| 锁类型 | 解锁方式 | 应用场景 | 主色调 | 解锁音效 |
|--------|---------|---------|--------|---------|
| **钥匙锁** | 收集N把钥匙 | 关卡出口门 | 红→黄→绿 | 咔嗒机械声 |
| **密码锁** | 破解/找密码线索 | 宝箱、隐藏门 | 紫色 | 电子滴滴声 |
| **机关锁** | 按顺序触发机关 | 遗迹内部、隐藏区域 | 橙色 | 齿轮+水声 |
| **等级锁** | 达到等级/科技条件 | 深渊区入口、高级区域 | 蓝色 | 能量嗡嗡声 |
| **NPC锁** | NPC好感度达标 | NPC区域、避难所 | 粉色 | 温暖叮当声 |
| **时间锁** | 日夜系统特定时段 | 特殊事件、隐藏区域 | 青色 | 潮汐+钟声 |
| **Boss锁** | 击败指定Boss | Boss区域奖励门 | 暗红色 | 爆炸+锁链断裂 |

### 密码锁详细设计

| 参数 | 值 | 说明 |
|------|-----|------|
| 密码长度 | 3-5位 | 随难度递增 |
| 字符集 | 数字/符号 | 水下主题符号系统 |
| 线索散布 | 3个线索 | 分布在关卡各处 |
| 尝试次数限制 | 无/有（困难模式） | 可选 |

**密码获取**: 探索关卡 → 发现线索1（墙壁涂鸦）→ 线索2（NPC日记）→ 线索3（石碑刻文）→ 拼凑密码 → 输入 → 正确解锁/错误提示。

**密码输入界面**: 圆形拨盘（类似潜水仪表），鼠标滚轮/方向键调整每位数字，错误反馈：仪表震动+红色闪烁。

### 机关锁详细设计

| 参数 | 值 | 说明 |
|------|-----|------|
| 机关数量 | 3-5个 | 随难度递增 |
| 触发顺序 | 特定顺序 | 需玩家推理 |
| 触发间隔 | 5秒内 | 超时重置 |
| 重置机制 | 全部重触发 | 顺序错误时重置 |

**机关类型**:

| 机关 | 触发方式 | 视觉反馈 |
|------|---------|---------|
| 压力板 | 玩家/物体站上去 | 下沉+发光 |
| 拉杆 | 交互键触发 | 拉下+齿轮转动声 |
| 水晶柱 | 射击/碰撞 | 变色+能量波纹 |
| 转盘 | 旋转到特定角度 | 咔嗒声+定位标记 |

**失败反馈**: 机关全部变红+闪烁 → 齿轮卡住声+警报声 → 机关回退初始位置 → 短暂锁定3秒 → "顺序错误，机关重置"。

### 等级锁详细设计

| 参数 | 值 | 说明 |
|------|-----|------|
| 所需等级 | 设定等级阈值 | 玩家等级达到即可 |
| 科技要求 | 特定科技解锁 | 如"深潜装备Lv2" |
| 自动检测 | 进入范围时检测 | 无需手动触发 |
| 视觉标识 | 等级数字显示 | 门上标注所需等级 |

**行为**: 等级不足→门显示红色+所需等级数字；等级达到→自动变为绿色+解锁动画；科技升级→门实时响应自动解锁。

### NPC锁详细设计

| 参数 | 值 | 说明 |
|------|-----|------|
| 好感度阈值 | 50/100 | 中等好感度 |
| 好感获取 | 完成任务/赠送物品 | 多种方式提升 |
| NPC类型 | 固定NPC | 每区域1-2个 |
| 开门方式 | NPC直接开门/给钥匙 | 两种解锁方式 |

### 时间锁详细设计

| 参数 | 值 | 说明 |
|------|-----|------|
| 开放时段 | 夜间/日间 | 基于日夜系统 |
| 持续时间 | 游戏内2小时 | 时段持续时长 |
| 倒计时显示 | UI显示剩余时间 | 紧迫感 |
| 锁定动画 | 时段结束自动锁 | 门关闭动画 |

**行为**: 时段未到→门紧闭+锁图标+时段标识；时段到达→门自动解锁+绿色光芒；时段结束→门重新锁定（如玩家未通过）。

### Boss锁详细设计

| 参数 | 值 | 说明 |
|------|-----|------|
| 关联Boss | 指定Boss ID | 击败后解锁 |
| Boss状态检测 | 实时检测 | 击败即解锁 |
| 奖励门 | 隐藏奖励区域 | 非通关必需 |
| Boss标记 | 门上显示Boss形象 | 提示需击败的Boss |

### 多层门关卡结构

| 层级 | 门类型 | 钥匙需求 | 额外条件 | 到达区域 | 难度 |
|------|--------|---------|---------|---------|------|
| 第1层门 | 入口门 | 1把钥匙 | 无 | 进入关卡主区域 | 简单 |
| 第2层门 | 核心门 | 3把钥匙 | 无 | 进入核心区域 | 中等 |
| 第3层门 | Boss门 | 5把钥匙 | 击败Boss/完成任务 | Boss区域/最终奖励 | 困难 |
| 隐藏门 | 秘密门 | 特殊条件 | 破解密码/机关/好感度 | 隐藏区域/稀有资源 | 可变 |

### 隐藏门触发条件

| 类型 | 发现方式 | 解锁方式 |
|------|---------|---------|
| 墙壁裂缝 | 靠近时可见裂缝 | 攻击/交互 |
| 水压异常 | 气泡异常聚集 | 特定位置射击 |
| 声波共振 | 气泡异常聚集 | 使用声呐设备 |
| 光影折射 | 特定角度光线照射 | 调整光源方向 |

### Godot实现架构

**BaseLock基类**: 锁的通用逻辑，包含lock_unlocked/lock_progress_changed/lock_failed信号，try_unlock()通用流程，_update_visual_state()视觉更新，add_progress()进度增加。

**KeyManager单例**: 钥匙库存管理(Dict存储)，key_collected/key_count_changed信号，add_key/remove_key/has_key/get_key_count接口。

**DoorStateMachine**: LOCKED→PARTIAL→UNLOCKED→OPENING→OPEN→CLOSING状态流转，on_key_collected()进度更新，try_open()开门检测，_play_opening_animation()使用Tween实现旋转。

## Formulas

### 门灯亮度

```
brightness = 0.5 + (keys_collected / required_keys) * 1.0
# 0/3: 0.5, 1/3: 0.83, 2/3: 1.17, 3/3: 1.5
```

### 机关锁超时判定

```
trigger_timer = 0
on_mechanism_triggered(id):
    triggered_order.append(id)
    trigger_timer = 0

each_frame:
    if triggered_order.size() > 0 and not is_unlocked:
        trigger_timer += delta_time
        if trigger_timer >= 5.0:
            triggered_order.clear()
            lock_failed.emit("超时重置")
```

### 密码锁验证

```
is_correct = (current_input == password)
if is_correct:
    try_unlock()
else:
    play_error_feedback()  # 红色闪烁3次 + 错误蜂鸣
```

### 时间锁时段判定

```
current_hour = get_current_game_hour()
if open_period_start <= current_hour < open_period_end:
    try_auto_unlock()
elif is_unlocked and current_hour >= open_period_end:
    relock()  # 时段结束重新锁定
```

## Edge Cases

1. **钥匙收集完成但玩家不按E开门**: 门保持UNLOCKED状态，绿色灯光持续，提示持续显示"[E] 打开门"，门不会自动打开。
2. **时间锁时段结束时玩家仍在门内**: 门执行CLOSING动画并将玩家推出门外（碰撞体重新激活），避免玩家被困。
3. **机关锁超时后玩家立即重新触发**: 机关回退到初始位置后有0.5秒冷却，防止连续快速触发导致逻辑混乱。
4. **密码锁错误尝试后快速重新输入**: 错误反馈（红色闪烁3次）期间允许重新输入，不锁定输入。
5. **Boss锁关联的Boss被远程击杀**: Boss锁实时检测Boss死亡信号，即使玩家不在Boss锁附近也立即解锁。
6. **NPC锁NPC死亡或离开**: NPC锁保持锁定状态，提示改为"NPC已离开，寻找其他方式"。
7. **等级锁玩家等级反复波动**: _process每帧检测，等级达到自动解锁，等级降低不重新锁定（已解锁保持）。
8. **多层门同时被解锁**: 每扇门独立管理状态，解锁事件不互相干扰，但UI提示按距离玩家最近的门优先显示。
9. **通关后存档删除失败**: SaveManager.delete()返回失败时重试3次，仍失败则标记存档为"completed"状态防止重复加载。
10. **隐藏门与普通墙壁混淆**: 隐藏门有细微视觉差异（纹理不同、微弱光线），声呐探测可标记隐藏门位置。
