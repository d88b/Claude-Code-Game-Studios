## Overview

难度曲线系统管理4种预设难度（简单/普通/困难/深渊）的30+维度参数配置、14参数自定义难度滑块系统、动态难度调整（DDA）、难度解锁条件、难度与结局关联、9海域难度递增和科技路线推荐。系统通过`DifficultyConfig` Resource类实现数据驱动，支持简单70%敌人伤害+120%资源到深渊150%敌人伤害+60%资源的极端对比。自定义难度可保存5套配置并导出分享。DDA系统根据玩家表现自动微调（敌人伤害±15%上限），简单/普通默认开启，困难/深渊默认关闭。

---

## Player Fantasy

玩家应感受到：
- **难度的透明选择** — 绿色(简单)/蓝色(普通)/橙色(困难)/红色(深渊)颜色标识，30维参数清晰对比，知道选了什么
- **动态调整的贴心感** — 连续失败3次自动降低敌人伤害5%，弹窗通知"已微调难度"，可在设置中关闭
- **自定义难度的自由度** — 14个参数独立调节，保存5套配置，以预设为基础微调
- **多周目递进的挑战** — 通关后解锁更高难度，困难/深渊不仅是数值提升，还有Boss额外阶段和AI协作增强

### 动态难度调整（DDA）

| 触发条件 | 判定标准 | 调整方向 |
|---------|---------|---------|
| 连续失败3次 | 同一波次连续失败3次 | 敌人伤害-5% |
| 波次无伤完成 | 连续2波无伤 | 敌人伤害+5% |
| Boss速杀 | 50%时间内击败Boss | 下次Boss难度+5% |
| 资源溢出 | 资源超上限80%达3阶段 | 资源获取-5% |
| 死亡过多 | 累计死亡5次 | 敌人伤害-10% |
| 教程反复失败 | 同一教程步骤失败3次 | 提供更详细提示 |

**DDA调整上限**:

| 参数 | 最大下调 | 最大上调 |
|------|---------|---------|
| 敌人伤害 | -15% | +15% |
| 敌人数量 | -10% | +10% |
| 资源获取 | +15% | -15% |
| Boss血量 | -10% | +10% |

DDA默认状态：简单/普通开启，困难/深渊关闭。可在设置中关闭或调整幅度（保守/标准/激进）。

### Godot实现

`DifficultyConfig` Resource类包含30+参数（战斗/资源/消耗/系统/AI/UI分组），4种预设通过`.tres`文件配置。`DifficultyManager`单例管理当前难度、DDA调整、自定义难度，提供`apply_enemy_stats()`/`get_resource_multiplier()`等方法。难度切换通过`difficulty_changed`信号通知全系统。

## Formulas

### 难度参数计算

```
# 最终乘数 = 预设基础值 + DDA调整值（如有）
final_enemy_damage = base_enemy_damage * (preset_multiplier + dda_adjustment)
# dda_adjustment 范围: -0.15 ~ +0.15 (敌人伤害)

# 示例: 普通难度敌人伤害100%，DDA下调10%
# final = 1.0 + (-0.10) = 0.90 → 敌人伤害90%
```

### 自定义难度等效评级

```
# 计算自定义配置的等效预设
avg_multiplier = (
    enemy_strength + enemy_count + (200 - resource_gain) +
    oxygen_consumption + repair_cost
) / 5.0

if avg_multiplier < 75%:    rating = "简单"
elif avg_multiplier < 110%: rating = "普通"
elif avg_multiplier < 140%: rating = "困难"
else:                       rating = "深渊"
```

### DDA触发与调整

```
# 连续失败检测
if consecutive_failures[wave_id] >= 3:
    apply_dynamic_adjustment("enemy_damage", -0.05)

# 上限检查
def get_param_min(param):
    match param:
        "enemy_damage": return -0.15
        "enemy_count":  return -0.10
        "resource_gain": return 0.0
        _: return -0.15

def get_param_max(param):
    match param:
        "enemy_damage": return +0.15
        "enemy_count":  return +0.10
        "resource_gain": return +0.15
        _: return +0.15

dda_adjustments[param] = clamp(current + delta, min_val, max_val)
```

### 海域难度平滑过渡

```
# 海域间难度增幅控制在合理范围
area_difficulty[i] = base_multiplier * area_scaling[i]
# area_scaling: [0.8, 1.0, 1.2, 1.5, 1.8, 2.0, 2.5, 2.8, 3.0]
# 增幅: [+25%, +20%, +25%, +20%, +11%, +25%, +12%, +7%]
```

### 通关时间预估

```
estimated_clear_time = {
    "easy":   {"hours": 7,  "deaths": 3,  "boss_attempts": 2},
    "normal": {"hours": 10, "deaths": 7,  "boss_attempts": 3},
```

## Edge Cases

1. **DDA与预设难度叠加导致参数超出预期**: DDA调整有硬性上限（敌人伤害±15%），不会超出安全范围。DDA通知弹窗显示调整后的实际值。
2. **自定义难度保存后被删除**: 删除配置时检查是否有存档正在使用该配置。如有，弹出确认"删除后当前游戏将使用基础参数替代"。
3. **难度切换时游戏正在进行**: 简单→任意难度随时可切换无惩罚。困难/深渊→简单需确认并标记"降低了难度"，成就标记"含难度调整"。切换立即生效，不需要重启。
4. **Boss阶段数在不同难度不同（简单2阶段/深渊5阶段）**: BossStateMachine从DifficultyConfig读取`boss_phase_count`，动态生成阶段阈值。简单难度跳过P3/P4直接P1→P2→狂暴。
5. **难度解锁条件检测（通关判定）**: 存档中标记`completed_normal`/`completed_hard`。通关判定以最终结局为准（悲剧沉没不算通关）。
6. **自定义难度滑块调节后等效评级仍为"普通"但个别参数极端**: 等效评级仅为参考，不代表实际体验。极端组合（如敌人200%+资源50%）可能导致实际体验远超深渊，系统不限制但提示"自定义难度可能极不均衡"。
7. **DDA通知弹窗遮挡关键UI**: DDA通知显示2秒后自动消失，不暂停游戏。可设置为"静音"（记录调整但不显示通知）。
8. **海域难度递增与玩家等级不匹配**: 海域有推荐等级但不强制。玩家可在低等级进入高难度海域（后果自负）。提示"建议等级X，当前等级Y"。
9. **新游戏+继承后难度参数冲突**: 新游戏+保留科技但不保留难度设置。玩家需要重新选择难度。已解锁的高难度仍然可选。
10. **自定义难度配置导入格式不兼容**: 提示"配置文件格式不兼容"，不覆盖当前配置。提供格式说明链接。
