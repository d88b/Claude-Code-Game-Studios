## Overview

氧气能源系统管理潜艇探索时的氧气和能源双资源管理机制，包括消耗计算、补充方式、多级警告系统、氧气耗尽死亡概率、能源耗尽瘫痪后果、携带罐管理、再生装备升级和回船补充。系统通过深度系数、活动系数、环境系数的多维叠加，为深海探索提供紧张感与策略性权衡。

---

## Player Fantasy

玩家应感受到：
- **氧气倒计时带来的生存压迫感** — 氧气持续消耗，深度越深消耗越快，迫使玩家在探索与撤退间做决策
- **双资源管理的策略深度** — 氧气决定存活时间，能源决定行动能力，两者需要平衡规划
- **升级后探索能力显著扩展的成长感** — 从Lv1氧气舱100单位到Lv5的500单位，深海探索从不可能变为日常
- **紧急情况下使用氧气罐/能源罐自救的紧张感** — 按键瞬间补充罐容量，生死一线

## Formulas

### 氧气消耗计算

```
氧气消耗 = 基础消耗率 × 深度系数 × 活动系数 × 环境系数 × 时间
```

**示例1：浅水区正常探索（60秒）**
```
消耗 = 1.0 × 1.0(浅水) × 1.0(移动) × 1.0(正常) × 60 = 60 单位
≈ 氧气舱Lv1容量的 60%
```

**示例2：深海区战斗探索（120秒）**
```
消耗 = 2.0 × 1.5(深海) × 2.0(战斗) × 1.2(洞穴) × 120 = 864 单位
≈ 氧气舱Lv3容量的 432%（必须携带氧气罐）
```

**示例3：深渊区冲刺逃跑（30秒）**
```
消耗 = 3.0 × 2.0(深渊) × 1.0(冲刺) × 1.0(正常) × 30 = 180 单位
≈ 氧气舱Lv2容量的 120%
```

### 能源消耗计算

```
能源消耗 = 基础消耗率 × 速度系数 × 设备系数 × 时间
```

**示例：深海区采集深渊矿（72秒）**
```
氧气消耗 = 2 × 1.2(深度系数) × 72 = 172.8 单位
能源消耗 = 1 × 72 = 72 单位
```

### 死亡概率计算

```
死亡概率 = 基础概率 + 深度加成 + 时间加成 - 紧急上浮减免

基础概率: 氧气耗尽即刻开始计算
深度加成: 深度每增加100m，死亡概率+10%
时间加成: 氧气耗尽后每秒等待，死亡概率+5%
紧急上浮减免: 使用紧急上浮，死亡概率-30%
氧气再生减免: 装备氧气再生系统，死亡概率-20%

死亡概率 = clamp(死亡概率, 0%, 100%)
```

### 护甲减免（能源防御相关）

```
护甲减免 = 设施护甲 / (设施护甲 + 50)

无护甲(0): 0%减免
轻度护甲(25): 33%减免
中度护甲(50): 50%减免
重度护甲(100): 67%减免
终极护甲(150): 75%减免
```

## Edge Cases

1. **氧气和能源同时耗尽**: 玩家既无法移动又面临死亡。优先判定氧气耗尽死亡流程，能源瘫痪作为辅助状态。
2. **氧气罐使用但舱未满**: 使用氧气罐时，优先补充舱容量直到满，多余部分不补充罐。
3. **补给点补充时舱和罐都满**: 补给点补充无效，不产生溢出资源。
4. **深渊区紧急上浮失败**: 深渊区(300m+)压力过大，紧急上浮有概率失败，触发无法上浮的死亡概率(70-90%)。
5. **氧气再生器能源耗尽**: 氧气再生器依赖能源运作，能源耗尽时再生停止，即使氧气再生器已安装。
6. **采集中途氧气为0**: 强制紧急上浮，采集进度保留50%，可获得部分资源。
7. **采集中途能源为0**: 采集立即停止，进度丢失，无法获得资源。
8. **战斗激烈时自动存档暂停**: 避免在危险状态下存档，导致玩家加载后处于必死状态。
9. **能源耗尽漂流状态**: 玩家仅能按洋流方向漂流，无法主动操控。洋流方向由关卡系统定义。
10. **多罐同时使用**: 玩家可连续使用多个罐，每次使用消耗一个罐。罐使用后消失。

## Acceptance Criteria

- [ ] 氧气消耗公式 = 基础消耗率 × 深度系数 × 活动系数 × 环境系数 × 时间，计算结果与示例一致
- [ ] 浅水区正常移动60秒消耗60单位氧气（1.0 × 1.0 × 1.0 × 1.0 × 60）
- [ ] 深渊区(300m+)冲刺30秒消耗180单位氧气（3.0 × 2.0 × 1.0 × 1.0 × 30）
- [ ] 氧气条颜色随百分比正确变化：>50%绿色，50-30%黄色，<30%红色
- [ ] 氧气降至30%时显示"氧气危险！请尽快撤退"提示
- [ ] 氧气降至15%时显示"氧气紧急！立即上浮！"提示并播放强烈警报声

- [ ] 氧气耗尽时触发死亡概率计算，深渊区(500m)紧急上浮成功死亡概率≤20%
- [ ] 能源耗尽后潜艇无法移动、无法使用设备、仅能悬停
