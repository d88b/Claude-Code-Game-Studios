## Overview

UI系统管理HUD布局（HP/体力/电量状态栏）、钥匙进度条、交互提示（拾取/门提示）、战斗反馈（ATTACK/HIT指示器）、6种场景HUD变体（航行/探索/战斗/波次/设施管理/Boss战）、暂停菜单、游戏结束/胜利界面和UI状态机。系统通过Godot Control节点树实现分层UI（HUD层/提示层/反馈层/菜单层），使用信号驱动UI更新（health_changed/stamina_changed/key_collected等），所有UI元素锚点定位以适配不同屏幕尺寸。

---

## Player Fantasy

玩家应感受到：
- **状态一目了然** — 左上角HP/体力、右下角电量、中间钥匙进度，关键信息不遮挡游戏画面
- **危机时的视觉警告** — 低血量进度条变红、低电量变红，直觉感受到危险逼近
- **交互引导清晰** — 靠近物品显示"[E] 拾取 电池"（蓝色发光），靠近门显示"需要3把钥匙"或"打开门逃脱"（绿色）
- **战斗反馈即时** — "ATTACK!"（黄色）和"HIT!"（绿色）0.3秒闪现，攻击命中有明确的视觉确认

## Detailed Rules

### UI分层系统

| 层级 | UI类型 | Z-index | 说明 |
|------|--------|---------|------|
| HUD层 | 状态栏、进度条 | 0 | 常驻显示，不遮挡游戏画面 |
| 提示层 | 拾取提示、门提示 | 10 | 临时显示，触发条件激活 |
| 反馈层 | 攻击反馈、命中反馈 | 20 | 短暂显示（0.3-0.5秒） |
| 菜单层 | 暂停菜单、设置菜单 | 100 | 全屏覆盖，暂停游戏 |

### 状态栏详细设计

**HP状态栏**:

| 属性 | 值 |

| 高度 | 20像素 |
| 内容 | HP进度条 + "HP: XX"数值标签 |
| 正常颜色 | 白色 |
| 低血量警告 | HP < 30%时进度条变红色（modulate = Color.RED） |

**体力状态栏**:

| 属性 | 值 |
|------|-----|
| 位置 | HP状态栏上方 |
| 宽度 | 屏幕宽度的25% |
| 高度 | 20像素 |
| 内容 | 体力进度条 + "STAM: XX"数值标签 |

**手电筒状态栏**:

| 属性 | 值 |
|------|-----|

| 高度 | 20像素 |
| 内容 | 电量进度条 + "FLASH: XX%"数值标签 |

### 钥匙进度条

| 属性 | 值 |
|------|-----|
| 位置 | 中下位置 |
| 宽度 | 屏幕宽度的30% |
| 高度 | 20像素 |
| 内容 | 钥匙收集进度 + "钥匙: X/Y"数值标签 |

**颜色渐变规则**:

| 进度 | 颜色 | 说明 |
|------|------|------|
| 0/Y | 红色 | 锁定状态 |
| 1/Y-半完成 | 红色（亮度增加） | 部分收集 |
| 半完成 | 黄色 | 半完成 |
| Y/Y（完成） | 绿色 | 解锁完成 |

### 交互提示UI

**拾取提示框**:

| 属性 | 值 |
|------|-----|
| 触发条件 | 玩家距离物品 < pickup_range（2.5m） |
| 位置 | 屏幕下方（anchor_top: 0.7） |
| 内容 | "[E] 拾取 [物品名称]" |
| 物品名称颜色 | 与物品发光颜色一致（电池=蓝色，医疗包=红色等） |
| 隐藏条件 | 玩家离开pickup_range或拾取后 |

**门提示框**:

| 属性 | 值 |
|------|-----|
| 触发条件 | 玩家距离门 < interact_range（3.0m） |
| 位置 | 屏幕下方（anchor_top: 0.75） |
| 钥匙不足时 | "需要X把钥匙（已收集: Y）" + LOCKED（红色） |
| 钥匙足够时 | "[E] 打开门 - 逃脱!" + EXIT（绿色） |

### 战斗反馈UI

**攻击反馈框**:

| 属性 | 值 |
|------|-----|
| 触发条件 | 玩家攻击或命中敌人 |

| 攻击时 | "ATTACK!"（黄色），显示0.3秒 |

### UI状态机

```
启动画面(Logo+CG)
    ↓
主菜单(新游戏/继续游戏/设置/退出)
    ├──→ 设置菜单(画面/音效/操控/游戏)
    ├──→ Loading界面(进度条+提示)
    │       ↓
    │   教程界面 → 新手引导
    │       ↓
    │   游戏HUD(航行/探索/战斗/波次) ←── ESC暂停菜单
    │       ├──→ 设施管理UI
    │       └──→ 游戏结束界面(死亡/胜利)
    └──→ 结局画面(多结局展示)
```

## Formulas

### 低血量警告颜色切换

```
if hp_ratio < 0.30:
    hp_bar_modulate = Color.RED
    hp_bar_pulse = true  # 呼吸闪烁
else:
    hp_bar_modulate = Color.WHITE
    hp_bar_pulse = false
```

### 低电量警告颜色切换

```
if battery_ratio < 0.20:
    battery_bar_modulate = Color.RED
    battery_bar_pulse = true
else:
    battery_bar_modulate = Color.WHITE
    battery_bar_pulse = false
```

### 钥匙进度颜色渐变

```
key_ratio = keys_collected / keys_required

if key_ratio == 0:
    color = Color(0.8, 0.2, 0.2)  # 暗红
elif key_ratio < 0.5:
    color = Color(1.0, 0.4, 0.2)  # 亮红
elif key_ratio < 1.0:
    color = Color(1.0, 0.8, 0.2)  # 黄色
else:
    color = Color(0.2, 0.8, 0.2)  # 绿色（完成）
```

### 屏幕适配计算

```
# 基于锚点的自适应布局
control.anchor_left = 0.02   # 左侧元素
control.anchor_right = 0.27  # 宽度25%
control.anchor_top = 0.95    # 底部
control.anchor_bottom = 1.0  # 底部边缘

# 进度条填充
progress_bar.value = (current_value / max_value) * 100
```

### 战斗反馈显示时序

```
on_player_attack():
    show_feedback("ATTACK!", color=Color.YELLOW, duration=0.3s)

on_player_hit_enemy():
    show_feedback("HIT!", color=Color.GREEN, duration=0.5s)

# 如果攻击和命中几乎同时发生（<0.1s间隔）
# HIT! 覆盖 ATTACK!，只显示HIT!
```

## Edge Cases

1. **UI元素重叠**: 拾取提示和门提示都在屏幕下方，玩家同时靠近物品和门时，门提示优先显示（anchor_top: 0.75 > 0.7），拾取提示暂时隐藏。
2. **Boss战UI与场景HUD切换**: Boss战开始时隐藏常规探索信息，只显示Boss血条/阶段/弱点/预警。Boss战后恢复原场景HUD。
3. **快速暂停/恢复**: 玩家快速按ESC暂停再恢复，UI层正确隐藏/显示，游戏状态不因UI切换而改变。
4. **屏幕尺寸极端比例**: 超宽屏（21:9）或竖屏（16:10）时，HUD元素基于锚点自动适配，进度条宽度使用屏幕宽度百分比而非固定像素。
5. **信号在节点销毁后触发**: 场景切换时旧UI节点已销毁但信号仍在发送，使用Godot信号连接时设置`CONNECT_DEFERRED`或检查节点`is_inside_tree()`。
6. **战斗反馈快速连续触发**: 短时间内多次攻击/命中，反馈文字不堆叠，最新反馈覆盖旧的，Timer重置。
7. **钥匙进度条钥匙数量变化**: 如果关卡设计中途改变了所需钥匙数量（keys_required），进度条实时更新最大值，颜色按新比例计算。
8. **暂停菜单中游戏时间停止**: 暂停时`get_tree().paused = true`，UI动画（呼吸闪烁、脉冲）不受影响（使用`process_mode = PROCESS_MODE_ALWAYS`）。
9. **游戏结束界面与存档冲突**: 玩家死亡后显示Game Over界面，同时触发存档（退出前保存），加载时从上次自动存档恢复而非死亡状态。
10. **多语言文本适配**: UI文字标签使用TranslationServer翻译，所有文本key化（如`tr("UI_HP_LABEL")`），切换语言时实时更新。

## Tuning Knobs

| 参数 | 当前值 | 安全范围 | 影响 |
|------|--------|---------|------|
| HP进度条宽度 | 屏幕25% | 15-35% | 影响HP信息可见性 |
| 低血量警告阈值 | 30% | 20-50% | 影响警告触发时机 |
| 低电量警告阈值 | 20% | 10-40% | 影响电量警告时机 |
| 进度条高度 | 20px | 15-30px | 影响视觉粗细 |
| HUD层字体大小 | 14px | 12-18px | 影响可读性 |
| 提示层字体大小 | 16px | 14-20px | 影响提示可见性 |
| 菜单层字体大小 | 18px | 16-24px | 影响菜单可读性 |
| ATTACK!显示时长 | 0.3秒 | 0.2-0.5秒 | 影响战斗反馈节奏 |
| HIT!显示时长 | 0.5秒 | 0.3-0.8秒 | 影响命中确认感 |

| 屏幕适配锚点容差 | ±2% | ±1-5% | 影响不同屏幕布局 |

## Acceptance Criteria

- [ ] HUD包含HP状态栏（左下角）、体力状态栏（HP上方）、手电筒状态栏（右下角）、钥匙进度条（中下）
- [ ] HP < 30%时进度条变红色并呼吸闪烁，HP恢复后变回白色
- [ ] 电量 < 20%时进度条变红色并呼吸闪烁，电量恢复后变回白色
- [ ] 钥匙进度条颜色随收集进度变化：0=暗红，半完成=黄色，完成=绿色
- [ ] 玩家靠近物品（<2.5m）显示"[E] 拾取 [物品名称]"提示，物品名称颜色与物品发光颜色一致
- [ ] 玩家靠近门（<3.0m）显示门状态：钥匙不足显示"需要X把钥匙（已收集: Y）"+LOCKED红色，钥匙足够显示"[E] 打开门 - 逃脱!"+EXIT绿色
- [ ] 玩家攻击时显示"ATTACK!"（黄色）0.3秒，命中敌人时显示"HIT!"（绿色）0.5秒
- [ ] 按ESC键显示暂停菜单（继续游戏/设置/退出游戏），游戏暂停
- [ ] 玩家死亡时显示"GAME OVER"（红色大字）+重新开始/退出游戏按钮
- [ ] 通关时显示"逃脱成功！"（绿色大字）+收集钥匙数+重新开始/退出游戏按钮
- [ ] 6种场景HUD变体正确显示/隐藏对应内容（航行/探索/战斗/波次/设施管理/Boss战）
- [ ] UI元素使用锚点定位，在不同屏幕尺寸（16:9/21:9/16:10）下正确适配
- [ ] 所有UI更新通过信号驱动（health_changed/stamina_changed/key_collected等），非每帧轮询
- [ ] 所有UI文本使用TranslationServer翻译key，支持多语言切换
- [ ] 暂停时UI动画（呼吸闪烁）继续运行，使用PROCESS_MODE_ALWAYS
