## Overview

实现补充内容汇总godot-survival-horror-demo项目中已实现的技术细节，作为各系统文档的补充参考，包括敌人多样性设计（追击型/潜伏型）、击退与眩晕机制、资源拾取UI、钥匙收集目标系统、存档系统实现细节、氛围视觉效果（受伤闪烁/低血量脉冲/暗角效果）、音效系统（16种音效分类）、关卡设计参数（墙壁/障碍物）、快捷键映射和AI感知系统（视觉/听觉/特殊感知）及群体AI行为（Flocking/包围/分散/协作）。

## Player Fantasy

玩家应感受到：
- **敌人行为的差异化** — 追击型敌人高速追击不放弃，潜伏型敌人三阶段突袭，每种敌人威胁感不同
- **战斗反馈的物理感** — 击退力度3.0、眩晕2秒，攻击命中有明确的物理反馈
- **氛围视觉的沉浸感** — 受伤时画面闪烁0.3秒、低血量时暗角脉冲增强、边缘红屏警告
- **钥匙收集的目标感** — 从0/3到3/3，门灯从红变绿，进度可视化的满足感

## Detailed Rules

### 敌人多样性

**追击型敌人（Enemy Chaser）**:

| 属性 | 值 | 说明 |
|------|-----|------|
| 移动速度 | 6.0 m/s | 高速追击 |
| 追击加速 | 1.5倍 | 狂暴模式下速度提升 |
| 狂暴触发距离 | 5m | 靠近玩家触发狂暴 |
| 血量 | 40 | 血量较低，易击杀 |
| 伤害 | 15 | 单次伤害 |
| 持续追击 | persistent_chase = true | 发现后不放弃 |

**狂暴机制**: 距离玩家<5m时触发，速度×1.5，眼睛颜色从橙色变红色，发光强度从1.0变为2.0。

**潜伏型敌人（Enemy Stalker）**:

| 属性 | 值 | 说明 |
|------|-----|------|
| 潜行速度 | 1.5 m/s | 慢速接近 |
| 突袭速度 | 5.0 m/s | 突袭时高速 |
| 血量 | 60 | 血量中等 |
| 突袭伤害 | 30 | 突袭高伤害 |
| 躲藏时长 | 3秒 | hide_duration |
| 突袭时长 | 2秒 | ambush_duration |
| 突袭触发距离 | 3m | ambush_range |

**三阶段行为**:
- **HIDE**: 躲藏3秒，眼睛熄灭，完全隐蔽
- **SNEAK**: 慢速潜行1.5m/s，眼睛微亮（能量0.3）
- **AMBUSH**: 距离<3m时突袭，眼睛亮起紫色(Color 1.0, 0.0, 0.5)，高速5.0m/s冲向玩家

### 击退与眩晕机制

**击退系统**:

| 参数 | 值 | 说明 |
|------|-----|------|
| 击退力度 | 3.0 | knockback_force |
| 击退衰减 | 5.0 | knockback_decay |
| 击退结束阈值 | 速度<0.5 | 击退结束 |

**击退流程**: 受到击退攻击 → 进入KNOCKBACK状态 → 速度=击退速度 → 每帧衰减 → 速度<0.5 → 进入STUNNED状态。

**眩晕系统**:

| 参数 | 值 | 说明 |
|------|-----|------|
| 眩晕时长 | 2秒 | stun_duration |
| 潜伏型眩晕 | 1.5秒 | 潜伏型眩晕更长 |
| 眩晕状态 | STUNNED | 无法移动攻击 |

**眩晕视觉效果**: 眩晕时眼睛熄灭，结束后恢复发光。

**视觉感知**:
- 感知锥形：前方120°，距离15m
- 视野遮挡：障碍物阻挡视线
- 光线影响：黑暗环境感知距离-50%

**听觉感知**:
- 感知半径：圆形，距离10m
- 声音来源：脚步声、射击声、爆炸声
- 声音衰减：距离越远声音越小
- 环境影响：水传播声音更远

**特殊感知**:
- 声呐探测：声呐开启时敌人位置暴露
- 热能感知：某些敌人可感知体温
- 电磁感知：机械类敌人感知电子设备

### 群体AI行为

**Flocking算法**（小型怪物群）:
- 聚合：向群体中心靠拢
- 分离：避免重叠
- 对齐：保持相同移动方向

**包围阵型**（中型敌人）:
- 3个敌人形成三角形包围
- 5个敌人形成五边形包围
- 交替攻击，避免同时暴露

**分散躲避**（受攻击时）:
- 被范围攻击时分散
- 分散后重新集结
- 分散时保持最小间距

**协作攻击**:
- 追击型吸引注意力
- 潜伏型从侧翼突袭
- 召唤型在后方提供支援

## Formulas

### 击退速度衰减

```
knockback_velocity = initial_force * direction
each_frame:
    knockback_velocity *= exp(-knockback_decay * delta_time)
    if knockback_velocity.length() < 0.5:
        state = STUNNED
        stun_timer = stun_duration
```

### 低血量脉冲

```
if hp_ratio < 0.30:
    pulse = sin(timer * 2.0) * 0.3 * (1.0 - hp_ratio / 0.30)
    vignette_strength = base_vignette + pulse
    screen_edge_alpha = pulse * 0.5
```

### 暗角强度

```
hp_ratio = current_hp / max_hp
vignette_strength = 0.8 * 0.4 * (1.0 - hp_ratio * 0.5)
# HP=100%: 0.16, HP=30%: 0.224, HP=0%: 0.32
```

### 脚步声间隔

```
if is_moving:
    footstep_timer += delta_time
    interval = is_sprinting ? 0.3 : 0.5
    if footstep_timer >= interval:
        play_sound(PLAYER_WALK if not sprinting else PLAYER_SPRINT)
        footstep_timer = 0
else:
    footstep_timer = 0
```

### 敌人狂暴判定

```
distance = (player_position - enemy_position).length()
if distance < rage_mode_threshold (5m) and not enraged:
    enraged = true
    chase_speed *= 1.5
    eye_color = Color.RED
    eye_intensity = 2.0
```

### 潜伏型敌人阶段转换

```
state machine: HIDE → SNEAK → AMBUSH

HIDE: timer = 0, eye_visible = false
  after 3s → SNEAK

SNEAK: move_speed = 1.5, eye_visible = true, eye_energy = 0.3
  if distance_to_player < 3m → AMBUSH

AMBUSH: move_speed = 5.0, eye_color = (1.0, 0.0, 0.5), eye_intensity = 2.0
  after 2s or hit player → reset to HIDE
```

## Edge Cases

1. **追击型敌人在狂暴时被击杀**: 狂暴动画和死亡动画不冲突，击杀后立即终止狂暴状态，播放死亡动画。
2. **潜伏型敌人在HIDE状态被AOE伤害波及**: HIDE状态暴露位置，但伤害减半（隐蔽状态部分保护），阶段不中断。
3. **击退撞到墙壁**: 击退速度立即归零，直接进入STUNNED状态，不等待速度衰减。
4. **眩晕期间受到第二次眩晕**: 眩晕计时不叠加，刷新计时器到完整持续时间。
5. **拾取物品时背包已满**: 物品不消失，保留在场景中，拾取提示持续显示直到背包有空间。
6. **钥匙收集完成但门未交互**: 门灯变绿，提示显示"[E] 打开门"，玩家不按E门不会自动打开。
7. **存档写入时游戏崩溃**: 使用临时文件写入策略（先写.tmp再rename），崩溃后旧存档保留，下次启动可恢复。
8. **AI感知在障碍物后方**: 使用射线检测(RayCast2D)判断视线是否被阻挡，有障碍物则视觉感知失效，仅靠听觉。
9. **群体AI分散时重叠**: 分散算法确保最小间距（1.0m），避免多个敌人重叠在同一位置。
10. **音效快速连续触发**: 音效播放前检查`is_playing()`，避免重叠导致音量爆表。
