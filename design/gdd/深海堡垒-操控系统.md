## Overview

操控系统负责管理玩家对船、潜艇和炮台的所有输入操作，是游戏的核心交互层。系统覆盖三个载体（船只、潜艇、手动炮台），提供统一但差异化的操控体验：船只稳重缓慢、潜艇灵活快速、炮台精准响应。支持键盘/鼠标、手柄、触屏多平台输入。

---

## Player Fantasy

玩家应感受到：
- **驾驶巨型海上堡垒的重量感** — 船体庞大，加速减速缓慢，转向沉稳
- **潜艇在深海中灵活穿梭的自由感** — 潜艇轻巧，加速快，转向灵活
- **手动操控炮台精准射击的掌控感** — 鼠标瞄准精准，锁定追踪流畅
- **操控与反馈的一致性** — 每次按键都有视觉、音效、震动的即时反馈

## Detailed Rules

### 操控载体

| 载体 | 操控场景 | 操控特点 |
|------|---------|---------|
| **船只** | 航行阶段、防守阶段 | 较慢、稳重、策略性 |
| **潜艇** | 探索阶段、战斗阶段 | 较快、灵活、操作性高 |
| **炮台** | 手动防守阶段 | 定点瞄准、精准射击 |

## Formulas

### 船只移动物理

```
velocity(t) = target_velocity * (1 - e^(-resistance * t))
# 加速曲线：渐进加速
# 阻力系数 = 0.85 (水阻力)
# 目标速度 = 2/5/8/12 m/s (取决于速度等级)
```

**减速公式**:
```
velocity(t) = initial_velocity * e^(-resistance * t)
# 正常速度5 m/s → 停止: 约2秒
```

### 潜艇移动物理

```
velocity(t) = target_velocity * (1 - e^(-0.9 * t))
# 潜艇阻力 0.9，加速更快
# 加速时间: 1秒 (vs 船只3秒)
```

### 深度对速度衰减

```
depth_speed_modifier(depth) = max(0.4, 1.0 - (depth - 100) / 1000)
# 浅水区(0-100m): 1.0
# 深水区(100-300m): 0.8
# 深海区(300-500m): 0.6
# 深渊区(500m+): 0.4
```

### 受伤闪烁强度

```
flash_intensity(t) = 0.5 * e^(-t / 0.3)
# 最大强度0.5, 衰减时间0.3秒
```

### 低血量脉冲强度

```
if HP < 30% of max_HP:
    pulse_intensity = 0.3 * (1.0 - HP / (0.3 * max_HP)) * sin(timer * 2.0)
else:
    pulse_intensity = 0
```

### 暗角强度

```
vignette_strength = 0.8 * 0.4 * (1.0 - (HP / max_HP) * 0.5)
# HP 100% → 0.16, HP 50% → 0.24, HP 10% → 0.38
```

### 转向角度插值

```
current_angle = lerp(current_angle, target_angle, turn_response * delta_time)
# 船只: turn_response = 5°/s, 响应0.5秒
# 潜艇: turn_response = 60°/s, 响应0.1秒
# 炮台: turn_response = 90°/s, 响应0.05秒
```

## Edge Cases

1. **氧气耗尽紧急上浮**: 当潜艇氧气为0时，自动触发紧急上浮，速度15m/s，消耗10能源。如果能源也不足，潜艇沉没，触发死亡流程。
2. **深渊区下潜极限**: 深渊区下潜速度降至2m/s，如果未装备高级抗压舱，潜艇持续受到压力伤害。
3. **紧急规避碰撞**: 船只紧急规避时若撞到障碍物，触发碰撞震动并减速50%，不造成船体损伤。
4. **炮台弹药耗尽**: 手动操控炮台时弹药为0，自动退出手动模式，切回自动炮台或提示换弹。
5. **多炮台切换**: Tab切换炮台时，如果目标炮台被摧毁或损坏，跳过该炮台选择下一个可用炮台。
6. **手柄瞄准精度**: 手柄摇杆瞄准精度低于鼠标，在深渊区等需要高精度的场景下，提供辅助瞄准（预测瞄准自动开启）。
7. **触屏虚拟按键遮挡**: 触屏模式下虚拟按键不遮挡关键游戏信息（HP、氧气、深度），按键透明度动态调整。
8. **悬停在深海区**: 潜艇悬停时持续消耗0.1能源/s。如果深渊区能源耗尽，潜艇开始缓慢下沉。
9. **快速连续按键防抖**: 紧急上浮需要 Space+Space 双次按键，两次按键间隔需 > 0.2秒且 < 0.5秒，防止误触。
10. **船锚定状态被攻击**: 锚定时船无法进行紧急规避，但锚定状态增加20%护甲（停泊防护）。

## Dependencies

| 依赖系统 | 方向 | 说明 |
|----------|------|------|
| 战斗系统 | 被依赖 | 炮台操控是战斗系统的输入层 |
| 资源采集系统 | 被依赖 | 潜艇操控是探索/采集的输入层 |
| 氧气能源系统 | 被依赖 | 潜艇操控受氧气/能源限制 |
| 战斗系统 | 被依赖 | 受伤闪烁和低血量脉冲依赖战斗系统的伤害事件 |
| 音效系统 | 被依赖 | 操控音效由音效系统播放 |
| UI系统 | 被依赖 | 操控HUD显示深度、速度、燃料等信息 |
| 波次防守系统 | 被依赖 | 紧急规避在防守阶段使用 |

## Acceptance Criteria

- [ ] 船只从停止加速到正常速度(5m/s)耗时在 2.5-3.5 秒范围内
- [ ] 船只从正常速度减速到停止耗时在 1.5-2.5 秒范围内
- [ ] 船只转向速度在 4-6°/s 范围内
- [ ] 潜艇从停止加速到正常速度(5m/s)耗时在 0.8-1.2 秒范围内
- [ ] 潜艇从正常速度减速到停止耗时在 0.3-0.7 秒范围内
- [ ] 潜艇水平转向 360° 耗时在 5-7 秒范围内
- [ ] 紧急规避触发后 0.3 秒内达到紧急规避速度
- [ ] 紧急上浮 Space+Space 双次按键间隔 0.2-0.5 秒有效，其他间隔无效
- [ ] 炮台瞄准精度范围 ±5° 内射击有效
- [ ] 炮台锁定敌人后追踪偏差 < 10°
- [ ] 受伤闪烁在受到攻击后 0.05 秒内出现，0.3 秒内完全消失
- [ ] HP < 30% 时低血量脉冲自动启动，HP 恢复到 30% 以上自动停止
- [ ] 暗角强度随HP变化正确计算（HP 100%→0.16, HP 50%→0.24, HP 10%→0.38）
- [ ] 深渊区(500m+)潜艇上浮/下潜速度 ≤ 2 m/s
- [ ] 深度速度衰减在浅水区(0-100m)无影响，在深渊区(500m+)降至最低值
- [ ] 键盘 WASD 输入映射在船和潜艇模式下均正确响应
- [ ] 鼠标移动控制炮台瞄准时，准星跟随鼠标位置
- [ ] Tab 键切换炮台时，如果目标炮台不可用则自动跳过
- [ ] 所有操控参数可通过 Tuning Knobs 在配置文件中调整，无需修改代码
- [ ] 手柄输入下瞄准辅助自动开启，辅助精度不低于鼠标模式的 80%
