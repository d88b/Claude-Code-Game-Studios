## Overview

难度曲线系统管理4种预设难度（简单/普通/困难/深渊）的全局参数配置、自定义难度滑块系统、动态难度调整（DDA）、难度与结局关联、海域难度递增和科技路线推荐。系统通过DifficultyConfig资源类实现数据驱动，所有难度参数可在配置文件中调整。

---

## Player Fantasy

玩家应感受到：
- **难度选择的自主权** — 新手可选简单模式享受探索，老玩家可选困难模式迎接挑战
- **动态难度的贴心照顾** — 连续失败时系统自动微调降低难度，但不会让玩家察觉
- **多结局系统的重复游玩动力** — 简单模式结局A，困难模式真结局C，深渊模式完美结局D
- **自定义难度的个性化体验** — 14个参数滑块自由组合，创建"高资源+强敌人"的独特挑战

### 动态难度调整（DDA）

| 触发条件 | 判定标准 | 调整方向 |
|---------|---------|---------|
| 连续失败3次 | 同一波次连续失败3次 | 降低难度5% |
| 波次无伤完成 | 连续2波无伤完成 | 提高难度5% |
| Boss速杀 | 在50%时间内击败Boss | 下次Boss难度+5% |
| 资源溢出 | 资源超上限80%达3个阶段 | 资源获取-5% |
| 死亡次数过多 | 累计死亡5次 | 降低难度10% |
| 教程反复失败 | 同一教程步骤失败3次 | 提供更详细提示 |

**DDA调整上限**:

| 参数 | 最大下调 | 最大上调 |
|------|---------|---------|
| 敌人伤害 | -15% | +15% |
| 敌人数量 | -10% | +10% |
| 资源获取 | +15% | -15% |
| Boss血量 | -10% | +10% |

**DDA开关**: 简单/普通默认开启，困难/深渊默认关闭。可手动关闭。

### 难度配置文件结构（DifficultyConfig）

Godot Resource类包含: difficulty_name, difficulty_icon, difficulty_color, 战斗参数(enemy_damage/count/hp/attack_speed_multiplier, boss_phase_count), 资源参数(resource/rare_resource/drop_rate/exp_multiplier), 消耗参数(oxygen/fuel/food/ammo_consumption, repair_cost/build_time_multiplier), 系统参数(weather_frequency, autosave_interval, death_penalty_percent, salvage_rate), AI参数(ai_reaction_speed, ai_cooperation_level 0-3, boss_rage_threshold), UI参数(tutorial_detail_level 0-3, dynamic_difficulty_enabled)。

预设配置通过preload加载: difficulty_easy.tres, difficulty_normal.tres, difficulty_hard.tres, difficulty_abyss.tres。

## Formulas

### 全局难度乘数应用

```
实际值 = 基础值 × 预设难度系数 × 海域难度倍率 × DDA调整系数

预设难度系数: 简单=0.7-1.2(依参数不同), 普通=1.0, 困难=1.2-1.5, 深渊=1.5-2.0
海域难度倍率: 1号=0.8x, 递增到9号=3.0x
DDA调整系数: 范围±15%(敌人伤害), ±10%(敌人数量/资源)
```

**示例**: 困难难度 + 7号海域的敌人伤害
```
实际敌人伤害 = 基础伤害 × 1.3(困难) × 2.5(7号海域) = 基础 × 3.25
```

### 自定义难度等效评级

```
综合难度评分 = Σ(各参数偏移量 × 权重) / 参数数量

偏移量 = (参数值 - 100%) / 50%
权重: 敌人强度=0.3, 资源获取=0.2, 其他各=0.05

等效评级: <20%=简单, 20-40%=普通, 40-60%=困难, >60%=深渊
```

### DDA调整计算

```
dda_adjustments[param] = clamp(current + delta, min_val, max_val)

min/max by param:
  enemy_damage: -0.15 to +0.15
  enemy_count: -0.10 to +0.10
  resource_gain: 0.0 to +0.15 (仅下调资源时)
  boss_hp: -0.10 to +0.10
```

### 自定义难度实际价格

```
实际值 = 基础值 × custom_param_value / 100%

例如: 敌人强度设置为150% → 实际敌人伤害 = 基础 × 1.5
```

## Edge Cases

1. **难度切换中游戏进行中**: 简单/普通/自定义难度可在游戏中随时切换，困难/深渊难度游戏中不可切换（需新游戏）。切换时立即应用新参数。
2. **DDA调整与手动难度切换冲突**: 玩家手动切换到更简单的难度时，DDA累积的调整值清零，避免叠加。
3. **自定义难度成就标记**: 使用自定义难度通关，成就标记为"自定义难度"而非具体难度等级，不参与排行榜。
4. **Boss阶段数自定义为1**: 自定义难度Boss阶段设为1时，Boss仅有P1行为，无弱点暴露和狂暴（狂暴仍触发）。
5. **存档间隔自定义为15秒**: 极短存档间隔可能导致频繁I/O，但15秒是最小安全值，不影响性能。
6. **难度解锁条件不满足**: 未以普通通关时，困难按钮显示"🔒 需以普通难度通关"并禁用。
7. **DDA在深渊模式关闭**: 困难和深渊模式DDA默认关闭，即使玩家连续死亡也不自动调整。
8. **自定义配置加载失败**: 导入的JSON配置文件格式错误时，提示"配置加载失败"，不影响当前难度设置。
9. **海域难度与预设难度叠加过高**: 深渊难度+9号海域 = 基础×1.5×3.0=4.5倍敌人强度，可能导致无法通关。设计上保证最高难度仍可通关（需要完美装备和策略）。
10. **新游戏+保留难度设置**: 新游戏+模式下，难度设置保留但可更改，通关计数不影响已解锁的难度。

## Acceptance Criteria

- [ ] 简单模式下敌人伤害为基础值的70%，深渊模式为150%
- [ ] 简单模式下资源获取为基础值的120%，深渊模式为60%
- [ ] 困难模式下Boss狂暴阈值为20%（血量降至20%时触发狂暴）
- [ ] 深渊模式下Boss狂暴阈值为30%，且有5个阶段+隐藏机制
- [ ] 困难难度需要以普通难度通关1次后才解锁
- [ ] 深渊难度需要以困难难度通关1次后才解锁
- [ ] DDA连续失败3次同一波次后，敌人伤害降低5%
- [ ] DDA调整不超过上限（敌人伤害±15%，敌人数量±10%）
- [ ] 自定义难度的14个参数滑块均可在50%-200%范围内调整
- [ ] 自定义难度通关成就标记为"自定义难度"，不参与排行榜
- [ ] 简单难度通关解锁结局A，普通+5远古遗物解锁结局B，困难+所有隐藏Boss解锁结局C，深渊+100%收集+无死亡解锁结局D
- [ ] 难度配置文件为Godot Resource格式（difficulty_easy.tres等），所有参数可通过配置文件调整
- [ ] 简单/普通模式DDA默认开启，困难/深渊模式DDA默认关闭
- [ ] 自定义难度综合评分算法正确反映等效预设难度等级
