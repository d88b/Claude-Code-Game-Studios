## Overview

战斗系统管理船和潜艇两大载体的所有战斗行为，覆盖天空、水面、水下、内部和海底探索五层战场。船侧重防守（自动/手动炮台），潜艇侧重探索战斗（鱼雷、深海炮、特殊武器）。系统包含伤害计算、武器升级、敌人应对策略和Boss战斗机制。

---

## Player Fantasy

玩家应感受到：
- **指挥海上堡垒防御立体威胁的统帅感** — 多层炮台协同防守，天空/水面/水下同时开火
- **潜艇深入海底与怪物搏斗的刺激感** — 氧气有限、弹药有限，边探索边战斗
- **精准打击Boss弱点的成就感** — 手动操控炮台，锁定弱点，阶段化Boss战
- **武器升级带来战力提升的成长感** — 从基础炮台到追踪导弹、从基础鱼雷到深渊鱼雷

## Formulas

### 基础伤害计算

```
实际伤害 = 基础伤害 × 伤害倍率 × (1 - 护甲减免) × 随机因子(0.9-1.1)
```

### 护甲减免

```
护甲减免 = 护甲值 / (护甲值 + 100)
```

| 护甲值 | 减免 |
|--------|------|
| 0 | 0% |
| 50 | 33% |
| 100 | 50% |
| 150 | 60% |
| 200 | 67% |
| 300 | 75% |

### 伤害倍率叠加

```
总倍率 = 基础倍率(1.0) × 弱点倍率 × 暴击倍率 × 元素克制倍率 × 护甲克制倍率
# 示例：弱点(2.0) + 暴击(1.5) + 元素克制(1.3) = 2.0 × 1.5 × 1.3 = 3.9x
```

### 潜艇损伤影响

```
速度修正 = 基础速度 × (1 - 损伤惩罚)
# 轻度(80-50%): -10%, 中度(50-30%): -20%, 重度(30-10%): -30%, 濒危(10-1%): -50%

氧气消耗修正 = 基础消耗 × (1 + 损伤惩罚)
# 中度: +10%, 重度: +20%, 濒危: +50%
```

### 炮台升级伤害计算

```
升级后伤害 = 基础伤害 × (1 + 升级伤害加成)
# Lv1: ×1.2, Lv2: ×1.4, Lv3: ×1.6
```

### 战斗对氧气消耗的影响

```
战斗氧气消耗 = 基础消耗 × (1 + 战斗加成)
# 战斗状态: +20%, 冲刺躲避: +30%, 深海区战斗: +50%
```

## Edge Cases

1. **弹药耗尽**: 炮台弹药为0时自动停止射击，提示补充弹药。潜艇鱼雷为0时无法发射，需切换到其他武器或回船补充。
2. **氧气耗尽战斗中**: 潜艇氧气为0时强制进入紧急上浮状态，无法继续海底战斗。紧急上浮期间无法攻击。
3. **能源耗尽**: 特殊武器（电击、隐形、EMP）需要能源，能源不足时无法使用。能源为0时隐形系统自动关闭。
4. **潜艇沉没**: HP归零时潜艇沉没，触发死亡打捞机制。人员和装备留在死亡点，可通过打捞系统回收。
5. **炮台被摧毁**: 防守阶段炮台被敌人摧毁后退出自动射击队列，需战后修复。
6. **Boss护盾阶段**: Boss进入无敌护盾阶段时，所有攻击无效（伤害=0）。护盾消失后弱点暴露，进入可攻击窗口。
7. **锁定目标死亡**: 锁定瞄准的目标被其他炮台击杀后，自动切换到下一个最近目标。
8. **范围攻击友军**: 爆炸类武器在近距离可能伤到己方单位（护卫潜艇），需保持安全距离。
9. **电击连锁水中传播**: 电击武器在水中传播范围扩大50%，可能误伤玩家潜艇（如果在传导范围内）。
10. **隐形敌人被声波显形**: 隐形敌人被声波武器命中后强制显形5秒，显形期间可以被所有武器攻击。
11. **多炮台同时射击同一目标**: 多炮台锁定同一目标时，后命中的炮弹伤害不叠加但会触发额外暴击判定。
12. **登船敌人破坏弹药库**: 内部层敌人如果到达弹药库，引发连锁爆炸，造成大量船体损伤。

## Acceptance Criteria

- [ ] 基础对空炮(伤害20)攻击护甲0的敌人时，实际伤害在18-22范围内（含随机因子）
- [ ] 护甲100的敌人受到基础伤害时，实际伤害约为基础值的50%
- [ ] 护甲300的敌人受到基础伤害时，实际伤害约为基础值的25%
- [ ] 弱点攻击必定触发暴击，暴击伤害为基础伤害的3.0x（Boss）或2.0x（普通）
- [ ] 暴击率5%时，100次攻击中暴击次数在2-8次范围内
- [ ] 潜艇HP降至50%时，速度减少20%，氧气消耗增加10%
- [ ] 潜艇HP降至10%时，速度减少50%，无法使用冲刺
- [ ] 防空导弹自动追踪500m范围内的敌人，追踪偏差<10°
- [ ] 炮台升级Lv3后，伤害提升至基础值的160%
- [ ] 声波武器命中隐形敌人后，显形持续5秒
- [ ] 弹药为0时炮台自动停止射击，不产生负数弹药
- [ ] 潜艇氧气为0时强制触发紧急上浮，上浮期间无法攻击
- [ ] 范围爆炸武器对范围内所有敌人造成伤害，包括己方单位
- [ ] Boss护盾阶段所有攻击伤害为0，护盾消失后弱点暴露可攻击
- [ ] 锁定目标被击杀后，系统在0.5秒内自动切换到下一个目标
- [ ] 所有武器伤害计算公式可通过配置文件调整，无需修改代码
- [ ] 电击武器在水中传播范围比陆地大50%
- [ ] 登船敌人到达弹药库时触发连锁爆炸，造成船体损伤≥30%
