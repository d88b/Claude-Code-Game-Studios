## Overview

主菜单与Loading界面管理游戏启动流程（引擎Logo→工作室Logo→开场CG→主菜单）、主菜单（新游戏/继续游戏/设置/制作人员/退出）、难度选择界面、Loading场景（多线程资源加载+进度条+游戏提示）、存档信息展示和制作人员滚动界面。主菜单背景为动态深海画面（视差滚动+Shader波浪+粒子气泡+鱼群），支持日夜/天气联动变化。使用Godot Control节点树和ResourceLoader多线程加载实现。

---

## Player Fantasy

玩家应感受到：
- **深海氛围的沉浸感** — 启动即被动态深海包围：气泡上浮、鱼群游过、光线从水面射下、低频深海嗡鸣
- **按钮交互的精致感** — 悬停时按钮放大110%+蓝绿色发光+水波提示音，按下时弹性回弹+确认音
- **开场CG的史诗感** — 从陆地沉没到海上堡垒建造，30秒定调世界观
- **Loading不无聊** — 大幅场景艺术图+24条轮换提示语+平滑进度条动画

## Detailed Rules

### 游戏启动流程

```
游戏启动
  → Godot引擎初始化 (~0.5s)
  → [首次] 引擎Logo展示 (2s，"Powered by Godot Engine")
  → [首次] 工作室Logo展示 (2s，"Deep Fortress Studio")
  → 开场CG播放 (30s，可ESC跳过)
  → 进入主菜单
```

**第二次及以后启动**: 跳过引擎Logo和工作室Logo，直接进入开场CG（也可跳过）。

### 多线程资源加载

```
1. ResourceLoader.load_threaded_request(target_scene)
2. 每帧检查: ResourceLoader.load_threaded_get_status()
   返回: 0=加载中, 1=完成, 2=失败
   进度: 0.0-1.0
3. 更新进度条: progress_bar.value = progress * 100
4. 加载完成: scene = ResourceLoader.load_threaded_get()
   get_tree().change_scene_to_packed(scene)
```

## Formulas

### 暗角遮罩强度

```
血量比率 = HP / max_HP
暗角强度 = 0.8 * 0.4 * (1.0 - 血量比率 * 0.5)
# 基础强度0.4，黑暗度0.8，血量越低暗角越强
```

### 低血量脉冲警告

```
if HP < 30%:
    pulse_intensity = sin(timer * 2.0) * 0.3 * (1.0 - HP / 0.3)
    screen_vignette_strength = base_vignette + pulse_intensity
```

### 自定义难度等效评分

```
综合难度 = (
  (敌人密度 - 100) / 100 * 0.3 +
  (敌人强度 - 100) / 100 * 0.3 +
  (100 - 资源丰度) / 100 * 0.2 +
  (风暴频率偏移) * 0.1 +
  (初始资金偏移) * 0.1
)
等效评级: <20%=轻松, 20-40%=标准, 40-60%=困难, >60%=噩梦
```

### 进度条阶段闪烁

```
current_phase = int(progress * 4)  # 0-3对应4个阶段
if current_phase != previous_phase:
    flash_progress_bar(duration=0.1s, color=Color.WHITE)
    previous_phase = current_phase
```

### 背景日夜色调映射

```
hour = get_current_game_hour()
if 6 <= hour < 9:
    canvas_modulate = Color(1.1, 1.0, 0.9)  # 浅蓝偏暖
elif 9 <= hour < 17:
    canvas_modulate = Color(1.0, 1.0, 1.0)  # 明亮蔚蓝
elif 17 <= hour < 20:
    canvas_modulate = Color(0.8, 0.7, 0.9)  # 深蓝偏紫
else:
    canvas_modulate = Color(0.3, 0.3, 0.5)  # 深蓝近黑
```

## Edge Cases

1. **Loading中ESC取消**: 调用`ResourceLoader.load_threaded_cancel()`并返回主菜单，已加载的资源不泄露。
2. **多线程加载失败**: 进度条显示"加载失败！"，1秒后自动返回主菜单，不崩溃。
3. **首次启动无存档**: "继续游戏"按钮灰色禁用，悬停显示"暂无存档"提示tooltip，点击不触发任何操作。
4. **确认弹窗后取消**: 覆盖存档确认后点取消，回到主菜单，存档不变。
5. **Loading进度条100%但场景未就绪**: 进度条满格停留最多3秒，超时后强制进入场景或显示错误。
6. **制作人员滚动中按ESC**: 立即停止滚动并返回主菜单，不等待滚完。
7. **CG跳过时音频淡出**: ESC跳过CG时，CG音轨0.5秒淡出，避免突然静音。
8. **按钮悬停音效快速连续触发**: 音效播放前检查`is_playing()`，避免重叠播放。
9. **存档缩略图加载失败**: 使用默认存档缩略图（save_default.png）作为fallback。
10. **Loading提示语池为空**: 至少显示一条默认提示"祝你好运，船长！"，不报错。
