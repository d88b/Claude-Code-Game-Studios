## Overview

波次防守系统管理船只防守阶段的波次机制，包括5种波次类型（小型骚扰/定向攻击/立体围攻/特殊事件/逃跑选择）、强度递增曲线、敌人组合生成、波次间隔活动、预警系统、奖励计算和失败处理。系统是游戏核心循环"航行→探索→建造→防守"中的防守环节。

---

## Player Fantasy

玩家应感受到：
- **波次逐渐升级的压迫感** — 从零星小怪到立体围攻，难度曲线让玩家感受到成长与挑战并存
- **防守成功后的满足感** — 多层炮台协同开火，击退一波波敌人后获得丰厚奖励
- **逃跑选择的策略权衡** — 面对强敌是拼死一搏还是牺牲资源逃跑，每次选择都有代价
- **波次间隔的紧张修复** — 有限时间内修复设施、补充弹药、准备下一波，节奏紧凑

## Detailed Rules

### 波次类型

| 类型 | 强度 | 时长 | 敌人数量 | 攻击层级 | 奖励 |
|------|------|------|---------|---------|------|
| **小型骚扰** | 低 | 1-2分钟 | 5-15个 | 单层或双层 | 基础资源×1 |
| **定向攻击** | 中 | 2-3分钟 | 15-30个 | 集中攻击某一层 | 中级资源×2 |
| **立体围攻** | 高 | 3-5分钟 | 30-50个 | 三层或四层同时 | 高级资源×3 |
| **特殊事件** | 特殊 | 5-10分钟 | 1-10个(Boss+小怪) | Boss特殊攻击 | Boss蓝图+稀有资源 |
| **逃跑选择** | 可选 | 限时10秒决策 | 预警提示 | 预警提示 | 防守获奖励/逃跑损失资源 |

| 波次3 | 1.6x | 中型怪物为主 |
| 波次4 | 1.9x | 中型+大型怪物 |
| 波次5 | 2.2x | 大型+Boss级怪物 |

| 逃跑场景 | 损失 |
|---------|------|
| 小型骚扰 | 5%基础资源 |
| 定向攻击 | 10%基础资源 |
| 立体围攻 | 20%基础+中级资源 |
| 特殊事件 | 30%高级资源 |

### 波次失败处理

| 失败程度 | 船HP损失 | 后果 |
|---------|---------|------|
| 轻度失败 | 20-30% | 部分设施损坏，可修复 |
| 中度失败 | 50-70% | 多个设施损坏，长时间修复 |
| 重度失败 | 80-90% | 核心设施损坏，紧急修复 |

## Formulas

### 波次强度计算

```
wave_intensity = base_intensity × (1 + wave_number × 0.3)

base_intensity: 小型骚扰=10, 定向攻击=25, 立体围攻=50, 特殊事件=100
wave_number: 从0开始计数(第一波=0)
```

| 波次(序号) | 强度倍率 |
|-----------|---------|
| 第1波(0) | 1.0x |
| 第2波(1) | 1.3x |
| 第3波(2) | 1.6x |
| 第4波(3) | 1.9x |
| 第5波(4) | 2.2x |

### 敌人数量计算

```
enemy_count = base_count × intensity_multiplier

base_count: 小型骚扰=5, 定向攻击=15, 立体围攻=25
实际数量在结果基础上±20%随机浮动
```

### 敌人生成时间间隔

```
spawn_interval = base_spawn_interval / (1 + wave_number × 0.15)

小型怪物: base=3.5秒(范围2-5秒)
中型怪物: base=12.5秒(范围10-15秒)
大型怪物: base=45秒(范围30-60秒)
```

### 波次奖励计算

```
reward_amount = base_reward × wave_intensity_multiplier × sea_area_coefficient

base_reward: 基础资源=10单位, 中级资源=10单位, 高级资源=5单位
sea_area_coefficient: 新手=1.0, 初级=1.2, 中级=1.5, 高级=2.0, 深渊=3.0
```

### 逃跑损失计算

```
loss_percentage = base_loss × (1 - player_preparation_score × 0.2)

base_loss: 小型骚扰=5%, 定向攻击=10%, 立体围攻=20%, 特殊事件=30%
player_preparation_score: 0-1 (基于设施状态、弹药储备等)
```

### 波次时长计算

```
wave_duration = base_duration × intensity_multiplier

小型骚扰: base=90秒(范围60-120秒)
定向攻击: base=150秒(范围120-180秒)
立体围攻: base=240秒(范围180-300秒)
特殊事件: base=450秒(范围300-600秒)
```

## Edge Cases

1. **波次进行中船只HP归零**: 船被摧毁触发游戏结束流程，波次终止。
2. **核心设施被摧毁**: 动力室或指挥室被摧毁后船瘫痪，所有炮台停止工作，后续波次无法防守。触发重度或完全失败。
3. **弹药耗尽**: 所有炮台弹药为0时自动停止射击，无法继续防守。如果波次尚未结束，判定为弹药耗尽无法防守的失败条件。
4. **波次间隔中遭到额外敌人**: 波次间隔期间有零星敌人骚扰，数量不超过当前波次的20%。这些敌人为独立生成，不纳入正式波次计数。
5. **逃跑选择超时**: 玩家10秒内未做出选择，默认为防守（系统认为玩家选择战斗）。
6. **逃跑时资源不足**: 如果逃跑损失百分比计算后资源为负，资源归零但不产生负债。
7. **Boss波次中Boss逃跑**: Boss血量<10%时有概率逃跑（困难模式以下），触发波次提前结束，给予部分奖励。
8. **多层同时被突破**: 如果天空层和水面层同时被突破（敌人全部穿透防线），判定为立体防守失败，直接进入重度失败状态。
9. **波次奖励仓库满**: 如果奖励资源超过仓库容量，溢出部分丢失，不额外增加仓库。
10. **特殊事件与其他波次重叠**: 特殊事件波次触发时，取消当前正在准备的其他波次，优先处理特殊事件。
11. **船员全部死亡**: 波次进行中船员全部死亡后，船无法运作设施（炮台/动力室），判定为船员全部死亡的失败条件。
12. **登船敌人到达弹药库**: 内部层敌人如果成功到达弹药库，引发连锁爆炸，造成船体≥30%损伤，直接导致中度或更严重失败。

## Dependencies

## Acceptance Criteria

- [ ] 第1波小型骚扰波次，敌人数量在 3-7 个范围内（基础5个±20%）
- [ ] 第3波立体围攻波次，敌人数量在 20-30 个范围内（基础25个×1.6倍率）
- [ ] 第5波波次强度为第1波的2.2倍
- [ ] 波次预警在来袭前30秒显示预警信息
- [ ] 波次预警在来袭前15秒显示波次类型
- [ ] 波次预警在来袭前10秒显示敌人组合和攻击层级
- [ ] 波次间隔内玩家可修复设施、补充弹药（设施状态可交互修改）
- [ ] 逃跑选择10秒倒计时结束未做选择时，自动进入防守
- [ ] 逃跑损失计算结果不超过当前资源总量（不会出现负数资源）
- [ ] 特殊事件波次触发时，取消当前正在准备的其他波次
- [ ] Boss血量<10%时简单/普通模式有概率逃跑，触发波次提前结束
- [ ] 天空层+水面层同时被突破时，直接判定重度失败
- [ ] 波次奖励超过仓库容量时，溢出部分丢失
- [ ] 航行0-5分钟内不会触发任何波次
- [ ] 航行20+分钟后波次触发概率100%
- [ ] 登船敌人到达弹药库时触发连锁爆炸，船体损伤≥30%
- [ ] 所有波次参数（强度系数、敌人数量、间隔时长、奖励量）可通过配置文件调整，无需修改代码
