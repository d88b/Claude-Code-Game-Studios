## Overview

资源采集系统管理潜艇在海底探索时的资源采集行为，覆盖基础到终极四类资源层级。系统定义采集工具分级、采集时间计算、消耗公式、难度影响、批量采集机制和稀有发现概率。采集是游戏核心循环"探索→采集→建造→防守"的关键环节。

---

## Player Fantasy

玩家应感受到：
- **深入未知海域发现珍稀资源的探索感** — 扫描仪探测、逐步接近、发现资源点的惊喜
- **工具升级带来采集效率提升的成长感** — 从基础钻头到深渊钻头，采集时间大幅缩短
- **深海采集风险与回报并存的紧张感** — 氧气有限、敌人威胁、采集进度与生存的权衡
- **批量采集带来的规模满足感** — 高级工具支持多资源点一键采集

## Detailed Rules

### 资源分类

| 层级 | 深度 | 主要资源 | 采集难度 |
|------|------|---------|---------|
| **基础资源** | 0-50m | 铁矿、铜矿、木材、海藻、小型鱼肉 | 低 |
| **中级资源** | 100-200m | 深海矿、石油、中型鱼肉、珊瑚、生物样本 | 中 |

| 采集过程中死亡 | 全部损失，触发死亡打捞机制 |

## Formulas

### 采集时间计算

```
实际采集时间 = 基础时间 × 工具效率系数 × 深度系数 × 环境系数
```

**深度系数**:
| 深度范围 | 系数 |
|---------|------|
| 0-50m | 1.0 |
| 50-100m | 1.1 |
| 100-200m | 1.2 |
| 200-300m | 1.5 |
| 300-500m | 2.0 |
| 500m+ | 3.0 |

**环境系数**:
| 环境 | 系数 |
|------|------|
| 正常水域 | 1.0 |
| 洞穴内部 | 1.2 |
| 深海洞穴 | 1.5 |
| 遗迹内部 | 2.0 |
| 异常区域 | 1.5-3.0 |

**示例计算**:
- 浅水区铁矿（基础钻头）: `10秒 × 1.0 × 1.0 × 1.0 = 10秒`
- 深海区深渊矿（深海钻头）: `60秒 × 0.6 × 2.0 × 1.0 = 72秒`
- 深渊区深渊晶体（终极钻头）: `60秒 × 0.4 × 3.0 × 1.5 = 108秒`

### 基础采集时间

| 资源类型 | 基础时间 |
|---------|---------|
| 铁矿 | 10秒 |
| 铜矿 | 15秒 |
| 深海矿 | 30秒 |
| 深渊矿 | 60秒 |
| 深渊晶体 | 60秒 |
| 远古遗物 | 120秒 |

### 氧气消耗

```
采集氧气消耗 = 采集消耗率 × (1 + 深度系数 × 0.1) × 采集时间
```

| 采集类型 | 氧气消耗率 |
|---------|-----------|
| 基础采集 | 2 单位/s |
| 中级采集 | 2.5 单位/s |
| 高级采集 | 3 单位/s |
| 终极采集 | 4 单位/s |

深度每增加100m，氧气消耗额外+10%。

### 能源消耗

```
采集能源消耗 = 能源消耗率 × 采集时间
```

| 采集活动 | 能源消耗率 |
|---------|-----------|
| 钻头采集 | 1 单位/s |
| 抓取臂采集 | 0.5 单位/s |
| 扫描仪使用 | 2 单位/次 |

**示例**: 深海区采集深渊矿（72秒）:
```
氧气消耗 = 2 × 1.2 × 72 = 172.8 单位
能源消耗 = 1 × 72 = 72 单位
```

### 采集完成奖励

| 采集资源 | 基础奖励 | 稀有奖励(概率) | 特殊奖励(极低概率) |
|---------|---------|--------------|------------------|
| 铁矿 | 基础量 | 深海矿×1 (5%) | - |
| 深海矿 | 基础量 | 深渊矿×1 (10%) | 远古遗物碎片×1 (1%) |
| 深渊矿 | 基础量 | 深渊晶体×1 (15%) | 远古遗物×1 (2%) |

## Edge Cases

1. **工具不匹配**: 使用错误工具尝试采集时，提示"工具不适用"，采集无法开始。高级工具可用于低级资源但效率不提升（使用工具对应的基础效率系数）。
2. **氧气不足采集中断**: 采集中途氧气为0时，强制紧急上浮，采集进度保留50%，可获得部分资源。
3. **能源不足采集中断**: 采集中途能源为0时，采集立即停止，进度丢失，无法获得资源。
4. **批量采集中遇敌**: 批量采集模式遇到敌人攻击时，自动暂停批量采集，进入战斗状态。战斗结束后可选择继续或撤离。
5. **扫描仪探测隐藏资源**: 扫描仪有10%概率发现隐藏资源点。未装备扫描仪时无法发现隐藏资源。
6. **采集过程中潜艇受损**: 潜艇损伤达到中度及以上时，采集效率降低10%（精度下降影响工具操作）。
7. **遗迹内采集触发机关**: 在遗迹内部采集时有概率触发机关陷阱，需先解除机关才能安全采集。
8. **Boss区域采集**: Boss被击败后，Boss区域出现可采集的Boss掉落资源，限时5分钟，超时消失。
9. **深度极限采集**: 未装备深渊抗压舱的潜艇在500m+深度采集时，每10秒受到1点压力伤害。
10. **资源点被敌人占据**: 某些资源点被敌人守卫，需先清除敌人才能采集。
11. **采集进度保存**: 取消采集时，已消耗的氧气和能源不退还，但已获得的部分资源保留。

## Dependencies

| 依赖系统 | 方向 | 说明 |
|---------|------|------|
| 操控系统 | 被依赖 | 潜艇操控是探索/采集的输入层 |
| 氧气能源系统 | 依赖 | 采集过程消耗氧气和能源 |
| 战斗系统 | 依赖 | 采集过程中可能遭遇敌人 |
| 物品系统 | 依赖 | 采集工具是物品，资源进入物品仓库 |
| 玩家成长系统 | 依赖 | 工具升级、科技树解锁 |
| 关卡布局系统 | 依赖 | 资源分布在关卡场景中 |
| 敌人AI系统 | 依赖 | 敌人守卫资源点 |

## Tuning Knobs

| 参数 | 当前值 | 安全范围 | 影响 |
|------|--------|---------|------|
| 铁矿基础采集时间 | 10秒 | 5-20秒 | 影响初期采集节奏 |

| 批量采集资源点距离阈值 | 50m | 30-100m | 影响批量采集触发条件 |

## Acceptance Criteria

- [ ] 使用基础钻头在浅水区(0m)采集铁矿，实际时间在 8-12 秒范围内
- [ ] 使用深海钻头在300m深度采集深渊矿，实际时间在 60-80 秒范围内
- [ ] 使用终极钻头在500m+深渊区采集深渊晶体，实际时间在 90-120 秒范围内
- [ ] 工具不匹配时采集无法开始，显示"工具不适用"提示
- [ ] 采集中途氧气为0时触发紧急上浮，获得50%采集进度的资源
- [ ] 采集中途能源为0时采集停止，进度丢失，无资源获得
- [ ] 批量采集模式遇到敌人攻击时自动暂停，战斗结束后可继续
- [ ] 扫描仪探测时10%概率发现隐藏资源点（100次探测中8-15次）
- [ ] 采集铁矿有5%概率额外获得深海矿×1（100次采集中3-8次）
- [ ] 深度每增加100m，氧气消耗增加10%（300m相比100m消耗增加20%）
- [ ] 遗迹内部采集时间为正常水域的2倍
- [ ] Boss被击败后Boss区域资源点在5分钟内可采集，超时自动消失
- [ ] 未装备抗压舱的潜艇在500m+采集时，每10秒受到1点压力伤害
- [ ] 所有采集参数（基础时间、效率系数、深度系数、环境系数）可通过配置文件调整，无需修改代码
- [ ] 潜艇中度损伤时采集效率降低10%
