# 深海堡垒 - 游戏设计方案

## 一、核心概念

### 1.1 游戏一句话描述

**驾驶移动海上堡垒穿越危险海域，派出潜艇探索海底世界，收集资源建造防线，抵御来自天空、水面、水下的多重威胁。**

### 1.2 核心玩法三角

- **建造**: 扩建船上设施、升级潜艇、打造多层防线
- **防守**: 抵御天空/水面/水下/内部的立体威胁
- **搜打撤**: 潜艇下潜 → 海底探索 → 战斗 → 撤退回船

### 1.3 独特性 (USP)

- **移动基地**: 基地 (船) 本身在移动，不是固定点位
- **立体防守**: 天空+水面+水下+内部，四层防线
- **动态世界**: 海域不停移动，每次探索都是新地图
- **双重载体**: 船 (基地) + 潜艇 (探索工具)，两个玩法载体

## 二、游戏循环

### 2.1 主循环

**航行 → 探索 → 建造 → 防守 → 下一海域**

| 阶段 | 时长 | 玩家做什么 |
|------|------|-----------|
| 航行阶段 | 1-3分钟 | 船自动航行，观察新海域 |
| 探索阶段 | 5-15分钟 | 潜艇下潜，探索海底 |
| 建造阶段 | 3-10分钟 | 建造升级设施、修复损伤 |
| 防守阶段 | 2-5分钟 | 敌人波次来袭，防守船 |

### 2.2 搜打撤循环

**准备 → 下潜 → 探索 → 战斗 → 撤退 → 回船**

| 步骤 | 玩家行为 |
|------|---------|
| 准备 | 检查潜艇状态、装备武器、准备氧气 |
| 下潜 | 操控潜艇从船舱下潜到海底 |
| 探索 | 在海底洞穴/遗迹/资源点探索 |
| 战斗 | 遭遇海底生物/敌方潜艇，战斗 |
| 撤退 | 资源收集完毕或氧气不足，撤退 |
| 回船 | 潜艇回船，卸载资源、修复、升级 |

### 2.3 防守循环

**预警 → 威胁来袭 → 防守 → 修复 → 评估损失**

## 三、视角与场景结构

### 3.1 全程横向2D视角

视角统一，不切换:
- 船场景: 横向多层结构
- 潜艇场景: 横向水下世界
- 过渡: 潜艇从船舱 "浮出/下潜"

### 3.2 场景分层结构 (从上到下)

```
Y轴（深度）
↑ 负值 = 上方（天空/水面）
↓ 正值 = 下方（深海/深渊）

第1层（水面）    Y=-800~-600  暗蓝灰色，偶尔闪电
第2层（上层）    Y=-600~-300  人造结构，灯光可闪烁
第3层（中层）    Y=-300~0     灯光减少，应急灯
第4层（下层）    Y=0~150      几乎无光，手电筒是唯一光源
第5层（深渊）    Y=150+       全黑，隐约可见生物轮廓
```

**详见**：`深海堡垒-关卡场景设计.md`（完整房间布局、敌人分布、物品分布、氛围效果）

## 四、建造系统

### 4.1 船上设施

| 区域 | 设施 | 功能 |
|------|------|------|
| 船上层 | 指挥室 | 航行控制、雷达、声呐 |
| | 对空炮台 | 防守天空敌人 |
| | 观察塔 | 扩大预警范围 |
| 船中层 | 居住舱 | 人员休息、恢复体力 |
| | 仓库 | 存储资源、战利品 |
| | 工坊 | 制造装备、升级潜艇 |
| | 医疗室 | 治疗伤员 |
| 船下层 | 动力室 | 船引擎、推进系统 |
| | 潜艇舱 | 潜艇停泊、维修、升级 |
| | 弹药库 | 存储炮弹、鱼雷 |
| | 氧气舱 | 存储氧气罐 |

### 4.2 建造机制

- **模块化建造**: 每个设施是一个模块，可自由摆放
- **扩建限制**: 船有固定 "格子" 空间，需要规划布局
- **升级系统**: 每个设施可升级 (Lv1 → Lv2 → Lv3)
- **损伤修复**: 设施被攻击后需修复，修复消耗资源
- **连锁系统**: 某些设施需要相邻 (如弹药库→炮台)

### 4.3 潜艇建造/升级

| 潜艇部件 | 可升级项 |
|---------|---------|
| 船体 | 耐久度、装甲、抗压能力 |
| 引擎 | 速度、机动性、能源效率 |
| 氧气系统 | 氧气容量、再生速度 |
| 武器 | 鱼雷、深海炮、电击武器 |
| 采集工具 | 钻头、抓取臂、扫描仪 |
| 特殊装备 | 隐形系统、声呐、探照灯 |

## 五、防守系统

### 5.1 四层防线

| 防线层 | 威胁来源 | 防守设施 |
|--------|---------|---------|
| 天空层 | 飞行怪物、空投兵、风暴 | 对空炮台、防空导弹、避雷针 |
| 水面层 | 海面敌人、敌方船只、海盗船 | 船侧炮、鱼雷发射器、撞击 |
| 水下层 | 水下生物、敌方潜艇、深潜者 | 水下炮、护卫潜艇、声呐陷阱 |
| 内部层 | 登船敌人、内部入侵、叛乱 | 舱门封锁、内部卫兵、防御陷阱 |

### 5.2 防守机制

- **自动炮台**: 部署后自动攻击，消耗弹药
- **手动操控**: 玩家可以手动操控某个炮台精准射击
- **护卫潜艇**: 派出潜艇环绕船周边巡逻
- **舱门封锁**: 敌人入侵时封锁舱门，限制移动
- **损伤系统**: 设施被攻击后损伤，影响功能
- **紧急修复**: 战斗中可紧急修复，但效率低

### 5.3 防守波次设计

| 波次类型 | 特点 |
|---------|------|
| 小型骚扰 | 少量敌人，测试防线 |
| 定向攻击 | 某一层集中攻击 |
| 立体围攻 | 多层同时攻击 |
| 特殊事件 | Boss怪、风暴、触礁等 |

## 六、搜打撤系统

### 6.1 搜 (Search) - 探索机制

| 探索元素 | 说明 |
|---------|------|
| 海底洞穴 | 随机生成的洞穴，内有资源和危险 |
| 沉船遗迹 | 沉船残骸，可能有稀有物资 |
| 资源点 | 矿物、生物样本、燃料等 |
| 危险区域 | 深渊区、辐射区、高压区 |
| 隐藏事件 | 随机遭遇事件 (宝藏、怪物、NPC) |

### 6.2 打 (Fight) - 战斗机制

| 战斗类型 | 说明 |
|---------|------|
| 潜艇vs怪物 | 操控潜艇武器攻击海底生物 |
| 潜艇vs潜艇 | 遭遇敌方潜艇，水下战斗 |
| 躲避战 | 某些敌人太强，只能躲避 |
| Boss战斗 | 深海Boss，需要策略击败 |

### 6.3 撤 (Withdraw) - 撤退机制

| 撤退触发 | 说明 |
|---------|------|
| 氧气不足 | 氧气消耗殆尽，必须撤退 |
| 损伤严重 | 潜艇损伤过高，继续会沉没 |
| 资源饱和 | 仓库满了，需要回船卸载 |
| 威胁警报 | 船发出警报，潜艇需支援 |
| 玩家决策 | 玩家主动决定撤退 |

| 撤退风险 | 说明 |
|---------|------|
| 追击 | 撤退时敌人可能追击 |
| 迷路 | 深海洞穴可能迷路 |
| 资源丢失 | 被追击时可能丢失部分资源 |
| 船已移走 | 船在移动，潜艇需要追赶 |

### 6.4 死亡与打捞机制

**撤离失败 = 死亡**

当潜艇被击毁或氧气耗尽未能撤退时，发生死亡事件。

**死亡后果**:
- 人员死亡 (尸体留在死亡点)
- 装备掉落 (留在死亡点，可回收)
- 潜艇沉没 (可能部分损坏)

**打捞方式**:

| 方式 | 代价 | 风险 | 时间 |
|------|------|------|------|
| 自己去打捞 | 消耗氧气/能源 | 死亡点可能有敌人 | 较长 |
| 花钱请系统捞 | 金币/资源费用 | 无风险 | 较快 |
| 派队员去捞 | 消耗人员体力 | 风险中等 | 中等 |

**打捞成功率**:

| 条件 | 成功率 |
|------|--------|
| 浅水区死亡 | 高 (90%) |
| 深海区死亡 | 中 (70%) |
| 深渊区死亡 | 低 (50%) |
| 死亡点有敌人 | 需先清怪才能打捞 |

**装备损坏度**:

| 状态 | 说明 |
|------|------|
| 完好 | 装备无损，直接回收使用 |
| 损坏 | 装备损伤，需修复后使用 |
| 永久损坏 | 深渊死亡可能永久丢失部分装备 |

**电疗复活机制**:

| 元素 | 设计 |
|------|------|
| 复活舱设施 | 船上需建造"复活舱"才能复活人员 |
| 复活代价 | 消耗电力 + 医疗资源 |
| 复活时间 | 需等待 3-5 分钟 |
| 虚弱状态 | 复活后短暂虚弱，战斗力降低 |
| 多人复活 | 复活舱等级决定同时复活人数 |

**死亡流程**:

```
死亡 → 尸体+装备留在死亡点 → 选择打捞方式 → 
尸体回船 → 电疗复活 → 人员恢复 (虚弱状态) → 
装备回收 → 损坏装备需修复
```

## 七、探索系统

### 7.1 海底世界结构

```
浅水区 (0-50m)
├── 一般资源 (矿物、燃料)
├── 小型敌人
├── 安全探索区

深水区 (50-200m)
├── 中级资源 (稀有金属、样本)
├── 中型敌人
├── 沉船遗迹

深海区 (200-500m)
├── 高级资源 (深海矿物、生物样本)
├── 大型敌人
├── 海底洞穴

深渊区 (500m+)
├── 终极资源 (深渊矿、远古遗物)
├── Boss级敌人
├── 极高风险
```

### 7.2 探索装备系统

| 装备类型 | 功能 |
|---------|------|
| 钻头 | 挖掘矿物、破坏障碍 |
| 抓取臂 | 抓取资源、物品 |
| 扫描仪 | 扫描周围资源、敌人 |
| 探照灯 | 照亮黑暗区域 |
| 声呐 | 探测远处敌人/资源 |
| 隐形系统 | 躲避敌人 |
| 深海抗压舱 | 进入深渊区必需 |

### 7.3 氧气与能源管理

- **氧气**: 潜艇氧气有限，需规划探索时间
- **能源**: 潜艇行动消耗能源，需携带能源罐
- **补给站**: 海底可能有补给点
- **紧急上升**: 氧气耗尽可紧急上升，但损伤大

### 7.4 海底山洞系统

**核心概念**:

| 特点 | 说明 |
|------|------|
| 随机生成 | 每次探索的山洞结构不同 |
| 多层迷宫 | 洞穴有分支、岔路、隐藏通道 |
| 资源丰富 | 山洞深处有稀有资源 |
| 危险伴随 | 洞穴内有特殊敌人、陷阱 |
| 探索奖励 | 完全探索可获得额外奖励 |

**山洞类型**:

| 类型 | 特点 | 深度范围 |
|------|------|----------|
| 浅水洞穴 | 结构简单，资源一般，敌人弱 | 50-100m |
| 珊瑚洞穴 | 美丽景观，有珊瑚资源，中等难度 | 100-200m |
| 岩石洞穴 | 结构复杂，矿物丰富，敌人强 | 200-300m |
| 深渊洞穴 | 极复杂迷宫，终极资源，Boss可能出现 | 300m+ |
| 隐藏洞穴 | 需要特殊条件发现，奖励极高 | 各深度 |

**山洞机制**:

| 机制 | 说明 |
|------|------|
| 地图系统 | 进入洞穴后自动生成地图（可查看已探索区域） |
| 分支岔路 | 多条路线，需要选择（可能有陷阱路线） |
| 隐藏通道 | 需要特殊装备发现（如扫描仪） |
| 氧气消耗 | 洞穴内氧气消耗更快（需谨慎规划） |
| 洞穴陷阱 | 岩石塌方、水流冲击、毒气区域 |
| 洞穴敌人 | 洞穴特有的敌人类型 |
| 洞穴宝藏 | 深处有宝藏箱，需完全探索解锁 |

**山洞特有敌人**:

| 敌人 | 出现位置 | 特点 |
|------|----------|------|
| 洞穴螃蟹 | 各类洞穴 | 攻击强，爬墙壁 |
| 暗影鱼 | 深处洞穴 | 隐形，突然袭击 |
| 岩石巨人 | 岩石洞穴 | 巨大，需要策略击败 |
| 洞穴Boss | 深渊洞穴 | 每个深渊洞穴可能有一个Boss |

**山洞特有资源**:

| 资源 | 说明 |
|------|------|
| 洞穴水晶 | 特有资源，用于高级建造 |
| 隐藏矿物 | 洞穴深处有稀有矿物 |
| 洞穴宝藏箱 | 完全探索解锁，奖励丰富 |
| 隐藏蓝图 | 洞穴墙壁上可能有技术蓝图 |

### 7.5 海底遗迹系统

**核心概念**:

| 特点 | 说明 |
|------|------|
| 古代文明 | 沉没的古代建筑、城市、神庙 |
| 故事线索 | 遗迹揭示世界背景故事 |
| 终极宝藏 | 遗迹深处有稀有宝藏和蓝图 |
| 守护者 | 遗迹有守护者或Boss |
| 解谜元素 | 需要解开谜题才能深入 |

**遗迹类型**:

| 类型 | 说明 | 特点 |
|------|------|------|
| 沉船遗迹 | 沉没的船只残骸 | 装备、物资、航海日志 |
| 古代神庙 | 深海神庙建筑 | 神秘宝藏、守护神 |

**遗迹机制**:

| 机制 | 说明 |

| 遗迹地图 | 遗迹内部有完整地图结构 |
| 解谜系统 | 需要解开谜题才能进入深处 |
| 守护者 | 遗迹深处有守护者或Boss |

| 谜题类型 | 说明 |

| 光线谜题 | 调整光线角度/镜子位置 |
| 水流谜题 | 控制水流方向/阀门 |

**遗迹守护者/Boss**:

| 守护者 | 遗迹类型 | 特点 |

| 神庙守护神 | 古代神庙 | 巨大Boss，需要策略击败 |

| 科研AI | 科研遗迹 | 机械Boss，高科技攻击 |
| 战争机器 | 战争遗迹 | 重型武器，需要躲避战术 |

| 奖励类型 | 说明 |

## 十二、天气与环境系统

### 12.1 天气系统

**天气类型**:

| 天气 | 说明 | 影响 |
|------|------|------|
| **晴天** | 天空晴朗，风平浪静 | 探索效率高，视野好，防守正常 |
| **多云** | 云层遮挡，光线减弱 | 探索视野降低，需探照灯 |
| **小雨** | 小雨降下，水面波动 | 探索视线干扰，氧气消耗略增 |
| **大雨** | 暴雨降下，水面巨波 | 探索困难，视野极差，氧气消耗增加 |
| **风暴** | 强风暴雨，天空危险 | 天空层敌人增多，探索暂停，防守加强 |
| **雷电风暴** | 强风暴+雷电 | 天空层电击伤害，EMP风险，探索暂停 |
| **浓雾** | 海面浓雾，视野极差 | 视野极低，雷达失效，需声呐导航 |
| **海啸预警** | 巨浪预警 | 水面层危险，船需加固，探索暂停 |
| **极寒天气** | 极地寒流来袭 | 温度骤降，需保暖装备，设备冻结风险 |
| **极热天气** | 热浪来袭 | 温度骤升，需降温装备，设备过热风险 |

**天气影响机制**:

| 影响类型 | 说明 |
|---------|------|
| **视野影响** | 不同天气影响视野范围 |
| **探索影响** | 不同天气影响探索效率、氧气消耗 |
| **防守影响** | 不同天气影响防守难度、特定敌人增多 |
| **温度影响** | 天气影响海面温度 |
| **设备影响** | 天气影响设备性能（冻结、过热、EMP） |
| **移动影响** | 天气影响船和潜艇移动速度 |

**天气周期系统**:

| 周期 | 说明 |
|------|------|
| **天气预报** | 雷达可预报未来天气 |
| **天气时长** | 每种天气持续一定时长 |
| **天气变化** | 天气会逐渐变化（晴→多云→小雨→大雨） |
| **天气预警** | 某些天气有预警时间（风暴、海啸） |
| **天气记录** | 记录天气变化历史 |

### 12.2 温度系统

**温度分布**:

| 区域 | 温度范围 | 说明 |
|------|---------|------|
| **海面层** | -20°C ~ 40°C | 受天气影响大，变化剧烈 |
| **浅水层** | 15°C ~ 25°C | 相对稳定，温暖 |
| **深水层** | 5°C ~ 15°C | 开始降温 |
| **深海层** | 0°C ~ 5°C | 冷温度，需保暖装备 |
| **深渊层** | -5°C ~ 0°C | 极冷，需高级保暖装备 |
| **海底火山区** | 50°C ~ 200°C | 极热，需耐热装备 |
| **冰下洞穴** | -10°C ~ -20°C | 极冷，需保暖装备 |
| **热泉区域** | 40°C ~ 80°C | 热温度，需耐热装备 |

**温度影响**:

| 温度状态 | 影响 |
|---------|------|
| **正常温度** | 无影响，正常探索 |
| **低温** | 氧气消耗增加，需保暖装备 |
| **极低温** | 设备冻结风险，人员冻伤风险 |
| **高温** | 氧气消耗增加，需降温装备 |
| **极高温** | 设备过热风险，人员烫伤风险 |

**温度装备需求**:

| 区域 | 需要装备 |
|------|---------|
| 深海层 | 保暖舱（Lv1） |
| 深渊层 | 保暖舱（Lv2）+ 保暖服 |
| 冰下洞穴 | 保暖舱（Lv2）+ 极寒服 |
| 海底火山区 | 耐热舱（Lv1） |
| 热泉区域 | 耐热舱（Lv1）+ 耐热服 |

**温度管理机制**:

| 机制 | 说明 |
|------|------|
| **温度显示** | 潜艇显示当前温度 |
| **温度预警** | 温度过高/过低时预警 |
| **温度适应** | 某些生物适应特定温度 |
| **温度伤害** | 温度过高/过低造成伤害 |
| **温度恢复** | 离开极端温度区域后恢复 |

## 十六、后续版本规划 - 联机海战系统

> **注意**: 联机海战是后续版本的额外功能，不在 MVP 和首发版本中。

### 16.1 核心概念

| 机制 | 说明 |
|------|------|
| 多人对战 | 玩家的大船与其他玩家的大船海战 |
| 资源争夺 | 海战胜利可掠夺对方资源 |
| 排名系统 | 海战积分 → 全球排行榜 |
| 竞技社交 | 增加游戏的竞技性和社交性 |

### 16.2 海战模式

| 模式 | 说明 | 特点 |
|------|------|------|
| **实时对战** | 两个玩家同时在线，实时海战 | 竞技性强，即时操作 |
| **异步攻防** | 玩家A进攻玩家B的船（B可能不在线） | 防守方船自动防守 |
| **组队海战** | 多玩家组队 vs 多玩家组队 | 团队协作，分工防守 |
| **夺宝海战** | 特殊海域，多人争夺稀有资源点 | 资源驱动，PVPvE |

### 16.3 海战战斗机制

| 机制 | 说明 |
|------|------|
| **船对船射击** | 船侧炮/鱼雷直接攻击对方船体 |
| **潜艇支援** | 派出潜艇骚扰对方船的水下层 |
| **登船战** | 派队员登对方船，内部破坏设施 |
| **防守配置** | 对战前可调整防守布局 |
| **损伤显示** | 对战中损伤实时显示双方 |

### 16.4 战前准备

| 准备项 | 说明 |
|--------|------|
| 防守调整 | 重新摆放炮台、调整防守策略 |
| 资源分配 | 分配弹药、氧气、能源 |
| 人员部署 | 分配人员到各防守层 |
| 装备检查 | 检查潜艇装备状态 |
| 战术选择 | 选择进攻策略（突袭/围攻/登船） |

### 16.5 战斗层级

| 层级 | 可操作内容 |
|------|-----------|
| 天空层 | 对空炮台攻击对方飞行单位 |
| 水面层 | 船侧炮攻击对方船体（主战场） |
| 水下层 | 潜艇攻击对方船水下部分 |
| 内部层 | 登船队员内部破坏（需成功登船） |

### 16.6 战后结算

| 结果 | 说明 |
|------|------|
| **胜利** | 获得战利品（对方资源/装备） |
| **失败** | 损失部分资源，船需修复 |
| **平局** | 双方都有损失，无战利品 |
| **逃遁** | 主动撤退，损失少量资源 |

### 16.7 资源掠夺规则

| 掠夺类型 | 说明 |
|---------|------|
| 基础资源 | 可掠夺对方 20-30% 基础资源 |
| 稀有资源 | 可掠夺对方 10-15% 稀有资源 |
| 装备 | 可掠夺对方掉落的装备 |
| 人员 | 不能掠夺人员（俘虏机制后续考虑） |

### 16.8 排名与积分系统

| 系统 | 说明 |
|------|------|
| **海战积分** | 胜利获得积分，失败扣分 |
| **排行榜** | 全球/好友排行榜 |
| **段位系统** | 积分 → 段位（青铜/白银/黄金/钻石） |
| **赛季重置** | 每赛季重置积分，赛季奖励 |
| **战绩记录** | 记录历史战绩，可查看对战详情 |

### 16.9 联机技术实现

| 技术点 | 实现建议 |
|--------|---------|
| **服务器架构** | 专用对战服务器 / P2P直连 |
