## Overview

音效系统管理17种行为音效（玩家/手电筒/物品/敌人/门状态）、2种环境氛围音效、16首BGM曲目和16种深海主题音效。音效通过优先级系统（最高/高/中/低/背景）管理播放，支持音效池（10播放器）、三类音量控制（主音量/音效音量/环境音量）和快速连续触发保护（is_playing检查）。BGM根据游戏场景（航行/战斗/Boss/遗迹/风暴等）动态切换。

---

## Player Fantasy

玩家应感受到：
- **物理反馈的音效真实感** — 行走每0.5秒播放沉重脚步声，冲刺每0.3秒播放急促脚步声，攻击有挥舞/射击声
- **警告音效的紧迫感** — 敌人靠近时响亮的ENEMY_NEARBY音效（音量1.0），低血量时心跳声加速
- **氛围音效的沉浸感** — 深海低频嗡鸣持续播放，气泡声随机触发，远处鲸鱼叫声偶尔传来
- **BGM随场景变化的情绪引导** — 平静海域悠扬钢琴，风暴来袭激烈管弦，Boss降临震撼鼓点

### 音效优先级

| 优先级 | 音效类型 | 说明 |
|--------|---------|------|
| 最高 | ENEMY_NEARBY, PLAYER_DEATH, DOOR_OPEN | 重要警告/事件 |
| 高 | PLAYER_ATTACK, ENEMY_ATTACK, KEY_COLLECT | 重要行为 |
| 中 | PLAYER_HURT, DOOR_UNLOCK, ENEMY_STUNNED | 一般行为 |
| 低 | PLAYER_WALK, ITEM_PICKUP, DOOR_LOCKED | 频繁触发 |
| 背景 | AMBIENT_HORROR, AMBIENT_TENSION | 持续循环 |

**优先级规则**: 高优先级音效可打断低优先级音效（同通道内），背景音效始终播放不被打断。

**BGM切换规则**: 场景变化时BGM交叉淡入淡出（fade out 1s → fade in 2s），道德选择弹窗出现时BGM降低3dB。

### 深海主题音效（16种）

**潜艇音效（4种）**: 引擎嗡鸣、声呐脉冲、水压警告、舱门开关。

**环境音效（5种）**: 深海低频(50Hz以下)、气泡上升、暗流涌动、鲸鱼叫声、海底地震。

**天气音效（3种）**: 暴雨击水、雷声、风暴呼啸。

**战斗音效（4种）**: 炮台射击、鱼雷发射、水中爆炸、命中反馈。

### 音量控制

| 音量类型 | 默认值 | 说明 |
|---------|--------|------|
| 主音量 | 1.0 | master_volume，影响所有音效 |
| 音效音量 | 0.8 | sfx_volume，影响行为音效 |
| 环境音量 | 0.3 | ambient_volume，影响背景音效 |

**音量调节**: 设置界面可分别调节三类音量，实时生效。

### 音效管理器

**音效池**: 10个音效播放器池，避免同时播放过多音效导致爆音。

**音效文件路径**: `assets/audio/` 目录下，17个行为音效wav文件 + 16首BGM + 16种深海主题音效。

**快速连续触发保护**: 音效播放前检查`is_playing()`，避免重叠导致音量爆表。

## Formulas

### 脚步声触发

```
if is_moving:
    footstep_timer += delta_time
    interval = is_sprinting ? 0.3 : 0.5
    if footstep_timer >= interval:
        play_sound(PLAYER_SPRINT if sprinting else PLAYER_WALK)
        footstep_timer = 0
else:
    footstep_timer = 0
```

### 最终音量计算

```
final_volume = base_volume × master_volume × sfx_volume  # 行为音效
final_volume = base_volume × master_volume × ambient_volume  # 环境音效

# 示例: PLAYER_ATTACK(base=0.9, master=1.0, sfx=0.8)
final_volume = 0.9 × 1.0 × 0.8 = 0.72
```

### BGM交叉淡入淡出

```
# 场景变化时切换BGM
fade_out(current_bgm, duration=1.0)
wait(0.5)  # 重叠0.5秒
fade_in(new_bgm, duration=2.0)
```

### 音效池分配

```
func play_sound(sound_id, priority):
    # 检查是否有空闲播放器
    player = find_free_player()
    if not player:
        # 找最低优先级的正在播放的音效
        lowest = find_lowest_priority_player()
        if lowest.priority < priority:
            lowest.stop()
            player = lowest
        else:
            return  # 无可用播放器，跳过

    player.stream = load_audio(sound_id)
    player.priority = priority
    player.volume = calculate_final_volume(sound_id)
    player.play()
```

## Edge Cases

1. **音效快速连续触发（如玩家连续受伤）**: 检查`is_playing()`，如果正在播放则跳过或重置播放位置，不叠加音量。
2. **10个音效播放器全部占用且新音效优先级不够**: 新音效被丢弃，不报错。下一帧再尝试。
3. **BGM切换时场景快速变化（如战斗→胜利→平静）**: 使用BGM切换队列，取消中间过渡BGM，直接播放最终场景BGM。
4. **环境音效循环播放时文件加载失败**: 使用静音占位文件（silent.wav），不报错，控制台输出警告。
5. **音量调节为0时**: 播放器仍正常工作，只是output volume为0，不暂停/停止播放。
6. **音效文件缺失**: 开发阶段输出错误日志，发布版本使用默认音效或静默处理。
7. **道德选择弹窗出现时BGM降低**: BGM音量降低3dB，弹窗关闭后1秒内平滑恢复。
8. **玩家戴耳机 vs 外放**: 音效系统不区分，但设置界面提供"空间音效"开关（3D定位音效仅耳机生效）。
9. **音效在低配置设备上播放延迟**: 音效文件预加载到内存（非流式加载），减少播放延迟。
10. **BGM播放完毕但场景未变化**: BGM自动循环播放，循环间0.5秒淡出淡入过渡。
