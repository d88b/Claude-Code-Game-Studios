## Overview

物品系统管理游戏中所有物品的类型分类、发光效果、拾取机制、稀有度分级、合成配方、商人交易、背包管理、掉落概率和持久化存储。系统通过ItemData资源类驱动物品属性，使用5级稀有度系统（普通/稀有/史诗/传说/独特）控制物品价值和视觉表现，支持2/3/1合成、配方合成和商人偏好定价，为游戏提供完整的物品经济循环。

---

## Player Fantasy

玩家应感受到：
- **物品发光的探索引导感** — 远处看到不同颜色的光晕，金色钥匙、紫色蓝图、红色医疗包，直觉知道物品类型
- **稀有物品发现的惊喜感** — 传说物品金色闪烁+呼吸脉冲光效，与普通物品的恒定发光截然不同
- **合成升级的成就感** — 2个低级电池合成高级电池，资源不浪费而是转化为更有价值的物品
- **商人交易的策略感** — 不同商人有不同偏好，卖给老海商远古遗物比卖给机械师多赚20%

### 拾取机制

- **拾取按键**: E键（interact动作）
- **检测流程**: 每帧检测 → 遍历所有物品 → 计算距离 → 找最近物品 → 距离 < pickup_range → 设置为nearby_item → 显示拾取提示
- **拾取流程**: 玩家按E → 检测nearby_item → 物品存在 → pickup_item() → 应用物品效果 → 播放拾取效果 → 物品消失 → 隐藏提示

### 拾取效果

| 物品类型 | 音效 | 音量 | 粒子数量 | 粒子寿命 |
|---------|------|------|---------|---------|
| 普通物品 | ITEM_PICKUP | 0.8 | 20个 | 0.5秒 |
| 钥匙 | KEY_COLLECT | 0.8 | 30个 | 0.5秒 |

**消失动画**: 拾取触发 → 创建Tween动画 → 物品缩放至Vector3.ZERO（0.3秒） → 物品隐藏 → 物品删除

### 合成系统

**合成类型**:

| 合成类型 | 材料数量 | 说明 | 成功率 |
|---------|---------|------|--------|
| 2合1合成 | 2个低级物品 → 1个高级物品 | 基础合成 | 100% |
| 3合1合成 | 3个低级物品 → 1个高级物品 | 进阶合成 | 受工坊等级影响 |
| 配方合成 | 特定组合 → 特定物品 | 需要蓝图解锁 | 100% |

**合成配方示例**:

| 合成产物 | 材料 | 所需工坊等级 | 成功率 |
|---------|------|-------------|--------|
| 高级电池 | 电池×2 | Lv2 | 100% |
| 浓缩医疗包 | 医疗包×2 + 稀有草药×1 | Lv2 | 100% |
| 高能氧气罐 | 氧气罐×2 + 深海矿×1 | Lv3 | 95% |
| 强化零件 | 基础零件×3 | Lv2 | 90% |
| 稀有蓝图碎片 | 未知残片×3 | Lv3 | 80% |
| 终极武器组件 | 远古遗物×1 + 深海矿×3 + 高级蓝图×1 | Lv5 | 100%（需配方） |

**合成成功率计算**:

```
基础成功率 = 配方固定成功率
工坊加成 = (工坊等级 - 所需工坊等级) × 5%
最终成功率 = min(100%, 基础成功率 + 工坊加成)
```

**合成失败处理**:

| 工坊等级差 | 失败后果 |
|-----------|---------|
| 刚好/超出 | 不失败，按基础成功率判定 |
| 低1级 | 失败返还50%材料 |
| 低2级 | 失败返还25%材料 |
| 低3级以上 | 不可合成 |

## Formulas

### 拾取范围检测

```
distance = (player_position - item_position).length()
if distance < pickup_range:
    show_pickup_prompt(item)
```

pickup_range: 普通物品2.5m，特殊物品3.0m。

### 合成成功率

```
基础成功率 = 配方固定成功率
工坊加成 = (工坊等级 - 所需工坊等级) × 5%
最终成功率 = min(100%, 基础成功率 + 工坊加成)
```

**示例**: Lv4工坊合成Lv3配方（基础80%）
```
工坊加成 = (4 - 3) × 5% = 5%
最终成功率 = min(100%, 80% + 5%) = 85%
```

### 交易价格

```
实际收购价 = 基础收购价 × (1 + 波动系数) × (1 + 商人偏好加成)
实际售价 = 基础售价 × (1 + 波动系数)
```

**示例**: 远古遗物卖给老海商（基础100金币，偏好+20%，波动+5%）
```
实际收购价 = 100 × (1 + 0.05) × (1 + 0.20) = 100 × 1.05 × 1.20 = 126金币
```

### 掉落概率

```
最终掉落率 = 基础掉落率 × (1 + 幸运值 × 0.005) × 海域修正 × Boss修正
```

**示例**: 远古遗物在深海区（基础5%，幸运值15，无Boss修正）
```
最终掉落率 = 5% × (1 + 15 × 0.005) × 1.0 × 1.0 = 5% × 1.075 = 5.375%
```

### 稀有掉落概率参考

| 稀有度 | 基础掉落率 | 示例来源 |
|--------|-----------|---------|
| 普通 | 60-80% | 常规资源点/小怪掉落 |
| 稀有 | 15-25% | 精英怪/特定海域掉落 |
| 史诗 | 5-10% | Boss/遗迹/隐藏区域掉落 |
| 传说 | 1-3% | 终极Boss/隐藏Boss掉落 |
| 独特 | <1% | 剧情固定获得，不可掉落 |

## Edge Cases

1. **背包已满时拾取物品**: 提示"背包已满"，物品保留在场景中不消失，玩家可丢弃其他物品后再拾取。
2. **独特物品不可丢弃**: 独特物品（红色稀有度）和钥匙/关键任务物品的丢弃按钮禁用，防止误操作。
3. **合成失败材料损失**: 工坊等级低于配方需求2级以上时，失败返还25%材料；低3级以上系统禁止合成操作。
4. **商人收购价为0或负数**: 如果波动系数和厌恶减成叠加后价格为负，实际收购价设为1金币（最低值）。
5. **堆叠物品部分拾取**: 如果拾取物品只有部分空间可堆叠（如背包中已有8/10个电池），拾取时填满已有堆叠后剩余放入空槽。
6. **Boss区域采集资源限时5分钟**: Boss被击败后，掉落资源5分钟内可采集，超时消失。
7. **扫描仪未装备时隐藏资源不可见**: 隐藏资源点需要扫描仪探测（10%概率），未装备扫描仪时不会提示隐藏资源。
8. **Boss召唤道具重复挑战掉落衰减**: 重复挑战同Boss，每次掉落率-10%，最低50%。
9. **物品效果应用时目标已满**: 如氧气已满时使用氧气罐，罐被消耗但不产生额外氧气（无溢出）。
10. **存档加载后物品metadata恢复**: 存档加载时恢复物品的剧情标记、来源标记等metadata，确保任务进度不丢失。
