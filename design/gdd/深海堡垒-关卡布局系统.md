## Overview

关卡布局系统管理9个海域的关卡结构设计，包括墙壁系统、障碍物系统、资源分布、敌人布局、动态关卡生成（基于种子的随机布局+BFS路径验证）、视线设计、节奏控制、引导设计和奖励可见性。系统使用Godot TileMap进行2D关卡构建，支持预制件系统和关卡自动化测试。

---

## Player Fantasy

玩家应感受到：
- **每个海域独特风格的探索新鲜感** — 从开阔珊瑚礁到深渊迷宫，每个海域有截然不同的关卡体验
- **利用掩体和通道进行战术选择的策略感** — 墙壁和障碍物创造掩护、伏击、绕行等玩法
- **发现隐藏区域和稀有奖励的惊喜感** — 奖励部分可见但需绕路到达，激发探索欲
- **随难度递增逐步复杂化的挑战感** — 从简单线性路径到多层迷宫，关卡复杂度逐步提升

| 区域 | 说明 | 特点 |

### 特殊地形

**洞穴系统**: 入口(5m宽) → 通道(3m宽×20m长, 1-2潜伏敌人) → 大厅(15m×15m, 3-4巡逻敌人) → 宝藏室(8m×8m, 1个Boss) → 出口。

**遗迹系统**: 入口 → 机关走廊(3m宽×30m长, 地刺/落石/毒气/箭矢陷阱) → 主殿(20m×20m) → 密室(10m×10m, 密码锁) → 奖励室(8m×8m)。

**沉船系统**: 甲板(开放) → 货舱(狭窄通道) → 船长室(相对宽敞) → 底部(水浸减速) → 隐藏密室(需密码/机关)。

### 动态关卡生成

**种子系统**: 相同种子生成相同关卡，玩家可分享种子挑战相同布局。

**生成流程**: 输入种子 → 初始化RNG → 生成墙壁布局 → 生成障碍物 → 生成资源点 → 生成敌人出生点 → 生成钥匙位置 → 生成门和锁 → BFS路径验证 → 输出关卡。

**BFS路径验证**: 验证玩家出生点到出口门、到所有钥匙、到所有资源点的可达路径。如果验证失败（100次尝试），回退到预设计关卡。

**随机分布算法**: 使用泊松盘采样(Poisson Disk Sampling)确保元素间距不小于最小距离，根据距离出生点的远近分配资源稀有度。

| 简单 | 20% | 低 | 高 | 少 | 集中 |


## Formulas

### 密度计算

```
actual_density = base_density × sea_area_coeff × difficulty_coeff

sea_area_coeff: 1号海域=1.0, 递增到9号=2.0
difficulty_coeff: 简单=0.7, 普通=1.0, 困难=1.4, 噩梦=1.8
```

**示例**: 深海区(4号, 海域系数1.2) + 困难难度
```
墙壁密度 = 35% × 1.2 × 1.4 = 58.8%
```

### AI密度计算

```
actual_ai_density = base_density × layout_coeff × sea_area_coeff

layout_coeff: 开阔区域=1.5, 狭窄走廊=0.7, 多层结构=1.2, 迷宫=0.8

示例: 深海区(海域系数1.3) + 开阔区域(布局系数1.5) + 基础密度3
实际密度 = 3 × 1.5 × 1.3 = 5.85 ≈ 6个AI
```

### 深度速度修正（多层关卡）

```
depth_speed_modifier(depth) = max(0.4, 1.0 - (depth - 100) / 1000)

浅水区(0-100m): 1.0
深水区(100-300m): 0.8
深海区(300-500m): 0.6
深渊区(500m+): 0.4
```

### 暗角强度（基于HP）

```
vignette_strength = 0.8 × 0.4 × (1.0 - (HP / max_HP) × 0.5)

HP 100% → 0.16
HP 50% → 0.24
HP 10% → 0.38
```

### 资源稀有度分布

```
# 泊松盘采样后根据距离分配稀有度
normalized_distance = distance_to_spawn / max_distance

if randf() < normalized_distance × 0.8:
    place_rare_resource(point)
else:
    place_common_resource(point)

# 距离出生点越远，稀有资源概率越高
# 最大距离处: 0.8 = 80%稀有资源
# 出生点附近: 0%稀有资源
```

## Edge Cases

1. **BFS路径验证失败**: 如果100次随机生成都无法找到从出生点到出口的可达路径，回退到预设计关卡(fallback level)。
2. **种子生成重复关卡**: 相同种子值必须生成完全相同的关卡布局。使用确定性RNG（不调用系统随机种子）。
3. **资源/钥匙全部不可达**: BFS验证时发现某个钥匙或资源点被墙壁完全包围，重新生成该元素位置或调整墙壁布局。
4. **迷宫死胡同过多**: 深渊迷宫死胡同比例超过40%时，玩家可能感到沮丧。生成后检测死胡同数量，超标则调整。
5. **动态障碍物阻断关键路径**: 移动障碍物（如暗流、沉船残骸）在运行时可能阻断BFS验证时畅通的路径。运行时每2秒重新验证关键路径。
6. **关卡尺寸与性能**: 9号遗迹区120m×120m最大关卡，TileMap元素过多可能导致性能问题。使用TileMap chunking，仅渲染玩家可视范围内的区块。
7. **热泉区岩浆伤害与路径**: 岩浆池作为危险区域可能完全阻断玩家路径。生成时确保至少有一条不经过岩浆的安全路径到达出口。
8. **冰下区冰层打破**: 冰层可打破后暴露下层通道，可能意外创建捷径到达出口。打破冰层后重新运行BFS验证路径合理性。
9. **遗迹机关陷阱锁死**: 密码门/机关锁如果因为随机生成导致密码无法解开（钥匙位置被墙挡住），路径验证应检测到并重新生成。
10. **传送门循环**: 深渊迷宫传送门如果形成循环或把玩家送回起点，可能导致无限循环。传送门目标点必须经过验证，确保推进玩家向出口方向。
11. **敌人出生点被墙挡住**: 随机生成的敌人出生点如果被墙壁包围，敌人无法移动到关卡其他区域。生成后验证每个敌人出生点有至少一条到出口的路径。
12. **多钥匙关卡钥匙顺序**: 如果出口门需要3把钥匙，确保钥匙1不需要钥匙2才能到达（无循环依赖）。使用拓扑排序验证钥匙获取顺序。

## Acceptance Criteria

- [ ] 相同种子值生成的关卡，两次运行布局完全一致（墙壁、资源、敌人位置相同）
- [ ] BFS路径验证确认玩家出生点到出口门存在可达路径
- [ ] BFS路径验证确认玩家到所有钥匙存在可达路径
- [ ] 多钥匙关卡中钥匙获取顺序无循环依赖（拓扑排序验证通过）
- [ ] 深渊迷宫死胡同比例不超过40%
- [ ] 热泉区岩浆池不阻断所有到达出口的路径（至少1条安全路径）
- [ ] 浅海区可视距离为40m，深渊区为10m
- [ ] 困难难度下墙壁密度 = 基础密度 × 海域系数 × 1.4（难度系数）
- [ ] 资源稀有度随距离出生点递增（出生点附近0%稀有，最远处约80%）
- [ ] 关卡节奏遵循安全区→危险区交替模式，危险区间距在30-50m范围内
- [ ] 起始区引导强度为强，危险区为弱
- [ ] 9号遗迹区(120m×120m)关卡运行时帧率不低于55fps（TileMap chunking生效）
- [ ] 所有关卡参数（密度、可视距离、迷宫复杂度、传送门数量）可通过配置文件调整，无需修改代码
- [ ] 动态障碍物阻断关键路径时，运行时2秒内检测到并通知AI重新寻路
- [ ] 波次防守系统中立体围攻波次可同时在天空+水面+水下三层生成敌人
- [ ] TileMap层级按Z-Index正确分层（背景-2 → 装饰-1 → 地面0 → 墙壁1 → 交互2 → 敌人3 → 特效4）
