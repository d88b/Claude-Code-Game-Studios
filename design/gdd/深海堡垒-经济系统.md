## Overview

经济系统是一个多层次、动态化的交易体系，包含四种货币（金币/深海贝壳/能量晶体/海盗代币）、六种商人类型（流动/水下市场/深海稀有/黑市/避难所/遗迹）、完整的价格波动机制（供需关系/世界事件/商人关系/时间因素）、以物易物、黑市交易和讨价还价小游戏。经济系统贯穿游戏全程，是玩家获取资源、升级装备、推进剧情的重要途径。

---

## Player Fantasy

玩家应感受到：
- **讨价还价的策略乐趣** — "太低了便宜点"、"我常来照顾生意"、"别家可比这便宜"，每种谈判策略带来不同结果
- **市场波动的真实感** — 大量出售铁矿导致跌价10-30%，风暴期间氧气涨价30-80%，市场有生命
- **黑市的高风险刺激** — 夜间20:00-04:00开放，15%被发现率，禁用武器和禁忌科技，被巡逻队抓到罚款50%金币
- **多货币体系的深度** — 金币买日常、贝壳换稀有、能量晶体买远古、海盗代币走黑市，每种货币有独特生态

## Detailed Rules

### 货币体系

| 货币 | 获取方式 | 主要用途 | 稀有度 | 携带上限 |
|------|---------|---------|--------|---------|
| 金币 | 击败敌人、任务、出售资源 | 基础交易，日常资源与装备 | 普通 | 99,999 |
| 深海贝壳 | 深海采集、遗迹发现、特殊任务 | 稀有物品、特殊装备 | 稀有 | 9,999 |
| 能量晶体 | Boss掉落、深渊采集、终极任务 | 终极交易、远古科技 | 极稀有 | 999 |
| 海盗代币 | 海盗活动、黑市任务、击败海盗精英 | 黑市交易、海盗装备 | 特殊 | 9,999 |

**金币获取**: 普通敌人5-30/次，精英50-200，Boss 500-2000，任务100-1000，日常50-150/天。

**货币汇率**:

| 兑换 | 基准汇率 | 浮动范围 | 地点 |
|------|---------|---------|------|
| 金币→贝壳 | 500:1 | 400-700:1 | 水下市场 |
| 贝壳→能量晶体 | 10:1 | 8-15:1 | 深海稀有商人 |
| 金币→海盗代币 | 100:1 | 80-150:1 | 黑市 |
| 海盗代币→金币 | 120:1 | 100-150:1 | 黑市 |
| 贝壳→金币 | 450:1 | 350-600:1 | 任意商人 |

汇率每日波动±10%，受市场供需和世界事件影响。

### 商人类型

| 类型 | 出现方式 | 交易内容 | 价格水平 | 接受货币 |
|------|---------|---------|---------|---------|
| 流动商人 | 随机海域，每3-5天出现 | 基础资源、普通装备 | 基准±10% | 金币 |
| 水下市场商人 | 固定（水下市场） | 各种资源、中级装备、蓝图 | 基准±5% | 金币、贝壳 |
| 深海稀有商人 | 深渊区隐藏，每章1-2次 | 稀有资源、高级蓝图、深渊装备 | 基准+50%~+100% | 贝壳、晶体 |
| 黑市商人 | 隐藏位置，条件解锁 | 非法装备、禁忌科技、海盗武器 | 基准-20%~+200% | 海盗代币 |
| 避难所商人 | 固定（避难所内） | 生活用品、食物、医疗、建材 | 基准-5%~+5% | 金币、以物易物 |
| 遗迹商人 | 固定（遗迹内） | 远古遗物、古代蓝图、遗迹碎片 | 特殊定价 | 遗迹碎片、晶体 |

**商人刷新**: 固定商人永久存在（库存每周刷新）、半固定商人按章节刷新、随机商人每天20%概率出现（停留1-2天）、隐藏商人条件满足后永久解锁。

| 资源 | 基准价(金币) | 浮动范围 |
|------|------------|---------|
| 铁矿×10 | 50 | 30-80 |
| 深海矿×10 | 200 | 100-350 |
| 木材×10 | 40 | 20-70 |
| 食物×10 | 30 | 15-60 |
| 生物样本×1 | 150 | 50-300 |
| 氧气罐(满) | 100 | 50-200 |
| 弹药×10 | 80 | 40-150 |
| 远古碎片×1 | 2000 | 面议 |

**装备与蓝图价格**:

| 类型 | 基准价(金币) | 备注 |
|------|------------|------|
| 蓝图(普通) | 500 | 300-800 |
| 蓝图(稀有) | 2000 | 1000-4000 |

| 武器(稀有) | 800-2000 | 部分需贝壳 |

### 市场波动机制

**供需关系**: 每种资源维护全局供需指数(0-100)，50=平衡，<50=供大于求(降价)，>50=供不应求(涨价)。指数每日向50回归5%。

**玩家行为影响**: 大量出售某资源(>100单位)→价格下跌10-30%，持续3-7天。长期不购买(>10天)→价格上涨5-20%。商人库存不足(<10%)→价格上涨30-100%。

**世界事件影响**:

| 事件 | 影响资源 | 价格变化 | 持续时间 |
|------|---------|---------|---------|
| 风暴来袭 | 氧气、弹药、修复材料 | +30%~+80% | 风暴期+1天 |
| 海盗战争 | 武器、弹药、护甲 | +50%~+100% | 战争持续期 |
| 和平时期 | 建材、食物、生活用品 | -15%~-30% | 和平持续期 |
| 遗迹发现潮 | 远古遗物、遗迹碎片 | -20%~-40% | 3-5天 |
| 深海地震 | 深海矿、深渊材料 | +40%~+60% | 2-3天 |

**商人好感度价格修正**:

| 好感区间 | 价格修正 | 额外优惠 |
|---------|---------|---------|
| 0-20(敌对) | +50% | 无 |
| 21-40(冷淡) | +15% | 无 |
| 41-60(中立) | 0% | 无 |
| 61-80(友好) | -10% | 解锁隐藏商品 |
| 81-100(亲密) | -20% | 解锁稀有商品 |

**时间因素**: 每日波动±5%，每周供需回归30%，章节推进基准价调整±10%。

### 以物易物机制

**规则**: 按物品基准价计算交换比例，商人收取10-30%溢价。避难所商人-10%溢价，流动商人+10%溢价。好感度越高溢价越低。黑市和遗迹商人不可用。

### 黑市交易系统

**进入条件**: 海盗代币≥10 + 完成"暗道"任务 + 仅夜间(20:00-04:00) + 隐藏海域坐标。

**风险系统**:

| 行为 | 被发现率 | 后果 |
|------|---------|------|
| 进入黑市 | 5% | 无 |
| 购买禁用武器 | 15% | 巡逻队出现 |
| 购买禁忌科技 | 25% | 通缉+罚款 |
| 被巡逻队发现 | 100% | 罚款50%金币或战斗 |

**风险规避**: 贿赂巡逻队(50%逃脱，需100代币)、夜间行动(-30%发现率)、红帆好感80+(-20%)、伪装道具(-40%)。

### 讨价还价系统

**流程**: 选择物品 → 商人报价 → 选择谈判策略 → 商人回应(同意/拒绝/反提议) → 最多3轮 → 最终价格。

**谈判策略**:

| 策略 | 降价幅度 | 好感影响 | 成功率加成 | 适用 |
|------|---------|---------|-----------|------|
| 直接砍价 | 5-10% | 0 | +0% | 所有 |
| 利用关系 | 8-15% | +1 | +5% | 好感41+ |
| 比价威胁 | 10-18% | -2 | +2% | 所有 |
| 批量折扣 | 12-20% | +3 | +10% | 市场/避难所 |
| 情感攻势 | 5-12% | +2 | +3% | 流动/避难所 |
| 海盗式威胁 | 15-25% | -10 | +15% | 仅黑市 |

**成功率**: 基础30%，好感61-80 +10%，好感81-100 +25%，批量折扣+15%。失败则好感-2，连续成功3次好感+5。

### 交易界面

**布局**: 左上方显示货币余额和商人好感，左侧为玩家出售区，右侧为商人出售区，中间为交易结算按钮，底部为讨价还价/赠送礼物/对话/离开按钮。

## Formulas

### 价格计算

```
def calculate_price(base_price, resource_id, merchant_id):
    price = base_price

    # 供需修正
    supply_demand = get_supply_demand_index(resource_id)  # 0-100
    price *= (0.7 + (supply_demand / 100) * 0.6)  # 0.7x ~ 1.3x

    # 世界事件修正
    price *= get_world_event_modifier(resource_id)

    # 商人好感度修正
    affinity = get_merchant_affinity(merchant_id)
    if affinity >= 81:  price *= 0.80
    elif affinity >= 61: price *= 0.90
    elif affinity <= 20: price *= 1.50
    elif affinity <= 40: price *= 1.15

    # 每日随机波动
    price *= random.uniform(0.95, 1.05)

    # 讨价还价修正
    price *= (1.0 - bargain_discount)

    return round(price / 5) * 5  # 5的倍数取整
```

### 供需指数更新

```
# 每日更新
supply_demand[resource] += player_sell_amount * 2 - player_buy_amount
supply_demand[resource] = clamp(supply_demand[resource], 0, 100)

# 向平衡回归
supply_demand[resource] = supply_demand[resource] + (50 - supply_demand[resource]) * 0.05

# 每周额外回归30%
if day % 7 == 0:
    supply_demand[resource] = supply_demand[resource] + (50 - supply_demand[resource]) * 0.30
```

### 以物易物估值

```
trade_value = sum(item.base_price * item_count for item in offered_items)
required_value = sum(item.current_price * item_count for item in wanted_items)
premium = get_barter_premium(merchant_id, affinity)  # 1.10 - 1.30

can_trade = trade_value >= required_value * premium
```

### 讨价还价成功率

```
base_success = 0.30
if affinity >= 81: success += 0.25
elif affinity >= 61: success += 0.10

success += strategy_bonus  # 根据策略+0%~+15%

if used_comparison_threat: affinity -= 2  # 比价威胁降低好感

result = random.uniform(0, 1) < success
```

## Edge Cases

1. **玩家大量出售资源导致价格暴跌后想后悔**: 价格已生效，不可撤销。系统提示"大量出售影响了市场价格"。
2. **黑市交易中被巡逻队发现但玩家无金币**: 改为强制战斗或扣除等值资源（按当前市价换算）。
3. **讨价还价3轮全部失败**: 商人维持原价，好感-2，不允许继续讨价还价（本轮交易锁定）。
4. **以物易物时玩家物品价值略低于需求**: 显示"还需X金币等值物品"，允许补充物品直到满足。
5. **货币携带量超过上限**: 超出部分存入仓库（非背包），不丢弃。
6. **商人库存为0但玩家想购买**: 显示"暂时缺货"，告知补货时间（下次刷新）。
7. **汇率波动期间进行货币兑换**: 使用兑换瞬间的汇率，不受后续波动影响。
8. **世界事件结束但玩家已在交易中**: 当前交易使用事件期间价格，下一次交易恢复正常。
9. **黑市夜间开放时间窗口**: 20:00开放，04:00关闭。04:00时仍在黑市的玩家收到30秒倒计时警告，超时被强制传送出黑市。
10. **商人死亡/离开后未完成交易**: 交易取消，玩家物品和货币全部退回。

## Tuning Knobs

| 参数 | 当前值 | 安全范围 | 影响 |
|------|--------|---------|------|
| 金币携带上限 | 99,999 | 50,000-999,999 | 影响经济规模 |
| 贝壳/金币基准汇率 | 500:1 | 200-1000:1 | 影响贝壳价值 |

| 供需指数周回归率 | 30% | 10-50% | 影响长期平衡 |

## Acceptance Criteria

- [ ] 四种货币（金币/深海贝壳/能量晶体/海盗代币）各有独立获取方式和用途
- [ ] 货币携带上限正确：金币99,999、贝壳9,999、晶体999、代币9,999
- [ ] 六种商人类型各有独立交易内容、价格水平和接受货币
- [ ] 价格计算公式包含供需修正、世界事件修正、好感度修正、随机波动
- [ ] 供需指数0-100，每日向50回归5%，每周额外回归30%
- [ ] 大量出售资源(>100单位)导致价格下跌10-30%，持续3-7天
- [ ] 世界事件正确影响对应资源价格（风暴+30-80%，海盗战争+50-100%等）
- [ ] 商人好感度正确修正价格（敌对+50%，亲密-20%）
- [ ] 以物易物按基准价计算，避难所商人-10%溢价，流动商人+10%溢价
- [ ] 黑市仅夜间(20:00-04:00)开放，进入需海盗代币≥10
- [ ] 黑市风险系统正确计算被发现率和后果
- [ ] 讨价还价支持6种策略，最多3轮，基础成功率30%
- [ ] 讨价还价失败好感-2，连续成功3次好感+5
- [ ] 价格计算结果取5的倍数
- [ ] 货币/市场状态数据存入存档系统
