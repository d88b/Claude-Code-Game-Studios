## Overview

结局系统设计了6种不同的结局（新家园/深渊统治/海洋守护者/永恒漂泊/远古觉醒/悲剧沉没），通过道德值、NPC好感度、船员存活率、船体完整度、远古武器选择、隐藏任务完成等多维度因素综合判定。每种结局有独特的触发条件、6步流程、叙事动画和奖励内容。结局判定按优先级执行（失败→隐藏→和平→野心→最终选择→默认），支持结局画廊查看、多周目继承和全收集成就。

---

## Player Fantasy

玩家应感受到：
- **结局多样性的重玩动力** — 6种结局从35%的新家园到2%的远古觉醒，每条路线都有独特叙事和视觉风格
- **选择权重的真实感** — 道德值、NPC好感、船员存活率、隐藏任务……每个决定都在悄然塑造最终命运
- **结局动画的仪式感** — 从序幕(15-30s)到主体(60-120s)到尾声(15-30s)到制作人员(60s)，每种结局有独特色调和音乐
- **全收集的挑战感** — 6种结局+12种道德选择+8个NPC招募+7条隐藏链+12个远古碎片，50+成就等待解锁

## Detailed Rules

### 六种结局概览

| # | 结局 | 类型 | 预估达成率 | 情感基调 | 解锁内容 |
|---|------|------|-----------|---------|---------|
| 1 | 新家园 | 标准结局 | 35% | 希望、温暖 | 新家园+难度 |
| 2 | 深渊统治 | 野心结局 | 15% | 力量、野心 | 深渊统治模式 |
| 3 | 海洋守护者 | 和平结局 | 5% | 和谐、宁静 | 和平模式 |
| 4 | 永恒漂泊 | 自由结局 | 20% | 孤独、自由 | 无尽模式 |
| 5 | 远古觉醒 | 隐藏结局 | 2% | 神秘、超越 | 真结局/续作伏笔 |
| 6 | 悲剧沉没 | 失败结局 | 23% | 悲壮、遗憾 | 从检查点重试 |

### 结局触发条件

**结局1：新家园（标准结局）**

| 条件 | 要求 |
|------|------|
| 完成所有章节主线 | 第七章全部任务 |
| 船员存活率 | ≥50% |
| 船体完整度 | ≥30% |
| 最终选择 | "共享新家园" |
| 道德值 | ≥-20（不能极端邪恶） |

**结局2：深渊统治（野心结局）**

| 条件 | 要求 |
|------|------|
| 完成前六章主线 | 至第六章结束 |
| 远古武器选择 | "用于攻击" |
| 海盗/敌对势力好感 | 低（敌对或冷淡） |
| 船员忠诚度 | ≥60% |
| 道德值 | ≤-21（偏冷酷） |
| 击败终极Boss | 完成最终战斗 |

**结局3：海洋守护者（和平结局）**

| 条件 | 要求 |
|------|------|
| 完成生态守护者隐藏链 | 全部3个任务 |
| 不主动击杀非敌对生物 | 整个游戏过程0次 |
| 珊瑚好感度 | ≥80 |
| 全部NPC好感度 | 均≥60 |
| 击败终极Boss | 使用防御/和平方式 |
| 道德值 | ≥+61（偏仁慈） |

**结局4：永恒漂泊（自由结局）**

| 条件 | 要求 |
|------|------|
| 完成前六章主线 | 至第六章结束 |
| 不加入任何NPC阵营 | 未与任何阵营结盟 |
| 最终选择 | "继续航行" |
| 道德值 | -20~+20（中立） |

**结局5：远古觉醒（隐藏结局）**

| 条件 | 要求 |
|------|------|
| 远古遗迹碎片 | 12个全部收集 |
| 远古信号隐藏链 | 全部5个任务 |
| 神秘信号解读 | 3个全部解读 |
| NPC好感度 | 均≥50 |
| 隐藏任务链 | 7条全部完成 |
| 道德值 | 任意（不限） |

**结局6：悲剧沉没（失败结局）**

| 条件 | 要求 |
|------|------|
| 船员存活率 | <10% |
| 或船体完整度 | <5% |
| 或最终Boss战失败 | Boss战中失败 |

### 结局判定优先级

```
步骤1: 检查失败条件
  船员<10% 或 船体<5% → 结局6（悲剧沉没）

步骤2: 检查隐藏结局条件
  全碎片(12)+全隐藏链+NPC≥50 → 结局5（远古觉醒）

步骤3: 检查和平结局条件
  生态链+0击杀+珊瑚≥80+道德≥61 → 结局3（海洋守护者）

步骤4: 检查野心结局条件
  攻击路线+敌对好感+道德≤-21+忠诚度≥60 → 结局2（深渊统治）

步骤5: 检查最终选择
  "共享新家园"+道德≥-20 → 结局1（新家园）
  "独占新家园" → 结局2（深渊统治）
  "继续航行" → 结局4（永恒漂泊）

步骤6: 默认
  不满足以上任何条件 → 结局4（永恒漂泊）
```

### 结局流程

每种结局6步流程：

| 步骤 | 内容 | 时长 |
|------|------|------|
| 1 | 序幕 — 过场动画/对话，铺垫结局氛围 | 15-30秒 |
| 2-4 | 主体 — 核心叙事（根据结局不同） | 60-120秒 |
| 5 | 尾声 — 收尾/暗示，过渡到制作人员 | 15-30秒 |
| 6 | 制作人员名单 — 背景音乐+滚动字幕+结局CG | 60秒 |

**各结局视觉风格**:

| 结局 | 色调 | 音乐风格 | 关键视觉元素 |

| 海洋守护者 | 明亮（蓝/绿/白） | 和谐、宁静、钢琴 | 海洋生物、阳光穿透海面 |
| 永恒漂泊 | 蓝灰（深蓝/灰/银） | 孤独、悠远、吉他 | 星空、大海、孤船 |

## Formulas

### 结局判定公式

```
def determine_ending(conditions):
    # Step 1: Failure check
    if conditions.crew_survival_rate < 0.10 or conditions.ship_integrity < 0.05:
        return ENDING_6_TRAGEDY

    # Step 2: Hidden ending
    if (conditions.ancient_fragments == 12 and
        conditions.hidden_chains_completed == 7 and
        conditions.npc_affinities_avg >= 50):
        return ENDING_5_AWAKENING

    # Step 3: Peace ending
    if (conditions.eco_chain_completed and
        conditions.non_hostile_kills == 0 and
        conditions.coral_affinity >= 80 and
        conditions.moral_value >= 61):
        return ENDING_3_GUARDIAN

    # Step 4: Ambition ending
    if (conditions.ancient_weapon_choice == "attack" and
        conditions.enemy_faction == "hostile" and
        conditions.moral_value <= -21 and
        conditions.crew_loyalty >= 0.60):
        return ENDING_2_DOMINATION

    # Step 5: Final choice
    if conditions.final_choice == "share" and conditions.moral_value >= -20:
        return ENDING_1_NEW_HOME
    elif conditions.final_choice == "monopolize":
        return ENDING_2_DOMINATION
    elif conditions.final_choice == "sail_on":
        return ENDING_4_WANDERING

    # Step 6: Default
    return ENDING_4_WANDERING
```

## Edge Cases

1. **多个结局条件同时满足**: 按优先级顺序判定（失败→隐藏→和平→野心→选择→默认），先满足者优先。
2. **最终选择弹窗时玩家不操作**: 弹窗持续显示，不自动选择，游戏暂停等待玩家决定。
3. **结局动画播放中玩家按ESC**: ESC不跳过结局动画（这是叙事体验的核心部分），但可跳过制作人员名单。
4. **结局6（悲剧沉没）后选择重试**: 从最后检查点重新开始，保留已收集的远古碎片和怪物图鉴（多周目继承规则）。
5. **结局画廊中查看未解锁结局**: 显示灰色占位图和"???"描述，不展示具体内容。
6. **结局判定所需的NPC已死亡**: NPC好感度视为0，影响结局判定（如海洋守护者需要珊瑚≥80，珊瑚死亡则不满足）。
7. **通关后存档清理与结局画廊冲突**: 存档清理不影响结局画廊数据（结局画廊存储在独立的unlock数据中）。
8. **远古觉醒结局触发但玩家未完成最终Boss战**: 远古觉醒为最高优先级（除失败外），Boss战作为结局动画的一部分自动播放。
9. **多周目继承后道德值重置但玩家想要之前路线**: 道德值强制重置为0，确保每周目都是独立体验。
10. **结局数据统计时某些字段为空**: 使用默认值（0或null），不报错，UI显示"—"。

## Acceptance Criteria

- [ ] 6种结局各有独立的触发条件、流程和叙事动画
- [ ] 结局判定按优先级执行：失败→隐藏→和平→野心→选择→默认
- [ ] 结局1需要完成全部7章+船员存活≥50%+船体≥30%+道德≥-20+"共享"选择
- [ ] 结局3需要生态链完成+0次非敌对击杀+珊瑚好感≥80+道德≥61
- [ ] 结局5需要12个碎片+7条隐藏链+NPC好感≥50
- [ ] 结局6在船员<10%或船体<5%或Boss战失败时触发
- [ ] 每种结局有独特的视觉风格（色调/音乐/关键视觉元素）
- [ ] 结局动画结构：序幕(15-30s)→主体(60-120s)→尾声(15-30s)→制作人员(60s)
- [ ] 结局画廊可查看已解锁结局CG和统计数据
- [ ] 未解锁结局在画廊中显示灰色占位+"???"
- [ ] 通关后存档清理不影响结局画廊解锁状态
- [ ] 结局6提供从检查点重试选项
- [ ] 多周目继承规则正确：科技50%、图鉴100%、地图100%、道德重置、好感重置
- [ ] 结局数据结构包含unlocked_endings/ending_conditions/ending_gallery
- [ ] 结局数据存入存档系统
