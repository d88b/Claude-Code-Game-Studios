## Overview

设置菜单系统管理5大类设置选项（画面/音效/操控/游戏/系统），包含20+画面设置项、8+音效设置项、12键位映射+灵敏度+震动操控设置、4级难度+教程+辅助功能游戏设置和语言+存档管理+重置系统设置。设置修改后即时生效，3秒后自动保存为JSON文件(`user://settings.json`)。辅助功能系统覆盖视觉/听觉/操作/认知四大类共22项功能，支持首次启动推荐系统。

---

## Player Fantasy

玩家应感受到：
- **设置的即时反馈** — 拖动亮度滑块画面立即变亮/变暗，调整音量立刻听到变化，不需要重启游戏
- **辅助功能的包容性** — 色盲模式、高对比度、敌人轮廓、字幕大小可调，每种需求都有对应选项
- **键位自定义的自由度** — 12个功能全部可修改，一键恢复默认，键位冲突时弹出警告
- **难度切换的灵活性** — 随时可调高难度无惩罚，调低难度时确认但不禁止，成就标记"含难度调整"

## Formulas

### 设置自动保存延迟

```
on_setting_changed():
    if save_timer is not active:
        save_timer.start(3.0)  # 3秒后保存

on_save_timer_timeout():
    save_settings_to_file("user://settings.json")
    save_timer.stop()
```

## Edge Cases

1. **分辨率切换后黑屏**: 分辨率应用后5秒内无操作自动回退到上一个可用分辨率，防止黑屏无法操作。
2. **键位冲突（两个功能映射到同一键）**: 弹出确认弹窗"此键已用于[功能X]，是否覆盖？"，确认后覆盖，原功能无键位绑定。
3. **设置文件损坏或格式错误**: 使用默认设置覆盖，弹出提示"设置文件损坏，已恢复默认设置"。
4. **滑块值超出范围**: clamp到有效范围内，不报错。
5. **设置修改后立即关闭游戏**: 退出游戏时强制保存所有未保存的修改。
6. **辅助功能与画质设置冲突**: 如高对比度模式与阴影关闭同时启用，两者不冲突，独立生效。
7. **首次启动推荐系统跳过**: 玩家可跳过辅助功能推荐，后续随时在设置中手动启用。
8. **导入存档格式不兼容**: 提示"存档格式不兼容"，不覆盖当前存档。
9. **语言切换后部分文本缺失翻译**: 使用默认语言（简体中文）作为fallback，缺失文本显示默认语言版本。
10. **设置UI在低分辨率下显示不全**: 最低支持800×600分辨率，设置面板支持滚动，确保所有选项可访问。
