## Overview

敌人AI系统管理所有敌人类型的行为逻辑，包括基础状态机、感知系统（视觉/听觉/特殊）、群体行为（Flocking/包围/分散/协作）、路径规划（A*寻路）、难度分级和特殊AI类型（追击型/潜伏型/巡逻型/登船型/隐形/召唤型）。系统使用数据驱动配置，每种敌人通过Resource配置文件定义行为参数。

---

## Player Fantasy

玩家应感受到：
- **敌人智能化的威胁感** — 敌人会协作包围、呼叫增援、预判玩家走位，而非单纯送死
- **潜行与躲避的策略深度** — 利用视觉锥形盲区、声音传播规律来规避敌人
- **不同类型敌人的独特挑战** — 追击型的高速压迫、潜伏型的背刺恐惧、召唤型的持续压力
- **难度递增的合理挑战** — 从简单的固定路线巡逻到高级预判包围，随难度逐步提升

## Detailed Rules

### 基础状态机

所有敌人AI遵循6核心状态 + 1特殊状态：

| 状态 | 移动速度 | 可攻击 | 进入条件 | 退出条件 |
|------|---------|--------|---------|---------|
| IDLE(待机) | 0 | 否 | 初始化/丢失目标/眩晕恢复 | 感知到玩家/收到警报 |
| PATROL(巡逻) | 50%正常速度 | 否 | 初始化/巡逻AI默认 | 感知到玩家/收到警报 |
| CHASE(追击) | 100%正常速度 | 否 | 感知到玩家/收到同伴警报 | 进入攻击范围/丢失目标/被击退 |
| ATTACK(攻击) | 30%正常速度 | 是 | 进入攻击范围 | 目标超出范围/被击退/血量过低 |
| KNOCKBACK(击退) | 击退方向强制移动 | 否 | 受到强力攻击 | 击退动画结束 |
| STUNNED(眩晕) | 0 | 否 | 受到特定攻击(重击/特殊武器) | 眩晕计时结束(3秒) |
| ENRAGED(狂暴) | +20%速度 | 是 | 血量<30%（特殊变体） | 战斗结束/死亡 |

**状态转换规则**:
- IDLE → CHASE: 感知到玩家
- PATROL → CHASE: 感知到玩家
- CHASE → ATTACK: 进入攻击范围
- CHASE → PATROL/IDLE: 丢失目标(10秒超时)
- ATTACK → CHASE: 目标超出攻击范围
- 任何状态 → KNOCKBACK: 受到强力攻击
- KNOCKBACK → STUNNED: 重击
- STUNNED → IDLE: 3秒后恢复
- 任何攻击状态 → ENRAGED: 血量<30%

**狂暴状态效果**:
- 攻击速度 +30%
- 移动速度 +20%
- 感知范围 +50%
- 免疫 STUNNED 状态
- 视觉标识: 眼睛变为红色发光

### 感知系统

**视觉感知**:
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 感知角度 | 120°（前方锥形） | 以正前方为中线，左右各60° |
| 感知距离 | 15m | 基础感知距离 |
| 遮挡检测 | 射线检测 | 障碍物阻挡时无法看见 |
| 光线影响 | 黑暗环境-50% | 夜间/深海降至7.5m |

```
有效感知距离 = 基础距离(15m) × 光线系数 × 玩家行为系数 × 潜行系数

光线系数: 明亮=1.0, 昏暗=0.5, 极暗=0.3
玩家行为系数: 静止=1.0, 行走=1.2, 奔跑=1.3, 射击=1.5
潜行系数: 潜行=0.4, 正常=1.0
```

**听觉感知**:
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 感知形状 | 圆形，半径10m | 360°全方位 |
| 水下加成 | +50%感知距离 | 水下增至15m |
| 障碍物衰减 | 每层墙壁-30%音量 | 隔墙后衰减 |

| 声音类型 | 基础音量 | 最大传播距离 |
|---------|---------|-------------|
| 静止 | 0 | 0m |
| 行走 | 30 | 8m |
| 奔跑 | 60 | 15m |
| 射击 | 80 | 25m |
| 爆炸 | 100 | 40m（全图可闻） |
| 设施损伤 | 50 | 12m |
| 警报 | 90 | 30m |

```
有效音量 = 基础音量 × (1 - 距离/最大距离)
if 有效音量 > 听觉阈值: 检测到声音
```

**特殊感知**:
| 感知类型 | 拥有者 | 范围 | 说明 |
|---------|--------|------|------|
| 声呐感知 | 机械类/Boss | 20m | 玩家使用声呐时立即CHASE |
| 热能感知 | 深海怪物 | 8m | 不受视觉遮挡影响 |
| 电磁感知 | 电子敌人/机甲 | 12m | 感知电子设备信号 |

### 群体行为

**Flocking（小型怪物群，3-8个）**:
| 规则 | 权重 | 说明 |
|------|------|------|
| 聚合（Cohesion） | 1.0 | 向群体中心靠拢 |
| 分离（Separation） | 1.5 | 最小间距2m |
| 对齐（Alignment） | 0.8 | 保持同方向移动 |

**包围阵型（中型敌人，3-5个）**:
| 阵型 | 数量 | 布局 | 攻击模式 |
|------|------|------|---------|
| 三角包围 | 3个 | 三角形分布 | 交替攻击 |
| 五边包围 | 5个 | 五边形分布 | 2正面+3侧翼 |
| 半圆包围 | 4个 | 半弧形分布 | 正面压制+侧面骚扰 |

**分散躲避**: 受到范围攻击时向反方向分散，分散速度=1.5x正常速度，最小间距3m。

**协作攻击**:
| 角色 | 职责 | 行为 |
|------|------|------|
| 追击型 | 吸引注意力 | 正面追击 |
| 潜伏型 | 侧翼突袭 | 侧面/后方隐蔽接近 |
| 召唤型 | 后方支援 | 保持安全距离召唤增援 |
| 巡逻型 | 封锁退路 | 占据关键位置 |

### 路径规划

| 系统 | 说明 | 适用场景 |
|------|------|---------|
| A*寻路 | NavigationMesh上最优路径 | 开放区域、复杂地形 |
| 动态障碍规避 | RVO避让移动障碍物 | 敌人互相避让 |
| 路径平滑 | 减少折线感 | 所有寻路场景 |
| 路径缓存 | 缓存最近3条路径 | 频繁访问同一区域 |

| 参数 | 值 |
|------|-----|
| 网格分辨率 | 0.5m/格 |
| 最大搜索距离 | 30m |
| 路径更新频率 | 0.5秒 |
| 地形代价 | 水域×1.5, 洞穴×1.2 |

### 难度分级

| AI参数 | 简单 | 普通 | 困难 | 深渊 |
|--------|------|------|------|------|
| 反应速度 | 1.5秒 | 1.0秒 | 0.5秒 | 0.2秒 |
| 视觉距离 | 70% | 100% | 120% | 150% |
| 听觉半径 | 70% | 100% | 120% | 140% |
| 预判能力 | 无 | 0.5秒预测 | 1秒预测+封锁退路 | 预测意图+占位 |
| 协作能力 | 不协作 | 基础协作 | 高级协作 | 完美协作 |
| 分散躲避 | 不分散 | 范围攻击时分散 | 任何攻击分散 | 预判方向分散 |
| 呼叫增援 | 不呼叫 | 血量<30% | 发现即呼叫 | 发现即呼叫，更多增援 |

### AI通信系统

| 类型 | 触发条件 | 传播范围 | 效果 |
|------|---------|---------|------|
| 警报 | 发现玩家 | 20m | 附近敌人进入CHASE |
| 呼叫增援 | 血量<30%或需要协作 | 30m | 召唤附近同伴 |
| 危险警告 | 受到范围攻击 | 10m | 附近敌人分散 |
| 撤退信号 | Boss/大型敌人撤退 | 15m | 小怪跟随撤退 |

**接收概率**: 同类型100%, 不同类型50%, Boss 100%且可指挥小怪。

### 特殊AI类型

**追击型(Chaser)**: 比玩家快10%，中等生命/攻击，狂暴机制（血量<30%时速度+30%/攻速+40%/感知+50%/免疫眩晕）。

**潜伏型(Stalker)**: 三阶段行为 — HIDE(隐藏不可见) → SNEAK(缓慢接近, 距离>8m) → AMBUSH(突袭伤害×2, 距离<8m或玩家背对)。攻击完成后重新隐蔽，被发现且距离>5m时放弃隐蔽直接追击。

**巡逻型(Patrol)**: 预设3-5个路径点循环巡逻，发现玩家时发出警报（呼叫附近敌人），丢失目标后回到最近路径点继续。

**登船型(Boarding)**: 目标优先级 — 1.动力室 2.弹药库 3.指挥室 4.仓库 5.玩家位置。血量<20%或目标无法达成时撤退。

**隐形型(Stealth)**: 完全隐形(不可见) / 半透明(淡蓝轮廓, 距离<2m自动切换) / 显形(攻击时/受声呐攻击5秒)。攻击结束后3秒恢复隐形。

**召唤型(Summoner)**: 召唤冷却15秒，召唤1-3个小型敌人，最大场上6个召唤物。行为优先级: 1.保持安全距离>10m 2.召唤物不足时召唤 3.玩家接近<5m撤退 4.无法撤退时近战防御。

### AI记忆系统

| 记忆类型 | 内容 | 持续时间 | 用途 |
|---------|------|---------|------|
| 最后已知位置 | 玩家最后出现位置 | 10秒 | 丢失后前往搜索 |
| 最后移动方向 | 玩家离开时方向 | 5秒 | 预测逃跑路线 |
| 玩家习惯 | 常用武器/躲避方向 | 整场战斗 | 调整策略(困难/深渊) |
| 危险区域标记 | 玩家陷阱/炮台位置 | 30秒 | 避开危险区域 |

```
if 丢失目标 and 有最后已知位置:
    前往最后位置搜索(持续10秒)
if 搜索超时:
    回到IDLE或PATROL

if 玩家重复同一躲避方向≥3次 and 困难/深渊难度:
    下次攻击预判该方向
```

## Formulas

### 视觉感知计算

```
effective_vision_range = base_range(15m) × light_coeff × behavior_coeff × stealth_coeff

light_coeff:     明亮=1.0, 昏暗=0.5, 极暗=0.3
behavior_coeff:  静止=1.0, 行走=1.2, 奔跑=1.3, 射击=1.5
stealth_coeff:   潜行=0.4, 正常=1.0

if angle_in_cone(120°) and distance <= effective_vision_range and no_obstruction:
    detect_player → CHASE
```

### 听觉感知计算

```
effective_volume = base_volume × (1 - distance / max_range) × wall_attenuation

wall_attenuation = 0.7 ^ wall_count  # 每层墙壁×0.7
water_bonus = 1.5  # 水下环境

if effective_volume × water_bonus > hearing_threshold:
    detect_sound → 向声源方向移动
```

### Flocking速度计算

```
flocking_velocity = cohesion × 1.0 + separation × 1.5 + alignment × 0.8

cohesion = (average_neighbor_position - self_position).normalized()
separation = sum((self - neighbor).normalized() / distance) for neighbors within 2m
alignment = average_neighbor_velocity.normalized()

仅在邻居数量≥2时启用flocking
```

### AI密度计算

```
actual_ai_density = base_density × layout_coeff × sea_area_coeff

layout_coeff: 开阔区域=1.5, 狭窄走廊=0.7, 多层结构=1.2, 迷宫=0.8
sea_area_coeff: 随海域递增(1号=1.0, 9号=2.0)
```

### 狂暴状态数值

```
enraged_move_speed = base_speed × 1.2
enraged_attack_speed = base_attack_speed × 1.3
enraged_vision_range = base_vision × 1.5
immune_to_stun = true
```

## Edge Cases

1. **多个敌人同时发现玩家**: 选择距离最近的敌人作为"主导者"决定攻击策略，主导者被击败后下一个最近敌人接替。
2. **召唤物达到上限**: 召唤型敌人的召唤物数量达到6个上限时，暂停召唤直到有召唤物被消灭。
3. **潜伏型敌人被提前发现**: 潜伏型在SNEAK阶段被玩家发现时，如果距离>8m则退回到HIDE状态；如果距离<8m则直接进入AMBUSH。
4. **隐形敌人攻击后玩家逃跑**: 隐形敌人攻击后3秒内恢复隐形，如果玩家已跑出感知范围则回到IDLE。
5. **登船AI找不到登船点**: 登船AI如果所有登船点被炮台覆盖，会在船外围徘徊30秒后撤退。
6. **路径被动态障碍物完全阻断**: A*寻路超过2秒找不到路径时，尝试绕行或直接面向玩家移动（牺牲最优路径换取响应速度）。
7. **群体AI中部分敌人死亡**: 包围阵型中如有敌人倒下，剩余敌人重新调整阵型（3个变三角，4个变半圆），如果只剩1个则退化为CHASE。
8. **通信范围重叠**: 多个敌人同时发出警报时，接收方只处理最近来源的警报，避免重复响应。
9. **狂暴+眩晕冲突**: 狂暴状态免疫STUNNED，已进入狂暴的敌人不会因重击眩晕。
10. **玩家使用声呐探测**: 声呐感知类敌人立即进入CHASE状态（无视距离），持续10秒。10秒后如果丢失目标则回到搜索行为。
11. **AI在Boss战中**: Boss可100%接收所有通信并指挥小怪。小怪优先听从Boss指令而非自身AI逻辑。
12. **记忆系统超时**: 玩家使用隐形/传送等手段完全消失后，AI搜索10秒无果后回到PATROL状态，但记住"危险区域标记"30秒内避开该区域。

## Acceptance Criteria

- [ ] 敌人在静止玩家不移动、无遮挡、明亮环境下，15m内可检测到玩家进入CHASE
- [ ] 玩家潜行时视觉感知距离降至6m（15m × 0.4）
- [ ] 射击声音在25m内可被敌人听到（无障碍、无水环境）
- [ ] 水下环境中听觉感知距离增至15m（10m × 1.5）
- [ ] Flocking群体中敌人最小间距保持2m，不会重叠
- [ ] 3个中型敌人检测到玩家时形成三角包围阵型
- [ ] 召唤型敌人每15秒召唤1-3个敌人，场上最多6个召唤物
- [ ] 潜伏型敌人在距离>8m时保持HIDE/SNEAK，距离<8m时触发AMBUSH
- [ ] 狂暴状态敌人移动速度增加20%，免疫STUNNED
- [ ] 简单模式下敌人不协作、不形成包围、不呼叫增援
- [ ] 困难模式下敌人发现玩家即呼叫增援，预测玩家1秒后位置
- [ ] 登船AI优先攻击动力室，其次弹药库，血量<20%时撤退
- [ ] 隐形敌人攻击后3秒恢复隐形，受声呐攻击强制显形5秒
- [ ] 丢失目标后AI前往最后已知位置搜索10秒，超时回到PATROL
- [ ] A*寻路在0.5秒内为30m内目标计算路径，找不到路径时直接面向目标移动
- [ ] 范围攻击触发时，群体敌人在1秒内向反方向分散，最小间距3m
- [ ] Boss可指挥周围30m内所有小怪，小怪优先听从Boss指令
- [ ] 所有AI参数（视觉/听觉/Flocking/召唤/难度）可通过配置文件调整，无需修改代码
