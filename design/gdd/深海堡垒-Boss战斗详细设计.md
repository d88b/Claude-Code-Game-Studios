## Overview

Boss战斗系统设计5种主要Boss（风暴领主/深渊巨兽/寄生女王/海盗王/远古守卫）和6种NPC船只Boss（幽灵船/飞空艇/巨型潜水艇/海盗旗舰/深海巨兽船/战争机甲船），每种Boss采用4阶段血量阈值设计（75%/50%/25%/0%）+15%血量狂暴机制。系统包含Boss数据驱动配置（BossConfig Resource类）、状态机（6状态：INTRO/PHASE1-4/RAGE/DEATH）、弱点暴露系统（3.0x伤害窗口）、时间限制（4-6分钟）、转场动画、战斗UI（血条+阶段指示+弱点提示+技能预警）、S/A/B/C/D评分结算和重复挑战机制（4种模式+掉落衰减）。

---

## Player Fantasy

玩家应感受到：
- **Boss战的仪式感** — 乌云聚集风暴领主从云中显现、海底震动深渊巨兽升起，5秒不可控出场动画确立Boss威压
- **弱点暴露的策略窗口** — 每阶段有3-5秒弱点暴露时机，3.0x伤害倍率，需要集中火力把握窗口
- **狂暴的紧迫感** — 15%血量触发全屏红光+攻击+40%+速度+30%，BGM节奏加快，最后冲刺
- **评分结算的成就感** — 无伤S评分获得2x奖励和特殊成就，驱动重复挑战

### Boss狂暴机制

| 参数 | 值 |
|------|---|
| 触发条件 | 血量≤15% |
| 攻击提升 | +40% |
| 速度提升 | +30% |

### Boss战UI

- **血条**：屏幕顶部居中，颜色绿(>50%)/黄(>25%)/红(<25%)
- **阶段指示器**：血条下方4条竖线标记分界，当前阶段高亮
- **弱点提示**：闪烁标记+倒计时+3.0x倍率显示
- **技能预警**：屏幕中央红色文字+受影响区域红色半透明+安全区域绿色半透明
- **召唤物计数**：屏幕右侧"召唤物：3/6"
- **狂暴指示**：Boss血条旁火焰图标
- **时间限制**：屏幕左上方倒计时（最后30秒进度条变红）

### 转场动画

| 阶段 | 时长 | 效果 |
|------|------|------|
| Boss出场 | 4-5秒 | 不可控动画（海盗王除外可操控躲避） |
| 阶段转换 | 1-2秒 | Boss发光/变色，屏幕震动，玩家不可攻击0.5秒 |
| Boss死亡 | 2秒慢动作 | 爆炸/消散/沉没，掉落物散落，渐黑→结算 |

### 战斗评分

| 评分 | 条件 | 奖励倍率 |
|------|------|---------|
| S | 无伤+时间<50% | 2x + 特殊成就 |
| A | 受伤<20%+时间<70% | 1.5x |
| B | 受伤<50%+时间<100% | 1.0x |
| C | 受伤<80% | 0.8x |
| D | 险胜 | 0.5x |

### 重复挑战

- 已击败Boss可在对应海域使用"Boss召唤道具"重新挑战
- 召唤道具通过击败Boss概率掉落或商店购买
- **掉落衰减**：重复挑战同Boss，掉落率每次-10%（最低50%）
- **4种挑战模式**：标准(1x)/速通限时70%(1.5x)/无伤(2x+成就)/地狱狂暴30%(2.5x+独有掉落)

### Godot实现

- `BossConfig` Resource类：数据驱动所有Boss参数（血量/阶段/阈值/弱点/掉落/BGM/动画）
- `BossStateMachine`：6状态机（INTRO/PHASE1-4/RAGE/DEATH），血量阈值触发转换
- `BossUI` CanvasLayer：血条/阶段/弱点/警告/计时器
- `BossSummon`：召唤/重复挑战逻辑，应用掉落衰减

## Formulas

### 阶段阈值检查

```
phase_hp_thresholds = [1.0, 0.75, 0.5, 0.25]  # P1/P2/P3/P4
rage_threshold = 0.15

hp_ratio = current_hp / max_hp
if hp_ratio <= rage_threshold:
    enter_state(RAGE)
elif hp_ratio <= phase_hp_thresholds[i]:
    enter_state(PHASE_i)
```

### 弱点伤害倍率

```
if attacking_weakness and weakness_exposed:
    final_damage = base_damage * 3.0  # 弱点3倍伤害
else:
    final_damage = base_damage
```

### 狂暴属性修正

```
if enraged:
    boss.attack_damage *= 1.40
    boss.move_speed *= 1.30
    boss.attack_interval *= 0.70  # 攻击间隔缩短30%
    boss.immune_to_stun = true
```

### 掉落衰减

```
drop_rate = base_drop_rate * max(0.50, 1.0 - (challenge_count * 0.10))
# challenge_count: 0=首次, 1=第2次(-10%), 2=第3次(-20%), 最低50%
```

### 评分计算

```
score = (
    (1.0 - damage_taken_ratio) * 50 +  # 受伤评分(0-50分)
    (1.0 - time_ratio) * 50             # 时间评分(0-50分)
)
# S: score >= 90, A: >= 75, B: >= 60, C: >= 40, D: < 40
```

### 重复挑战评分倍率

```
challenge_multipliers = {
    "standard": 1.0,
    "speedrun": 1.5,    # 70%时间限制
    "no_damage": 2.0,   # 无伤
    "hell": 2.5         # 狂暴阈值提前至30%
}
final_reward = base_reward * score_multiplier * challenge_multiplier * drop_decay
```

## Edge Cases

1. **Boss转场动画期间玩家死亡**: 寄生女王（内部层Boss）转场时如果船员已全部死亡，Boss战失败但不会Game Over，提供紧急修复选项。
2. **时间限制到期Boss逃离**: Boss逃离后标记为"未完成"，下次仍可触发同一Boss。不重置Boss进度，从P1重新开始。
3. **狂暴期间Boss被秒杀**: 狂暴状态不可逆转，即使Boss在狂暴后1秒内被击杀也正常结算（S评分可能）。狂暴不延长Boss生命。
4. **Boss召唤道具用完**: 商店有无限库存但价格递增（第n次购买价格=基础价格×n）。防止玩家因资源不足无法重复挑战。
5. **分裂Boss（远古守卫P3）各部分被逐个击败**: 头部被击败后控制其他部分停止攻击10秒。先打头是最优策略，但不强制。
6. **寄生女王P4全屏孢子时所有舱门已打开**: 未封闭舱室船员有50%概率被寄生。提示"封闭舱门"但不自动封闭。
7. **NPC船只Boss同时触发多个（如海盗王+幽灵船）**: Boss战队列，先触发者优先。后触发者延迟至当前Boss战结束，延迟时间≤30秒，超时则取消。
8. **Boss弱点暴露期间玩家武器弹药不足**: 弱点窗口不延长。鼓励玩家管理弹药资源。简单难度下弹药充足不影响此机制。
9. **Boss死亡动画播放中玩家退出游戏**: 战斗结果已确定（Boss HP≤0），下次加载从结算界面开始，动画跳过。
10. **重复挑战掉落衰减达到最低50%**: 不再继续衰减，保持50%。确保重复挑战仍有最低收益。
