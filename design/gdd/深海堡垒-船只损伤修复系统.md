## Overview

船只损伤修复系统管理船只和设施的伤害机制、修复流程、资源消耗、紧急修复和连锁损伤。系统定义了6级损伤分级（完好→完全摧毁）、基于来源的损伤计算公式、标准修复与紧急修复双流程、连锁损伤传播机制，以及损伤对设施功能和船员伤亡的影响。

---

## Player Fantasy

玩家应感受到：
- **设施损伤带来的紧迫感** — 从中度损伤的效率下降到重度损伤的功能瘫痪，损伤直接影响防守能力
- **修复决策的策略性** — 修复到完好还是仅修复到轻度，消耗不同资源但影响不同，需要权衡
- **战斗中紧急修复的紧张节奏** — 使用紧急修复包快速恢复基本功能，但仅能修到中度状态
- **连锁损伤的恐惧感** — 弹药库爆炸可能波及周围设施，火灾蔓延持续损伤，促使优先处理高危设施

## Detailed Rules

### 设施损伤分级

| 损伤等级 | 设施HP范围 | 功能影响 | 视觉状态 |
|---------|-----------|---------|---------|
| 完好 | 100%-90% | 功能正常 | 正常外观 |
| 轻度损伤 | 90%-70% | 效率降低10% | 轻微破损痕迹 |
| 中度损伤 | 70%-50% | 效率降低30% | 明显破损痕迹 |
| 重度损伤 | 50%-30% | 功能暂停，无法使用 | 严重破损，火花 |

| 完全摧毁 | 0% | 设施消失，无法修复 | 设施消失 |

### 标准修复流程

1. 发现损伤设施 → 检查设施状态
2. 选择修复目标 → 修复到完好 或 修复到轻度
3. 检查修复资源 → 确认有足够资源
4. 开始修复 → 等待修复完成（消耗资源）
5. 修复完成 → 设施HP恢复，功能恢复

## Formulas

### 设施损伤计算

```
设施损伤 = 基础损伤 × 敌人攻击力系数 × 弱点系数 × (1 - 护甲减免)

护甲减免 = 设施护甲 / (设施护甲 + 50)
```

**示例1：中型敌人攻击普通设施（中度护甲）**
```
损伤 = 15 × 1.0 × 1.0 × (1 - 0.50) = 15 × 0.50 = 7.5 HP
```

**示例2：Boss攻击核心设施（中度护甲）**
```
损伤 = 50 × 1.0 × 2.0 × (1 - 0.50) = 50 × 2 × 0.5 = 50 HP
```

**示例3：鱼雷命中暴露设施（无护甲）**
```
损伤 = 40 × 1.0 × 1.5 × (1 - 0) = 40 × 1.5 × 1 = 60 HP
```

### 实际修复时间计算

```
实际修复时间 = 基础时间 × (1 - 人员效率加成) × (1 - 工坊效率加成) × (1 - 工具效率加成)
```

**示例：重度损伤（基础120秒），2人修复（20%），工坊Lv3（20%），高级工具（30%）**
```
实际时间 = 120 × (1 - 0.20) × (1 - 0.20) × (1 - 0.30)
         = 120 × 0.8 × 0.8 × 0.7
         = 120 × 0.448
         = 53.76 秒 ≈ 54秒
```

### 紧急修复时间

```
紧急修复时间 = 标准修复时间 × 0.3
```

**示例：重度损伤标准120秒**
```
紧急修复时间 = 120 × 0.3 = 36秒
```

## Edge Cases

1. **完全摧毁的设施无法修复**: 设施HP归零后从船体消失，无法通过任何修复手段恢复，需要重新建造（如果游戏支持）。
2. **多个设施同时受损**: 同时修复多个设施时，每个设施的修复时间增加（具体倍率由Tuning Knob定义），防止玩家无成本并行修复。
3. **紧急修复包不足**: 如果玩家没有紧急修复包，无法进行紧急修复，只能等待战斗结束后标准修复。
4. **修复过程中设施再次受损**: 修复进度不回退，但设施HP会下降。如果HP降至0以下，设施被摧毁，修复进度丢失。
5. **弹药库爆炸连锁触发二次爆炸**: 如果周围有另一个弹药库，连锁损伤可能导致二次爆炸。连锁传播深度限制为1层。
6. **火灾蔓延中被扑灭**: 如果玩家在火灾蔓延过程中扑灭火灾，连锁损伤停止，已造成的损伤保留。
7. **核心设施（动力室/指挥室）同时濒危**: 两个核心设施同时濒危时，触发"濒临沉没"警告，船速度-50%。
8. **修复资源不足**: 修复开始时资源不足，修复无法开始，提示缺少资源类型和数量。
9. **船员全部在修复中**: 如果所有船员都在修复设施，波次防守期间无人操作炮台，需平衡分配。
10. **登船敌人破坏正在修复的设施**: 内部层敌人可攻击正在修复的设施，修复进度中断，需清除敌人后重新开始。

## Acceptance Criteria

- [ ] 设施HP 90-100%为完好状态，功能正常，无警告
- [ ] 设施HP 70-90%为轻度损伤，效率降低10%，图标黄色
- [ ] 设施HP 50-70%为中度损伤，效率降低30%，图标橙色
- [ ] 设施HP 30-50%为重度损伤，功能暂停，图标红色闪烁+警报声
- [ ] 设施HP 10-30%为濒危损伤，功能暂停随时摧毁，图标剧烈闪烁+强警报声
- [ ] 设施HP 0%为完全摧毁，设施消失无法修复
- [ ] 中型敌人攻击普通设施（中度护甲）造成7.5 HP损伤（15 × 1.0 × 1.0 × 0.5）
- [ ] Boss攻击核心设施（中度护甲）造成50 HP损伤（50 × 1.0 × 2.0 × 0.5）
- [ ] 重度损伤标准修复时间120秒，紧急修复时间36秒（120 × 0.3）
- [ ] 紧急修复仅恢复到中度损伤状态（HP 50%）
- [ ] 弹药库爆炸对周围3格设施造成50-100 HP连锁损伤
- [ ] 动力室爆炸导致整船HP损失30%
- [ ] 设施中度损伤时5%概率造成1-2名船员受伤
- [ ] 设施完全摧毁时50%概率造成2-5名船员死亡
- [ ] 所有损伤参数（基础损伤值、弱点系数、护甲减免公式）可通过配置文件调整，无需修改代码
