## Overview

剧情系统通过五幕结构（启航→深海初探→暗流涌动→深渊召唤→抉择）讲述2150年气候剧变后人类寻找新家园的故事。系统包含道德值追踪（-100~+100，5级：暴君/冷酷/中立/仁慈/圣人）、6个关键道德选择、任务分支设计（第三章3条路线）、12个剧情触发事件和8个NPC好感度关联剧情。剧情与NPC系统、任务系统、结局系统深度关联，支持多周目游玩（5周目解锁真结局）。

---

## Player Fantasy

玩家应感受到：
- **道德选择的重量感** — 救援海盗船还是掠夺资源？每个选择±5~20道德值，直接影响结局走向和NPC态度
- **分支路线的 replay 价值** — 第三章武力/和平/暗中合作三条路线差异巨大，选择不可逆，多周目体验不同命运
- **真相揭示的震撼感** — 从"自然灾害"到远古文明实验，收集12个遗迹碎片后陆地沉没的真相逐渐浮出水面
- **NPC关系的影响力** — 高好感度NPC在关键时刻提供帮助（海伯给特殊装备、红帆牺牲保护），低好感度NPC背叛或离开

## Detailed Rules

### 故事大纲

**背景**: 2150年，全球气候剧变，海平面上升导致陆地大面积沉没。玩家扮演移动海上堡垒船长，带领幸存者寻找新家园。核心悬念：陆地沉没真的是自然灾害吗？

**五幕结构**:

| 幕 | 章节 | 核心主题 | 任务数 | 解锁条件 |
|----|------|---------|--------|---------|
| 第一幕 | 启航 | 建立堡垒，适应海洋 | 5个 | 基础功能 |
| 第二幕 | 深海初探 | 探索未知，发现遗迹 | 5个 | 深海装备 |
| 第三幕 | 暗流涌动 | 势力冲突，内部考验 | 6个 | 中级科技 |
| 第四幕 | 深渊召唤 | 深入险境，揭示真相 | 6个 | 深渊装备 |
| 第五幕 | 抉择 | 终极抉择，命运走向 | 4-5个 | 游戏结局 |

**核心冲突**:

| 冲突类型 | 冲突内容 | 解决方式 |
|---------|---------|---------|
| 外部冲突 | 变异生物、海盗掠夺、自然灾害 | 武力/外交/回避 |
| 内部冲突 | 船员分歧、资源短缺、道德抉择 | 领导力/道德选择 |
| 终极冲突 | 远古文明揭示真相，玩家决定人类未来 | 结局选择 |

### 道德值系统

**范围**: -100（极端邪恶）~ +100（极端善良），初始值0（中立）。

**道德值等级**:

| 范围 | 称号 | 船员反应 | NPC态度 | 结局倾向 |
|------|------|---------|---------|---------|
| +61~+100 | 海洋圣人 | 崇敬，愿追随到底 | 信任，主动帮助 | 海洋守护者 |
| +21~+60 | 仁慈船长 | 安心，士气高涨 | 友好，愿合作 | 新家园 |
| -20~+20 | 务实船长 | 中立，看利益行事 | 中立，按规矩办事 | 永恒漂泊 |
| -60~-21 | 冷酷船长 | 恐惧，忠诚下降 | 警惕，保持距离 | 深渊统治 |
| -100~-61 | 海上暴君 | 恐惧+怨恨，可能叛乱 | 敌对，可能反抗 | 悲剧沉没 |

**6个关键道德选择**:

| # | 章节 | 场景 | 选项A（善） | 选项B（恶） | 道德变化 | 主要影响 |
|---|------|------|------------|------------|---------|---------|
| 1 | 第二章 | 漂流海盗船 | 救援幸存者 | 掠夺资源 | A:+15/B:+15恶 | 声望、海盗关系 |
| 2 | 第三章 | 海盗保护费 | 支付保平安 | 拒绝并战斗 | A:+5善-10资源/B:+10恶-风险 | 海盗关系、资源 |
| 3 | 第四章 | 避难所求救 | 派资源救援 | 保留自保 | A:+15善-资源/B:+10恶-资源 | NPC好感、避难所存亡 |
| 4 | 第五章 | 远古武器 | 用于防御研究 | 用于攻击 | A:+15善/B:+15恶 | 结局走向、可用武器 |
| 5 | 第六章 | 船员叛乱 | 武力镇压 | 谈判妥协 | A:+5恶-快速/B:+10善-可能失败 | 忠诚度、内部关系 |
| 6 | 第七章 | 发现新家园 | 独占 | 共享 | A:+15恶/B:+20善 | 最终结局 |

### 任务分支设计（第三章"暗流涌动"）

**分支A（武力解决）**: 侦察海盗据点→准备战斗装备→突袭海盗舰队→击败海盗队长→搜刮宝藏。结果：大量金币+海盗装备，海盗永久敌对，铁锚+10，红帆-15，道德+10恶。

**分支B（和平谈判）**: 获取谈判资格→前往海盗营地→与海盗王谈判→达成贸易协议→首次贸易。结果：贸易特权（长期收入），红帆+15，珊瑚+5，道德+5善。

**分支C（暗中合作）**: 假意加入→完成投名状→收集情报→双面间谍→最终选择（帮助/背叛/利用双方）。结果：取决于最终选择，最复杂路线。

**分支锁定规则**: 一次性选择（选择后其他分支本周目不可访问），选择前弹出确认提示，确认后不可回退。

### 剧情与NPC好感度关联

**高好感度(80+)帮助**: 海伯给特殊装备、珊瑚揭示远古基因秘密、铁锚带领援军、红帆牺牲保护、贝壳与深渊生物沟通。

**低好感度(<30)背叛**: 铁锚在叛乱中站在叛乱方、红帆回到海盗阵营、珊瑚带走重要研究成果。

**NPC好感度总和→结局加成**: 平均≥70最佳结局条件，平均40-70标准结局，平均<40困难结局或失败。

### 多周目设计

**继承内容**: 已解锁科技50%、怪物图鉴100%、地图探索100%、成就100%、隐藏区域坐标50%。道德值和NPC好感度0%重置。

**新增内容**: 二周目解锁"新家园+"难度，三周目解锁隐藏商人，四周目解锁远古文明隐藏任务，五周目+解锁真结局条件。

**全收集目标**: 全部结局6种→"命运探索者"成就，全部NPC招募8个→"全员集结"成就，全部隐藏任务链7条→"深海探秘者"成就。

## Formulas

### 道德值计算

```
moral_value = clamp(initial_value + sum(choice_delta), -100, 100)

moral_tier:
  moral_value >= 61:  "海洋圣人"
  moral_value >= 21:  "仁慈船长"
  moral_value >= -20: "务实船长"
  moral_value >= -60: "冷酷船长"
  else:               "海上暴君"
```

### 结局判定优先级

```
# 步骤1: 失败检查
if crew_survival_rate < 0.10 or ship_integrity < 0.05:
    return ENDING_6 (悲剧沉没)

# 步骤2: 隐藏结局
if ancient_fragments == 12 and all_hidden_chains_done and npc_avg >= 50:
    return ENDING_5 (远古觉醒)

# 步骤3: 和平结局
if eco_chain_done and non_hostile_kills == 0 and coral_affinity >= 80 and moral >= 61:
    return ENDING_3 (海洋守护者)

# 步骤4: 野心结局
if weapon_choice == "attack" and enemy_faction_hostile and moral <= -21 and crew_loyalty >= 60:
    return ENDING_2 (深渊统治)

# 步骤5: 最终选择
if final_choice == "share" and moral >= -20:
    return ENDING_1 (新家园)
elif final_choice == " monopolize":
    return ENDING_2 (深渊统治)
elif final_choice == "sail_on":
    return ENDING_4 (永恒漂泊)

# 步骤6: 默认
return ENDING_4 (永恒漂泊)
```

## Edge Cases

1. **道德选择与主线任务同时触发**: 道德选择弹窗优先级更高，主线任务暂停等待选择完成。
2. **分支选择后玩家想反悔**: 分支选择前弹出确认弹窗（"选择后不可更改"），确认后锁定，本周目无法更改。
3. **NPC在剧情事件进行中死亡**: 剧情事件中止或修改，相关对话跳过，不导致游戏崩溃。
4. **道德值在边界值附近波动**: 如道德值-20（边界），+5后变为-15仍为"务实船长"，-5后变为-25进入"冷酷船长"。称号即时更新。
5. **多周目继承时科技50%导致某些科技不完整**: 继承的科技向下取整到已解锁的前置科技，不出现断层。
6. **剧情触发条件在加载存档后立即满足**: 延迟0.5秒触发，确保场景和UI完全加载。
7. **船员叛乱事件与Boss战同时触发**: Boss战优先级更高，叛乱事件延迟到Boss战后。
8. **远古文明真相揭示时玩家未完成所有主线**: 揭示事件正常触发，但不解锁远古觉醒结局（需全碎片+全隐藏链）。
9. **道德选择音效与BGM冲突**: 道德选择弹窗出现时BGM音量降低3dB，选择完成后恢复。
10. **存档加载时branch_choices引用了不存在的分支ID**: 忽略无效分支ID，使用当前主线进度重新计算可用分支。

## Tuning Knobs

| 参数 | 当前值 | 安全范围 | 影响 |
|------|--------|---------|------|
| 道德值范围 | -100~+100 | -50~+50 | 影响选择粒度 |
| 单次道德变化 | ±5~20 | ±3~30 | 影响选择权重 |
| 关键道德选择数 | 6个 | 4-10个 | 影响叙事复杂度 |
| 分支路线数(第三章) | 3条 | 2-5条 | 影响重玩价值 |
| 剧情触发事件数 | 12个 | 8-20个 | 影响叙事密度 |
| NPC好感剧情关联数 | 5个 | 3-8个 | 影响NPC重要性 |
| 多周目继承科技比例 | 50% | 30-80% | 影响重玩门槛 |

| 剧情事件BGM降低 | 3dB | 0-6dB | 影响叙事氛围 |
| 分支锁定不可逆点 | 确认后 | 选择后3秒 | 影响后悔空间 |
