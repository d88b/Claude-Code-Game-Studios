## Overview

新手教程系统通过7个渐进式阶段引导玩家学习基础移动、潜艇操控、资源采集、战斗基础、建造系统、防守波次和目标系统。每个阶段由事件触发（游戏开始/靠近潜艇/发现资源/遭遇敌人等），通过提示框、键位高亮和目标箭头进行非侵入式教学。教程可跳过、可回顾，教程进度存入存档系统。

---

## Player Fantasy

玩家应感受到：
- **渐进式学习的自然流畅** — 不是一次性灌输所有信息，而是在合适的时机学到合适的知识
- **实践中的成就感** — 移动10米就完成教程阶段1，下潜20米就完成阶段2，小目标不断确认
- **老玩家的尊重** — 可随时跳过教程，不被强制打断
- **教程回顾的安心感** — 设置中随时回看已完成的教程内容

## Detailed Rules

### 教程阶段划分

| 阶段 | 时长 | 教学内容 | 触发时机 | 完成条件 |
|------|------|---------|---------|---------|
| 阶段1 | 2分钟 | 基础移动、视角控制 | 游戏开始后5秒 | 移动距离 > 10米 |
| 阶段2 | 3分钟 | 潜艇操控、下潜上浮 | 玩家靠近潜艇舱 | 下潜深度 > 20米 |
| 阶段3 | 3分钟 | 资源采集、拾取物品 | 玩家靠近资源点 | 收集资源 >= 3个 |
| 阶段4 | 3分钟 | 战斗基础、武器使用 | 第一次遭遇敌人 | 击败敌人 >= 1个 |
| 阶段5 | 3分钟 | 建造系统、设施升级 | 玩家第一次回船 | 完成一次设施升级 |
| 阶段6 | 2分钟 | 防守系统、波次来袭 | 第一次防守波次来袭 | 成功防守一波次 |
| 阶段7 | 2分钟 | 目标系统、钥匙收集 | 玩家发现出口门 | 理解目标系统（靠近门并查看进度） |

### 阶段1：基础移动教学

**触发**: 游戏开始后5秒

**教学内容**:
```
提示框（底部）：
欢迎登上深海堡垒！
让我们先熟悉一下操控：
WASD - 前后左右移动
Shift - 冲刺（消耗体力）
鼠标 - 控制视角方向
试着移动一下吧！
```

**流程**:
1. 显示提示框（3秒后可关闭）
2. 高亮显示WASD键位（白色发光）
3. 玩家移动后 → 提示"很好！继续前进"
4. 引导玩家走到潜艇舱位置

### 阶段2：潜艇操控教学

**触发**: 玩家靠近潜艇舱

**教学内容**:
```
这是你的潜艇！
按 E 键进入潜艇
进入后：
W/S - 前进/后退
A/D - 左转/右转
Space - 上浮
Ctrl - 下潜
F - 开关探照灯
```

**流程**:
1. 高亮显示潜艇
2. 玩家按E进入潜艇
3. 显示潜艇操控提示
4. 引导玩家下潜到浅水区

### 阶段3：资源采集教学

**触发**: 玩家靠近资源点

**教学内容**:
```
发现资源！
靠近资源后按 E 键拾取
不同资源有不同的用途：
• 铁矿 - 基础建造
• 石油 - 船燃料
• 生物样本 - 研究材料
资源会发光，容易发现！
```

**流程**:
1. 高亮显示资源点
2. 玩家靠近后显示拾取提示
3. 玩家拾取后显示"资源+1"
4. 引导玩家收集3个资源

### 阶段4：战斗基础教学

**触发**: 玩家第一次遭遇敌人

**教学内容**:
```
发现敌人！
鼠标左键 - 发射武器
右键 - 瞄准/锁定目标
Q - 声呐探测（发现隐形敌人）
注意：
• 攻击敌人弱点伤害更高
• 保持距离，灵活躲避
• 氧气不足时及时撤退
```

**流程**:
1. 遭遇敌人时显示警告
2. 高亮显示武器发射键
3. 玩家攻击后显示"命中！"
4. 引导玩家击败1个敌人

### 阶段5：建造系统教学

**触发**: 玩家第一次回船

**教学内容**:
```
回到船上！
在这里你可以：
• 升级设施
• 制造装备
• 补充资源
• 修复损伤
按 Tab 打开建造菜单
```

**流程**:
1. 玩家回船后显示建造提示
2. 引导玩家打开建造菜单
3. 演示升级一个设施
4. 显示升级效果

### 阶段6：防守系统教学

**触发**: 第一次防守波次来袭

**教学内容**:
```
⚠ 警告：敌人来袭！
第 1 波 - 小型骚扰
预计持续：2分钟
防守提示：
• 炮台会自动攻击
• 可手动操控炮台精准射击
• 注意各层防线
```

**流程**:
1. 波次来袭前30秒显示警告
2. 波次开始时显示敌人信息
3. 波次结束后显示防守结果
4. 显示奖励内容

### 阶段7：目标系统教学

**触发**: 玩家发现出口门

**教学内容**:
```
发现出口门！
这是你的目标：
• 收集3把钥匙打开门
• 钥匙分散在危险区域
• 需要冒险探索才能找到
钥匙进度：0/3
██████░░░░░░░░░░░░
收集足够钥匙后回来开门！
```

**流程**:
1. 玩家靠近门时显示目标提示
2. 显示钥匙进度条
3. 引导玩家开始寻找钥匙
4. 教程完成，自由探索

### 教程UI设计

**提示框样式**:
- 位置：屏幕底部（不遮挡视野）
- 内容：[图标] 提示标题 + 提示内容 + [跳过] [知道了]
- 自动显示，3秒后可关闭
- 玩家可随时点击"知道了"关闭

**键位高亮**:
- 需要操作的键位白色高亮显示
- 玩家按下后变为绿色
- 3秒后自动消失

**目标箭头**:
- 屏幕边缘箭头 → 指向目标位置
- 引导玩家前往目标位置
- 到达目标后消失
- 可在设置中关闭

### 教程设置选项

| 选项 | 说明 |
|------|------|
| 显示教程 | 开启/关闭教程提示 |
| 键位提示 | 开启/关闭键位高亮 |
| 目标箭头 | 开启/关闭引导箭头 |
| 教程回顾 | 查看已完成的教程内容 |

## Formulas

### 教程完成判定

```
is_tutorial_complete = all(stages_completed[i] for i in 1..7)

stage_completed[1] = player_distance_moved > 10.0m
stage_completed[2] = player_dive_depth > 20.0m
stage_completed[3] = resources_collected >= 3
stage_completed[4] = enemies_defeated >= 1
stage_completed[5] = facility_upgrades_completed >= 1
stage_completed[6] = waves_defended >= 1
stage_completed[7] = has_interacted_with_exit_door
```

### 教程跳过判定

```
can_skip_tutorial = player_has_completed_tutorial_before
                 OR player_input_skip_confirmed

on_skip():
    tutorial_active = false
    tutorial_progress_saved = true
    hide_all_tutorial_ui()
```

### 教程提示自动关闭

```
auto_close_delay = 3.0s  # 提示显示后3秒可自动关闭
min_display_time = 1.0s  # 最小显示时间，防止瞬间关闭
```

### 引导箭头距离计算

```
arrow_direction = normalize(target_position - player_position)
arrow_screen_position = project_to_screen_edge(arrow_direction)
arrow_distance = (target_position - player_position).length()

# 距离目标越近箭头越淡
arrow_alpha = clamp(1.0 - arrow_distance / 100.0, 0.0, 1.0)
```

## Edge Cases

1. **玩家跳过教程后反悔**: 设置中提供"教程回顾"功能，可随时查看已完成的教程内容，但不会重新触发教学流程。
2. **教程触发条件与游戏事件冲突**: 如阶段4（战斗教学）在Boss战中触发，教程提示延迟到Boss战后显示。
3. **教程阶段乱序触发**: 如玩家先遇到敌人（阶段4）再下潜（阶段2），阶段按触发顺序执行，不强制排序。
4. **教程提示框被其他UI遮挡**: 教程提示Z-index高于HUD层但低于菜单层，确保不被状态栏遮挡。
5. **教程存档与加载**: 教程进度存入存档系统，加载存档后恢复已完成的教程阶段状态。
6. **键位高亮与自定义键位冲突**: 键位高亮显示当前输入映射的实际按键，而非固定WASD。
7. **教程阶段完成条件瞬间满足**: 如玩家移动速度极快，0.5秒内移动超过10米，阶段1仍判定为完成。
8. **教程提示关闭后立即触发新提示**: 新提示延迟1秒显示，避免UI闪烁。
9. **老玩家新游戏**: 检测玩家是否已完成过教程，新游戏时提供"跳过教程"选项。
10. **教程中玩家死亡**: 死亡后重新开始，教程阶段重置到阶段1。

## Tuning Knobs

| 参数 | 当前值 | 安全范围 | 影响 |
|------|--------|---------|------|
| 阶段1触发延迟 | 5秒 | 2-10秒 | 影响游戏开始节奏 |
| 提示框自动关闭延迟 | 3秒 | 2-8秒 | 影响阅读时间 |
| 最小显示时间 | 1秒 | 0.5-2秒 | 防止瞬间关闭 |
| 阶段1完成移动距离 | 10米 | 5-20米 | 影响教学难度 |
| 阶段2完成下潜深度 | 20米 | 10-50米 | 影响潜艇教学深度 |
| 阶段3完成收集数量 | 3个 | 2-5个 | 影响采集教学长度 |
| 键位高亮持续时间 | 3秒 | 2-5秒 | 影响引导可见性 |
| 引导箭头淡出距离 | 100米 | 50-200米 | 影响引导范围感 |
| 教程提示Z-index | 10 | 5-15 | 影响UI层级 |
| 新提示延迟时间 | 1秒 | 0.5-2秒 | 影响UI流畅度 |
| 波次预警提前时间 | 30秒 | 15-60秒 | 影响准备时间 |
| 教程跳过检测 | 已完成过教程 | 可选强制跳过 | 影响老玩家体验 |

## Acceptance Criteria

- [ ] 游戏开始后5秒显示阶段1移动教学提示框
- [ ] 玩家移动距离超过10米后阶段1标记为完成
- [ ] 玩家靠近潜艇舱时显示阶段2潜艇操控教学
- [ ] 玩家下潜深度超过20米后阶段2标记为完成
- [ ] 玩家靠近资源点时显示阶段3资源采集教学
- [ ] 玩家收集3个资源后阶段3标记为完成
- [ ] 第一次遭遇敌人时显示阶段4战斗教学
- [ ] 玩家击败1个敌人后阶段4标记为完成
- [ ] 玩家第一次回船时显示阶段5建造教学
- [ ] 玩家完成一次设施升级后阶段5标记为完成
- [ ] 第一次波次来袭前30秒显示阶段6警告
- [ ] 玩家成功防守一波次后阶段6标记为完成
- [ ] 玩家靠近出口门时显示阶段7目标系统教学
- [ ] 教程可随时跳过，跳过后隐藏所有教程UI
- [ ] 设置中可查看已完成的教程内容（教程回顾）
- [ ] 教程进度存入存档系统，加载后恢复完成状态
- [ ] 键位高亮显示当前输入映射的实际按键
- [ ] 教程提示框3秒后可自动关闭，最小显示1秒
