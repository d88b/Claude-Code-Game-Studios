## Overview

导航地图系统管理船只航线规划、海域地图生成、雷达/声呐探测、标记系统和潜艇探索地图渐进揭示。系统支持自动/手动/混合三种航行模式，4级雷达（200m-2000m）和4级声呐（100m-800m）探测不同内容，6种标记类型（资源/敌人/遗迹/补给/危险/自定义）帮助玩家记录重要位置，潜艇探索地图采用战争迷雾式渐进揭示+自动记录已探索区域。

---

## Player Fantasy

玩家应感受到：
- **航线规划的掌控感** — 最短路径/安全路径/资源路径三种方案可选，地图点击设定目标，实时显示距离和预计到达时间
- **探索未知的紧张感** — 潜艇探索地图从战争迷雾中逐步揭示，已探索区域白色、未探索区域灰色，探索进度百分比实时显示
- **雷达声呐的信息优势** — 雷达显示水面/空中敌人和资源，声呐探测水下敌人和隐藏资源，等级越高探测越远越详细
- **标记系统的便利性** — 永久标记保存重要地点（遗迹/补给点），临时标记记录探索发现，离开海域自动清理

## Detailed Rules

### 航行控制模式

| 模式 | 说明 | 操作方法 |
|------|------|---------|
| 自动航行 | 设置目标海域后自动沿最优路径航行 | 地图点击目标海域 |
| 手动航行 | 玩家手动控制航向和速度 | 键盘WASD/手柄摇杆 |
| 混合航行 | 自动为主，可手动微调方向 | 自动航线+手动方向覆盖 |

### 航线规划

| 规划类型 | 特点 | 适用场景 |
|---------|------|---------|
| 最短路径 | 距离最短，可能经过危险区 | 紧急赶路 |
| 安全路径 | 避开危险海域，距离较长 | 安全优先 |
| 资源路径 | 经过资源丰富区域，距离最长 | 采集资源 |
| 自定义路径 | 玩家手动设定航点 | 特定需求 |

### 雷达系统（船只水面探测）

| 等级 | 探测范围 | 探测内容 | 能源消耗 | 解锁条件 |
|------|---------|---------|---------|---------|
| 基础 | 200m | 敌人位置 | 0 | 船Lv1 |
| 强化 | 500m | 敌人+资源 | 0.1单位/s | 船Lv2 |
| 深海 | 1000m | 敌人+资源+遗迹 | 0.2单位/s | 船Lv3 |
| 终极 | 2000m | 全信息+预警 | 0.3单位/s | 船Lv4 |

### 声呐系统（潜艇水下探测）

| 等级 | 探测范围 | 探测内容 | 能源消耗 | 解锁条件 |
|------|---------|---------|---------|---------|
| 基础 | 100m | 敌人位置 | 2单位/次 | 潜艇Lv1 |
| 强化 | 200m | 敌人+隐形敌人 | 3单位/次 | 潜艇Lv2 |
| 深海 | 400m | 敌人+资源+隐形敌人 | 5单位/次 | 潜艇Lv3 |
| 终极 | 800m | 全信息+隐藏资源 | 8单位/次 | 潜艇Lv4 |

雷达为持续消耗（单位/s），声呐为脉冲消耗（单位/次）。

### 海域地图生成

| 元素 | 生成规则 | 分布密度 |
|------|---------|---------|
| 浅水区 | 随机分布 | 高密度 |
| 深水区 | 随机分布 | 中密度 |
| 深海区 | 固定位置 | 低密度 |
| 深渊区 | 固定位置 | 极低密度 |
| 遗迹 | 固定位置 | 1-3个/海域 |
| Boss区域 | 固定位置 | 1个/海域 |
| 补给点 | 随机分布 | 3-5个/海域 |
| 洞穴入口 | 随机分布 | 2-4个/海域 |

使用种子随机+固定锚点混合生成，确保同一种子海域布局一致。

### 标记系统

| 标记类型 | 用途 | 保存方式 |
|---------|------|---------|
| 资源点标记 | 标记资源丰富区域 | 临时（离开海域消失） |
| 敌人标记 | 标记敌人密集区域 | 临时 |
| 遗迹标记 | 标记遗迹位置 | 永久保存 |
| 补给点标记 | 标记补给点位置 | 永久保存 |
| 危险区标记 | 标记危险区域 | 永久保存 |
| 自定义标记 | 玩家自定义名称/备注 | 永久保存 |

最多同时存在20个标记。临时标记不占用上限。

### 潜艇探索地图

- **渐进揭示**：进入探索区域后地图从战争迷雾（灰色）逐步揭示为已探索（白色）
- **自动记录**：已探索区域永久保存，下次进入同一海域直接显示
- **探索进度**：百分比显示当前海域已探索程度
- **迷路提示**：停留原地超过30秒提示方向，洞穴中迷路提示出口方向，氧气低于50%提示最近补给点

### 导航预警系统

**航行预警**:

| 预警类型 | 触发条件 | 预警内容 |
|---------|---------|---------|
| 海域进入 | 进入新海域 | 海域名称和危险度 |
| 航线危险 | 航线经过危险区 | 危险区域提示 |
| 敌人接近 | 敌人接近航线 | 敌人位置和距离 |
| 波次来袭 | 波次即将开始 | 波次信息和倒计时 |

**探索预警**:

| 预警类型 | 触发条件 | 预警内容 |
|---------|---------|---------|
| 低氧气 | 氧气<50% | 最近补给点方向 |
| 低能源 | 能源<30% | 最近补给点方向 |
| 敌人接近 | 敌人进入探测范围 | 敌人位置和距离 |
| 危险区域 | 进入危险区 | 区域危险信息 |

Godot实现：使用`Navigation2D`/`NavigationAgent2D`做航线规划，`TileMap`做海域地图基础，`CanvasLayer`做UI覆盖，`Timer`做周期性探测。

## Formulas

### 航行时间计算

```
travel_time = distance / speed
# speed受天气/海况/船等级影响
effective_speed = base_speed * weather_multiplier * sea_condition_multiplier

# 示例: base_speed=10m/s, weather=0.8(轻风), sea_condition=0.9(轻浪)
# effective_speed = 10 * 0.8 * 0.9 = 7.2 m/s
# travel_time for 5000m = 5000 / 7.2 ≈ 694s ≈ 11.6分钟
```

### 航线评分

```
route_score = (
    distance_weight * (1.0 - distance / max_distance) +
    safety_weight * (1.0 - danger_level / max_danger) +
    resource_weight * (resource_density / max_density)
)
# 最短路径: distance_weight=0.7, safety_weight=0.1, resource_weight=0.2
# 安全路径: distance_weight=0.2, safety_weight=0.7, resource_weight=0.1
# 资源路径: distance_weight=0.1, safety_weight=0.2, resource_weight=0.7
```

### 探测范围计算

```
radar_range = base_range * level_multiplier
# 基础: 200m, 强化: 500m, 深海: 1000m, 终极: 2000m
# 天气影响: storm → range * 0.5, fog → range * 0.7

sonar_range = base_range * level_multiplier * water_clarity
# 基础: 100m, 强化: 200m, 深海: 400m, 终极: 800m
# 水质影响: clear=1.0, murky=0.7, polluted=0.5
```

### 探索进度计算

```
exploration_progress = (explored_cells / total_cells) * 100
# total_cells = 海域TileMap总面积 / reveal_cell_size
# 探索单元格大小: 默认10x10 tile
```

### 标记管理

```
max_permanent_markers = 20
# 临时标记（资源/敌人）不计入上限
# 永久标记（遗迹/补给/危险/自定义）计入上限
# 超出上限时提示"标记已满，请删除部分标记后再添加"
```

## Edge Cases

1. **自动航行中遭遇敌人拦截**: 自动暂停，提示"航线受阻"，切换到手动模式或重新规划路径。重新规划优先安全路径。
2. **雷达/声呐探测到大量目标导致UI拥挤**: 聚合近距离目标显示（如"附近3个敌人"），点击聚合图标展开列表。最多显示20个独立目标。
3. **标记数量达到20个上限**: 提示"标记已满"，不拒绝新标记请求而是引导删除。提供"清除所有临时标记"快捷按钮。
4. **探索地图加载存档后迷雾状态不正确**: 存档中保存`explored_cells`位图，加载后恢复已探索区域。新海域从全迷雾开始。
5. **航线规划目标海域不可达**（被陆地/障碍物阻挡）: BFS路径验证失败，提示"目标不可达"，建议最近可达位置。
6. **声呐在浅水区（<20m）使用**: 声呐效果衰减50%，提示"浅水区声呐效果受限"。深海声呐在浅水区降级为强化声呐效果。
7. **夜间雷达/声呐探测范围缩减**: 雷达夜间-30%（见日夜循环系统），声呐不受夜间影响（水下传播）。天气和夜间效果叠加计算。
8. **潜艇探索时迷路但所有提示都已用尽**: 提供"紧急上浮"选项，直接返回水面当前位置（消耗10%能源），不丢失已探索区域。
9. **自定义标记名称过长或含特殊字符**: 名称限制20字符，过滤特殊字符，超限时截断并提示。
10. **海域地图种子相同但生成结果不一致**: 使用固定随机数种子确保一致性。加载存档时使用存档中的种子值。

## Tuning Knobs

| 参数 | 当前值 | 安全范围 | 影响 |
|------|--------|---------|------|
| 基础航行速度 | 10 m/s | 5-15 m/s | 影响移动节奏 |
| 雷达基础范围 | 200m | 100-300m | 影响早期探测能力 |
