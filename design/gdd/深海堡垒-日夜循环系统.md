## Overview

日夜循环系统管理18分钟完整周期的四时段变化（白天8分钟→黄昏2分钟→夜晚6分钟→黎明2分钟），通过光照参数、视野范围、敌人类型替换、装备依赖和UI提示为玩家提供策略性探索节奏。白天正常探索，夜间视野减半、探照灯强制开启、氧气消耗增加10%、夜间专属敌人出现。系统与天气系统联动（风暴+夜晚光照0%），支持满月/新月/月蚀等月光事件和星空璀璨/流星等特殊夜晚事件。

---

## Player Fantasy

玩家应感受到：
- **日夜节奏的策略规划** — 白天充分利用良好视野探索，黄昏前做好准备，夜间谨慎行动
- **光照变化的沉浸感** — 黄昏橙黄色渐变、深蓝月光、水下光线随深度衰减，过渡自然无突兀切换
- **夜间风险的紧张感** — 视野减半、夜间专属敌人出现（暗影鱼隐形、幽灵水母发光）、探照灯能源消耗
- **装备升级的成就感** — 从基础探照灯到深海探照灯，从基础夜视仪到零能耗深海夜视仪

## Detailed Rules

### 四时段划分

| 时段 | 时长 | 光照状态 | 特点 |
|------|------|---------|------|
| 白天 | 8分钟 | 100%光照 | 正常探索，视野200m |
| 黄昏 | 2分钟 | 70%→50%渐变 | 过渡时段，夜间敌人开始出现 |
| 夜晚 | 6分钟 | 20%月光 | 视野减至100m，探照灯强制开启 |
| 黎明 | 2分钟 | 50%→70%渐变 | 过渡时段，夜间敌人减少 |

总周期：18分钟。白天占比44%，夜晚33%，过渡时段22%。

### 深度光照衰减

| 深度 | 白天光照 | 夜晚光照 | 说明 |
|------|---------|---------|------|
| 0-50m | 80% | 10%（月光透入） | 浅水受月光影响 |
| 50-100m | 60% | 5% | 中层光线弱 |
| 100-200m | 40% | 0% | 深水无光线 |
| 200m+ | 20%→0% | 0% | 深海无光线 |

| 影响项 | 白天 | 夜晚 | 说明 |

| 氧气消耗 | 正常 | +10% | 夜间消耗略增 |
| 探照灯能源 | 不消耗 | 0.5单位/s | 夜间必须开启 |

| 雷达探测范围 | 正常 | -30% | 夜间雷达受限 |
| 预警时间 | 正常 | 延迟 | 夜间预警缩短 |

| 浓雾 | 40% | 0% |

### UI提示

- **时段进度条**：当前时段名称+剩余时间+进度条
- **时段过渡提示**：黄昏即将来临时弹出，提示特点和准备建议
- **夜间警告**：夜晚来临时显示影响列表和建议
- Godot实现：使用`Timer`节点控制周期，`Tween`做光照渐变过渡，`WorldEnvironment`节点控制光照参数

## Formulas

### 日夜周期计算

```
cycle_duration = 18 * 60  # 1080秒 = 18分钟
day_duration = 8 * 60      # 480秒
dusk_duration = 2 * 60     # 120秒
night_duration = 6 * 60    # 360秒
dawn_duration = 2 * 60     # 120秒

current_phase = elapsed_time % cycle_duration
if current_phase < day_duration:
    phase = "day"
elif current_phase < day_duration + dusk_duration:
    phase = "dusk"
elif current_phase < day_duration + dusk_duration + night_duration:
    phase = "night"
else:
    phase = "dawn"
```

### 光照计算

```
base_light = {
    "day": 1.0,
    "dusk": 0.7 - 0.2 * (dusk_progress),  # 0.7 → 0.5
    "night": 0.2,
    "dawn": 0.5 + 0.2 * (dawn_progress)   # 0.5 → 0.7
}

depth_factor = clamp(1.0 - (depth / 250.0), 0.0, 1.0)
final_light = base_light * depth_factor * weather_multiplier
```

### 夜间氧气消耗

```
oxygen_consumption = base_consumption * (1.10 if is_night else 1.0)
```

### 视野范围计算

```
view_range = base_view_range * (0.5 if is_night else 1.0)
# 夜视仪加成
view_range += night_vision_bonus  # +50m/+100m/+150m
# 探照灯范围独立于视野范围
searchlight_range = searchlight_tier_range  # 50m/80m/120m/200m
```

## Edge Cases

1. **时段切换时玩家正在战斗中**: 光照渐变继续，不打断战斗。战斗结束后再弹出时段过渡提示。
2. **探照灯能源耗尽**: 夜间探照灯能源耗尽后视野降至5m（极暗），氧气消耗因恐慌+20%，提示"紧急返回"。
3. **日夜特殊事件与Boss战重叠**: Boss战优先级更高，特殊事件延迟到Boss战后触发，但奖励保留。
4. **天气+夜晚组合导致光照0%**（如风暴+夜晚）: 玩家必须使用探照灯，否则视野降至10m。不报错，UI显示"极度黑暗"警告。
5. **黄昏过渡期间玩家进入深海区**: 深海区本就无光线，黄昏/夜晚光照差异不明显。UI提示"深海区域，光线不受日夜影响"。
6. **日夜循环计时器加载存档后不同步**: 存档中记录`cycle_elapsed_time`，加载后从此值恢复。新游戏从零开始。
7. **满月/新月/月蚀周期与玩家游戏时间不匹配**: 月光事件基于游戏内时间独立运行，不依赖现实时间。周期为7天（游戏内）。
8. **日夜UI在低配置下Shader性能问题**: 光照渐变使用`WorldEnvironment`参数Tween，不使用逐像素Shader。性能开销<1ms。
9. **夜间型敌人在黎明时段未正确消失**: 敌人消失有30秒缓冲期，缓冲期内敌人仍正常行为但不再新生成。
10. **玩家跳过时段过渡提示后不知道当前时段**: HUD始终显示当前时段图标（太阳/月亮），不需要打开提示即可查看。
