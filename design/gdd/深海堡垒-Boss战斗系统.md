## Overview

Boss战斗系统管理5种主要Boss和6种NPC船只Boss的多阶段战斗机制，包括4阶段行为模式、弱点暴露窗口、狂暴机制、时间限制、转场动画、战斗UI、BGM动态变化、战后评分结算和重复挑战机制。所有Boss遵循统一的BossConfig数据驱动架构，使用状态机（INTRO→PHASE1-4→RAGE→DEATH）驱动阶段转换。

---

## Player Fantasy

玩家应感受到：
- **Boss登场的压迫感** — 风暴领主从乌云中显现、深渊巨兽从深渊升起，专属转场动画营造史诗感
- **弱点暴露的策略快感** — 发现弱点窗口（3-5秒），集中火力造成3.0x伤害，精准打击的满足感
- **狂暴阶段的终极紧张** — Boss血量降至15%以下全身发红，攻击+40%速度+30%，必须在狂暴中求生
- **战后评分的成就感** — S级无伤通关获得2倍奖励+特殊成就，激励重复挑战

### Boss阶段行为（通用4阶段模型）

所有Boss遵循相同的4阶段框架，血量阈值分别为75%/50%/25%（部分Boss有差异）：

| 阶段 | 血量区间 | 行为特点 | 弱点暴露 |
|------|---------|---------|---------|
| P1 | 100%-75% | 基础攻击模式，召唤小怪 | 无 |
| P2 | 75%-50% | 新攻击模式，弱点暴露3-5秒 | 暴露（3.0x伤害） |
| P3 | 50%-25% | 高速/分裂/再生，更激进 | 无或部分 |
| P4 | 25%-0% | 终极形态，弱点持续暴露但攻击更猛 | 持续暴露 |

### 转场动画

**Boss出现动画时长**: 风暴领主5秒、深渊巨兽5秒、寄生女王4秒、海盗王4秒（玩家可操控）、远古守卫5秒。

**阶段转换**: 1-2秒短暂暂停，Boss发光/变色/形态变化，屏幕震动/闪白，玩家不可攻击0.5秒。

**Boss死亡**: 爆炸/消散/沉没特效，奖励散落，慢动作2秒，胜利音效+Boss惨叫，渐黑→结算界面。

### Boss数据驱动配置

BossConfig资源类包含: boss_name, max_hp, attack_damage, move_speed, phase_count(默认4), phase_thresholds([0.75, 0.5, 0.25]), rage_threshold(0.15), time_limit(秒，0=无限制), weakness_exposure_phases([1, 3]表示P2/P4), weakness_damage_multiplier(3.0), drops掉落表, bgm_resource, intro_animation, death_animation。

### Boss状态机

状态: INTRO → PHASE1 → PHASE2 → PHASE3 → PHASE4 → RAGE → DEATH

阶段转换由HP比例触发: HP≤25%进入P4，HP≤15%进入RAGE（免疫STUNNED）。阶段进入时触发phase_changed信号，更新UI、切换BGM、播放转场动画。

## Formulas

### 阶段转换判定

```
hp_ratio = current_hp / max_hp

if hp_ratio <= 0.25: phase = PHASE4
elif hp_ratio <= 0.50: phase = PHASE3
elif hp_ratio <= 0.75: phase = PHASE2
else: phase = PHASE1

if hp_ratio <= 0.15 and phase != RAGE: phase = RAGE
```

### 弱点伤害

```
damage = base_damage × weakness_damage_multiplier(3.0)
```

弱点仅在特定阶段暴露（P2/P4），暴露时有倒计时窗口（3-5秒）。

### 狂暴状态数值

```
enraged_attack_damage = base_damage × 1.4
enraged_move_speed = base_speed × 1.3
enraged_attack_interval = base_interval × 0.7
enraged_immune_to_stun = true
```

### 评分计算

```
评分基于两个维度：受伤百分比 和 用时百分比

S: damage_taken < 20% AND time_used < 50%
A: damage_taken < 20% AND time_used < 70%
B: damage_taken < 50% AND time_used < 100%
C: damage_taken < 80%
D: damage_taken >= 80%

reward = base_reward × score_multiplier
S=2.0, A=1.5, B=1.0, C=0.8, D=0.5
```

### 重复挑战掉落衰减

```
repeat_drop_rate = base_drop_rate × max(0.5, 1.0 - challenge_count × 0.1)
```

第1次重复：-10%，第2次：-20%，...，最低50%。

### 掉落概率（含幸运值）

```
final_drop_rate = base_rate × (1 + luck_value × 0.005) × sea_area_modifier × boss_modifier
```

## Edge Cases

1. **Boss时间限制超时**: Boss逃离/撤退，战斗判定为失败，玩家获得部分奖励（评分D的50%）。
2. **狂暴+眩晕冲突**: 狂暴状态免疫STUNNED，已进入狂暴的Boss不会因重击眩晕。
3. **Boss战中玩家船只HP归零**: 船只被摧毁触发游戏结束，Boss战终止。
4. **多Boss同时出现**: 特殊事件可能触发多个Boss，但设计上避免这种情况，如发生则按优先级队列处理。
5. **召唤物达到上限**: Boss召唤的小怪数量有上限（通常6个），达到后暂停召唤直到有召唤物被消灭。
6. **Boss再生被打断**: 如深渊巨兽P3每10秒回复2%HP，集中输出可打断再生过程。
7. **弱点暴露期间Boss死亡**: 弱点暴露窗口内Boss被击杀，弱点倒计时立即终止，正常播放死亡动画。
8. **Boss阶段转换期间玩家死亡**: 阶段转换0.5秒玩家不可攻击期间如果受到持续伤害死亡，正常触发游戏结束。
9. **重复挑战奖励衰减下限**: 掉落率最低50%，即使重复挑战10次也不会低于基础值的一半。
10. **地狱模式狂暴提前**: 地狱模式下狂暴阈值从15%提前到30%，Boss更早进入狂暴状态。
11. **NPC船只Boss逃离**: NPC船只Boss在P4阶段如果HP极低，有概率逃离战场，战斗提前结束。
12. **Boss战BGM切换延迟**: 阶段转换时BGM切换可能有1-2秒延迟，设计上在阶段转换动画期间完成BGM切换以掩盖延迟。
