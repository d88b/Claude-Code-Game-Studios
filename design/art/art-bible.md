## Section 1: Visual Identity Statement

### One-Line Visual Rule

> **每一帧画面都是赛博朋克废土与宇宙恐怖交织的概念插画——霓虹符文在暴风雨中闪烁，虫族生物在沙尘暴中涌动，克苏鲁的阴影在深层潜伏，天气与魔导科技在每一处交互。**

### Supporting Visual Principles

| Principle | Definition | Design Test |
|-----------|------------|-------------|
| **赛博朋克魔导美学** | 魔导科技与赛博朋克的融合——魔力晶石像霓虹灯管般发光，符文电路像芯片纹路般刻蚀，战车既是改装废土车又有赛博改装感。不出现纯蒸汽朋克或纯科幻风格。 | 当战车看起来像"柴油卡车"时，增加霓虹符文电路和赛博改装元素（LED魔力条、电路板符文）。 |
| **虫族有机恐怖** | 墓园势力采用虫族风格——有机生物群、蜂巢式巢穴、蠕动的触须、生物质感而非骨骼质感。保留亡灵身份但增加克苏鲁腐化变异。 | 当丧尸看起来像"传统亡灵"时，增加有机质感和虫族元素（蠕动的肢体、粘液、蜂巢结构）。 |
| **克苏鲁深渊渗透** | 地狱势力保留恶魔身份但融入克苏鲁式的宇宙恐怖——不可名状的形态、扭曲的维度、触手与眼球、深渊的呼唤。深层地下是克苏鲁渗透的区域。 | 当恶魔看起来像"传统地狱怪"时，增加克苏鲁元素（触手、眼球组合、扭曲空间感）。 |
| **天气交互叙事** | 天气是动态的游戏机制——暴风雨降低视野增加魔能消耗，沙尘暴减缓战车速度但增强虫族感知，晴天增加魔力晶石充能效率。天气影响战车、人物、怪物的行为。 | 当天气只是"视觉特效"时，确保它有明确的 gameplay 效果并影响策略决策。 |
| **塔楼低调存在** | 机械阵营（塔楼）保留但视觉风格低调——锈蚀的机械而非闪亮的科技，损坏的AI而非精密的机器人。它们是废土的残留，次要敌人。 | 当机械敌人抢夺视觉焦点时，降低其视觉复杂度和威胁感，让虫族和克苏鲁成为主要恐惧来源。 |

### Faction Visual Identity

| Faction | Core Identity | New Style Fusion | Dominant Colors |
|---------|---------------|------------------|-----------------|
| **墓园 (Graveyard)** | 亡灵、丧尸、骷髅、尸巫 | 虫族有机质感 + 克苏鲁腐化变异（粘液、蠕动、蜂巢） | 腐烂绿 + 灰白 + 生物粘液青 |
| **地狱 (Hell)** | 恶魔、恶魔领主、深渊领主 | 克苏鲁宇宙恐怖 + 触手/眼球/不可名状 | 暗红 + 火焰橙 + 深渊紫黑 |
| **塔楼 (Tower)** | 机械守卫、魔像、泰坦 | 锈蚀残留机械（低调、次要威胁） | 锈铁色 + 锈蚀蓝 + 破损金属灰 |
| **元素 (Element)** | 变异野兽、元素生物 | 天气交互系统（风暴/沙尘/闪电） | 晶石紫 + 天空蓝 + 闪电白 |
| **玩家科技** | 战车、炮塔、要塞 | 赛博朋克魔导风格（霓虹符文、电路魔力） | 霓虹蓝 + 秘银银 + 符文金 |

| **战车出发** | 期待与危险感 | 黎明/黄昏光线，地堡出口的光线渐变，地平线剪影 | 辽阔、未知、压迫、自由边缘、冒险 | 紧张上升 |

| **撤退奔逃** | 恐慌与绝望 | 天色渐暗/魔能警告红灯闪烁，后视镜追兵剪影 | 恐慌、绝望、紧迫、逃离、最后机会 | 惊恐峰值 |

| **防守失败/退守内层** | 挫败但未放弃 | 外层被破坏的火光，内层紧急灯的冷酷蓝光，烟雾渗透 | 挫败、缩退、损失、未放弃、新防线 | 低谷紧张 |
| **深层地下探索** | 恐惧与好奇 | 克苏鲁式扭曲光线，魔力晶石的诡异紫光，深渊的不可见 | 恐惧、好奇、深渊、不可名状、宇宙恐怖 | 深层恐惧 |
| **克苏鲁遭遇** | 绝望与认知崩塌 | 维度扭曲的光线，触手/眼球组合的怪异发光，现实边界模糊 | 绝望、认知崩塔、不可名状、超越理解、深渊凝视 | 极端恐怖 |

### Weather System Atmosphere Rules

| 天气类型 | 视觉氛围 | Gameplay 影响 |
|----------|----------|---------------|
| **晴天** | 明亮自然光，高对比度，魔能晶石充能效率提升，视野清晰 | 魔能恢复+20%，视野最大化，最佳探索时机 |
| **暴风雨** | 暗沉天空，闪电照明，雨幕降低视野，霓虹符文在暗处发光 | 魔能消耗+30%，视野-50%，虫族感知-20%（雨水掩盖），战车速度-15% |
| **沙尘暴** | 黄褐色滤镜，低对比度，模糊边界，虫族在尘暴中活跃 | 视野-70%，战车速度-30%，虫族感知+40%（震动感应），元素晶石感知+30% |
| **雷暴** | 闪电间隙照明，高对比度瞬间爆发，电力设施短暂充能 | 闪电可短暂充能炮塔，元素晶石充能+50%，恶魔类敌人活动增强 |
| **雾霾** | 低对比度灰色滤镜，克苏鲁式朦胧感，深渊渗透 | 视野-40%，克苏鲁生物活跃度+30%，精神压力感增加 |

### Atmospheric Transition Guidelines

- **从安全到危险**：光线从温暖渐变到冷酷，对比度从低到高，声音从安静到嘈杂
- **从危险到安全**：反向渐变，但保留"伤痕感"——成功的防守后仍有血迹、硝烟、损坏痕迹
- **天气切换**：有30秒过渡动画，天空颜色渐变、粒子系统切换、环境声音过渡
- **克苏鲁氛围渗透**：深层探索时，正常光线逐渐扭曲，视角微微颤动，声音出现"低语"层

## Section 3: Shape Language

### Character Silhouette Philosophy

**战车**：
- **剪影识别点**：厚重的车身轮廓 + 霓虹魔力条沿边缘发光 + 改装部件的凸起轮廓
- **缩略图可读**：战车必须是"一个有发光边缘的移动方块"——不是精致的车，而是改装的废土战车
- **区分改装等级**：基础战车（方正轮廓）→ 改装战车（棱角增加、附件凸起）→ 终极战车（复杂轮廓但仍保持厚重感）

**玩家角色（下车）**：
- **剪影识别点**：背包的凸起轮廓 + 手电/魔力灯的光束方向 + 蹲伏时更低矮的轮廓
- **缩略图可读**：玩家下车后是"带背包的渺小剪影"——强调脆弱感，与战车的厚重形成对比
- **生存装备感**：防护服轮廓、头盔、实用装备——不是英雄，而是幸存者

**墓园势力（虫族风格）**：
- **剪影识别点**：蠕动的肢体 + 粘液滴落 + 蜂巢结构组合
- **集群可读**：单个虫族单位是"蠕动的有机形状"，集群是"蠕动的浪潮"
- **区分类型**：工虫（小型蠕动）→ 兵虫（有攻击肢）→ 蜂巢母体（大型触手组合）

**地狱势力（克苏鲁风格）**：
- **剪影识别点**：触手 + 眼球组合 + 扭曲的维度轮廓
- **单体可读**：地狱单位是"不可名状的触手眼球组合"——不是传统恶魔，而是宇宙恐怖
- **区分类型**：小恶魔（触手+小眼球）→ 深渊领主（多触手+大眼球）→ 克苏鲁化身（扭曲维度+触手森林）

**塔楼势力（低调机械）**：
- **剪影识别点**：锈蚀的方形机械 + 破损的金属边角
- **低调可读**：塔楼单位是"锈蚀的方块机械"——不精致，是废土残留
- **次要威胁感**：轮廓简单、威胁感低——让虫族和克苏鲁成为视觉焦点

**元素势力**：
- **剪影识别点**：晶石形状 + 光芒放射 + 天气元素附着
- **动态可读**：元素单位与当前天气绑定——晴天是发光晶石，风暴中有闪电附着

### Environment Geometry

**地表废墟**：
- **主几何**：破碎的直线+锐角（废墟建筑的轮廓）+ 衰败的曲线（腐蚀、锈迹）
- **赛博朋克遗迹**：霓虹招牌的直线 + 电路板的网格 + 融合魔导符文的有机曲线
- **天气附着**：暴风雨时增加雨幕的垂直线，沙尘暴时增加朦胧的模糊边界

**地下要塞**：
- **主几何**：方块+直线（挖掘的隧道）+ 圆形/弧形（玩家建造的设施）
- **玩家痕迹**：直线表示"人工建造"，不规则曲线表示"自然挖掘"
- **防御设施**：炮塔是"方形底座+霓虹发光炮管"，陷阱是"隐藏的几何触发区"

**深层/克苏鲁区域**：
- **主几何**：扭曲的曲线+不可名状的有机形状——"正常的几何开始扭曲"
- **深渊渗透**：直线逐渐弯曲，方形逐渐扭曲，视角微微颤动
- **异界裂隙**：克苏鲁裂隙是"维度裂缝"——不是几何形状，而是空间扭曲

### UI Shape Grammar

**HUD风格**：**半沉浸式（semi-diegetic）**
- 主HUD元素采用赛博朋克魔导风格——霓虹边框+符文背景
- 数值显示用"魔力条"而非传统进度条——霓虹发光的边缘
- 警告状态用"符文闪烁"而非传统红框——魔导风格的警报

**主要UI形状**：

| UI元素 | 形状语言 | 风格融合 |
|--------|----------|----------|
| **魔能条** | 霓虹发光的弧形条 | 赞博朋克+魔导 |
| **耐久/生命** | 秘银质感的方形条 | 废土金属质感 |
| **资源计数** | 晶石形状的图标+数字 | 元素晶石风格 |
| **撤退警告** | 闪烁的符文边框 | 导警报 |
| **尸潮倒计时** | 震动的数字+背景渐暗 | 紧张感UI |
| **天气状态** | 天气符号+滤镜图标 | 天气系统专属 |
| **阵营科技树** | 电路板网格布局 | 赛博朋克科技树 |

**UI与世界的呼应**：
- HUD边框采用与战车相同的霓虹符文风格——沉浸感
- 天气UI图标采用与元素势力相同的晶石形状——一致性
- 警告状态采用与克苏鲁区域类似的扭曲效果（极端警告时）——恐怖感渗透

### Hero Shapes vs. Supporting Shapes

| Hero Shapes（吸引视觉焦点） | Supporting Shapes（退居背景） |
|----------------------------|------------------------------|
| 战车的霓虹边缘发光 | 废墟的衰败背景纹理 |
| 虫族集群的蠕动浪潮 | 塔楼机械的锈蚀方正 |
| 克苏鲁的触手眼球组合 | 地表沙尘/雨幕的朦胧 |
| 炮塔的魔力发射光束 | 地堡墙壁的基础纹理 |
| 玩家的手电光束方向 | 环境的阴影区域 |
| 天气的闪电/风暴效果 | 平静天空的背景 |
| 资源的晶石闪光 | 地面的普通纹理 |

### Colorblind Safety

| 可能冲突 | 冲突描述 | 备用区分方案 |
|----------|----------|--------------|
| **腐烂绿 vs 天空灰** | 红绿色盲可能混淆虫族与天气背景 | 虫族增加"蠕动"动画特征，天气增加"滤镜"视觉特征 |
| **火焰橙 vs 霓虹蓝** | 某些色盲可能减弱区分 | 火焰橙用"闪烁+高温感"动画，霓虹蓝用"稳定冷光"特征 |
| **深渊紫黑 vs 锈色** | 低对比区域可能混淆 | 深渊紫黑用"扭曲"效果，锈色用"粗糙纹理"特征 |
| **阵营识别依赖色** | 色盲玩家阵营识别困难 | 每个阵营增加独特的"形状特征"：虫族=蠕动、克苏鲁=触手、塔楼=锈方块、元素=晶石 |

**色盲友好规则**：
- 不单独依赖颜色传达关键信息——必须有形状/动画/纹理备份
- 敌人阵营识别：颜色 + 独特形状组合
- 资源类型识别：颜色 + 晶石形状差异
- 警告状态识别：颜色 + 符文闪烁频率

## Section 6: Environment Design Language

### Architectural Style

**地表废墟风格**：
- **建筑原型**：赛博朋克末世废墟 + 魔导科技残留
- **文化历史痕迹**：
  - 霓虹招牌的残留（赛博朋克遗迹）——闪烁的魔力晶石灯，破碎的电路符文
  - 废弃的魔导工厂（工业残留）——符文刻蚀的管道，魔力熔炉的残骸
  - 民用建筑的衰败（生活痕迹）——破损的防护窗，贴符文的门框
- **时间感传达**：所有建筑都有"三个月内崩溃"的痕迹——突然的遗弃，而非缓慢的衰败

**地下要塞风格**：
- **玩家建造痕迹**：直线+方块（人工挖掘）vs 不规则曲线（自然洞穴）
- **防御设施风格**：
  - 炮塔：方形底座 + 霓虹发光炮管（赛博魔导风格）
  - 陷阱：隐藏触发区 + 符文发光警告
  - 闸门：厚重防爆门 + 魔力锁定符文
- **生活区域风格**：
  - 仓库：朴素方块堆叠 + 魔能照明
  - 维修站：工业设备 + 霓虹魔能条
  - 卧室/重生室：简约生活痕迹 + 赛博魔导装备架

**深层/克苏鲁区域风格**：
- **建筑原型**：扭曲的古代遗迹 + 维度裂缝
- **克苏鲁渗透痕迹**：
  - 正常建筑的边界开始扭曲——直线弯曲、方块不规则
  - 出现"不可名状"的有机结构——触手纹理、眼球图案
  - 维度裂缝——空间的撕裂，而非建筑的破损
- **深渊氛围**：从"废墟"到"异界"的渐进过渡

### Texture Philosophy

**数字绘画风格纹理**：
- **核心哲学**：概念美术质感而非真实材质——笔触感、绘画层次、艺术质感
- **纹理类型**：

| 纹理类型 | 笔触特征 | 色调处理 |
|----------|----------|----------|
| **废墟墙面** | 粗犷笔触、衰败层次、锈迹叠加 | 锈色为主，赛博霓虹残留 |
| **地下隧道** | 较平滑笔触、挖掘痕迹、光影层次 | 秘银银+泥土色，玩家光源 |
| **克苏鲁区域** | 扭曲笔触、有机曲线、不规则纹理 | 深渊紫黑+腐烂绿，扭曲光线 |
| **战车表面** | 精致笔触、金属光泽、符文电路 | 秘银银+霓虹蓝，赛博魔导 |
| **丧尸肉体** | 有机笔触、腐烂质感、粘液层 | 腐烂绿+灰白，虫族变异 |
| **晶石/元素** | 发光笔触、光芒放射、天气附着 | 霓虹蓝+天气色 |

**纹理层级**：
- **基础层**：区域主色调（废墟锈色、地下泥土色、深渊紫黑）
- **细节层**：衰败细节（裂痕、锈迹、粘液）
- **天气层**：天气附着（雨幕、尘暴、闪电）
- **发光层**：魔能发光（霓虹蓝、符文金、晶石闪光）

### Prop Density Rules

| 区域类型 | 道具密度 | 密度原因 |
|----------|----------|----------|
| **地表废墟（搜刮区域）** | 高密度 | 搜刮是核心玩法，废墟必须有可搜刮的容器 |
| **地表废墟（通道）** | 中密度 | 行走通道需保持可通行，但有余留痕迹 |
| **地下要塞（玩家建造）** | 可变密度 | 玩家决定密度——功能区域密集，通道稀疏 |
| **地下深层（遗迹）** | 中低密度 | 遗迹是发现区域，保持神秘感 |
| **克苏鲁区域** | 极低密度（扭曲） | 正常道具消失，出现"不可名状"的扭曲物 |
| **尸潮进攻路径** | 极低密度（被破坏） | 尸潮破坏区域，道具消失或损坏 |

**道具放置原则**：
- 搜刮区域：每10-15平方米至少一个可搜刮容器
- 通道：保持视野通透，仅余留衰败痕迹
- 玩家建造：玩家通过建造决定密度

### Environmental Storytelling Guidelines

**视觉叙事元素**（无文字的环境故事）：

| 叙事类型 | 视觉元素 | 传达信息 |
|----------|----------|----------|
| **末世崩溃时间** | 突然遗弃的痕迹（桌上未吃完的食物、半开的门、闪烁的警报灯） | "三个月内崩溃"——突然而非缓慢 |
| **阵营入侵痕迹** | 各阵营的独特破坏（虫族蜂巢、克苏鲁触手、机械锈蚀） | "谁入侵了这里"——阵营历史 |
| **玩家生存痕迹** | 自己建造的防御、修复的战车、收集的资源 | "我如何生存"——玩家叙事 |
| **天气历史** | 天气对环境的影响（暴风雨的侵蚀、沙尘暴的覆盖） | "天气如何改变世界"——天气叙事 |
| **深层恐怖** | 克苏鲁渗透的渐进（正常→扭曲→异界） | "深渊如何渗透"——恐怖渐进 |

**叙事密度规则**：
- 主要区域（搜刮/防守）：高叙事密度——玩家停留时间长，需要故事细节
- 通道区域：低叙事密度——快速通过，无需详细叙事
- 深层区域：渐进叙事密度——从正常到恐怖的叙事过渡

## Section 7: UI/HUD Visual Direction

### HUD Style Positioning

**半沉浸式（Semi-Diegetic）**：
- **定义**：HUD元素与游戏世界风格一致，但非完全场景内元素
- **风格融合**：赛博朋克魔导风格——霓虹边框+符文背景+魔力发光
- **沉浸感元素**：
  - HUD边框采用与战车相同的霓虹符文风格
  - 数值条用"魔力条"而非传统进度条——霓虹发光边缘
  - 警告状态用"符文闪烁"而非传统红框
- **功能性元素**：
  - 状态数值保持清晰的屏幕空间定位——不影响探索视野
  - 撤退警告必须抢夺视觉焦点——无论当前关注点在哪
  - 天气状态图标与元素势力晶石风格一致

### Typography Direction

**字体个性**：
- **主字体**：赛博魔导科技感——锐利的几何字体，符文边缘效果
- **辅助字体**：废土手写感——粗犷的笔触字体，用于手写标签/日志
- **警告字体**：高对比锐利字体——用于紧急警告，符文闪烁效果

**字重层级**：

| 层级 | 字重 | 用途 | 视觉效果 |
|------|------|------|----------|
| **标题** | Extra Bold | 区域名称、重要提示 | 霓虹发光边缘+符文背景 |
| **数值** | Bold | 魔能、耐久、资源计数 | 霓虹发光边缘（数值条） |
| **标签** | Regular | 资源名称、状态标签 | 秘银质感背景 |
| **说明** | Light | 描述文本、提示信息 | 低对比度，辅助信息 |
| **警告** | Bold+闪烁 | 撤退警告、极端危险 | 火焰橙闪烁+符文边框 |

**字号层级**：

| 元素 | 字号比例 | 视觉效果 |
|------|----------|----------|
| **区域名称** | 最大 | 进入区域时短暂显示 |
| **魔能/耐久条数值** | 大 | 持续显示，核心状态 |
| **资源计数** | 中 | 持续显示，次要状态 |
| **天气状态** | 中 | 天气切换时显示 |
| **撤退警告** | 大+动画 | 抢夺视觉焦点 |
| **尸潮倒计时** | 大+震动 | 渐进紧张感 |
| **说明文本** | 小 | 辅助信息 |

### Iconography Style

**图标类型**：赛博魔导扁平+发光——扁平形状+霓虹发光边缘

| 图标类型 | 形状风格 | 发光效果 | 颜色 |
|----------|----------|----------|----------|
| **魔能图标** | 晶石形状 | 霓虹蓝发光边缘 | #00D4FF |
| **耐久图标** | 方块护甲 | 秘银银质感 | #B8C4CE |
| **资源图标** | 各资源独特形状 | 霓虹蓝+金色光泽 | 资源类型色 |
| **警告图标** | 符文边框 | 火焰橙闪烁 | #FF6B35 |
| **天气图标** | 天气符号+晶石 | 天气色附着 | 天气类型色 |
| **阵营图标** | 阵营独特形状 | 阵营色发光 | 阵营主色 |

### UI Animation Feel

| UI元素 | 动画类型 | 动画时长 | 动画质感 |
|----------|----------|----------|----------|
| **魔能条变化** | 霓虹发光渐变 | 0.3s | 平滑渐变，霓虹闪烁反馈 |
| **耐久条变化** | 秘银质感变化 | 0.3s | 平滑渐变，金属震动反馈（受损） |
| **撤退警告** | 符文边框闪烁+放大 | 0.5s | 紧迫感动画，抢夺焦点 |
| **尸潮倒计时** | 数字震动+背景渐暗 | 渐进 | 渐进紧张，震动强度增加 |
| **天气切换** | 图标切换+滤镜渐变 | 0.3s | 平滑过渡，天空渐变 |
| **资源获得** | 图标弹出+数字跳动 | 0.2s | 快速反馈，喜悦感 |
| **克苏鲁警告** | 扭曲效果+颤抖 | 0.5s | 恐怖感动画，与世界一致 |

### UX Alignment Check

| 检查项 | 视觉方向 | UX需求 | 解决方案 |
|----------|----------|----------|----------|
| **撤退警告可读性** | 符文边框闪烁 | 必须在所有情况下可读 | 确保闪烁不影响文字可读，边框与文字分离 |
| **天气状态清晰** | 晶石图标+滤镜渐变 | 快速识别当前天气 | 保持图标形状独特，颜色辅助 |
| **阵营识别** | 阵营图标+颜色 | 色盲玩家也能识别 | 图标形状独特，颜色+形状组合 |
| **战斗时HUD清晰度** | 霓虹发光边缘 | 战斗时不遮挡视线 | HUD定位于屏幕角落，战斗时仅显示核心状态 |
| **克苏鲁警告恐怖感** | 扭曲效果+颤抖 | 不能影响操作准确性 | 扭曲效果仅应用于警告边框，不扭曲操作按钮 |

**结论**：视觉方向支持UX需求——赛博魔导风格增强沉浸感，警告状态抢夺焦点符合UX目标。

## Section 8: Asset Standards

### File Format Preferences

| 资产类型 | 源格式 | 导入后格式 | 原因 |
|----------|----------|------------|----------|
| **纹理（背景/UI）** | PNG（透明） | Godot Texture2D | PNG无损，透明支持，Godot自动优化 |
| **纹理（实体）** | PNG | Godot Texture2D | 同上 |
| **精灵图集** | PNG | Godot SpriteFrames | 动画精灵序列 |
| **音频（音效）** | WAV/OGG | Godot AudioStreamWAV/OGG | WAV无损用于音效，OGG压缩用于音乐 |
| **音频（音乐）** | OGG | Godot AudioStreamOGG | 流式播放，压缩节省内存 |
| **场景文件** | .tscn | Godot Scene | 场景定义 |
| **资源文件** | .tres | Godot Resource | 资源定义（材质、精灵帧） |
| **GDScript文件** | .gd | Godot Script | 脚本文件 |
| **Shader文件** | .gdshader | Godot Shader | 着色器文件 |

### Naming Convention Direction

**基于 GDScript 命名约定**：

| 资产类型 | 命名格式 | 示例 |
|----------|----------|------|
| **场景文件** | PascalCase 匹配根节点 | `BattleWagon.tscn`, `BunkerEntrance.tscn` |
| **脚本文件** | snake_case 匹配类 | `battle_wagon.gd`, `bunker_entrance.gd` |
| **纹理文件** | snake_case + 类型描述 | `battle_wagon_base.png`, `zombie_texture_01.png` |
| **精灵图集** | snake_case + 动画名 | `battle_wagon_move.png`, `zombie_attack.png` |
| **音频文件** | snake_case + 事件描述 | `magic_blaster_fire.wav`, `zombie_idle.ogg` |
| **Shader文件** | snake_case + 效果描述 | `neon_glow.gdshader`, `weather_rain.gdshader` |

**阵营前缀规则**：
- **玩家资产**：无前缀（默认归属）
- **墓园资产**：`graveyard_` 前缀（如 `graveyard_zombie.png`）
- **地狱资产**：`hell_` 前缀（如 `hell_demon.png`）
- **塔楼资产**：`tower_` 前缀（如 `tower_robot.png`）
- **元素资产**：`element_` 前缀（如 `element_crystal.png`）
- **天气资产**：`weather_` 前缀（如 `weather_rain_overlay.png`）

### Texture Resolution Tiers

**基于性能预算（512MB内存上限，<100 Draw Calls）**：

| 资产类型 | 理想分辨率 | 受限分辨率 | 层级 |
|----------|------------|------------|------|
| **战车主体** | 512x512 | 256x256 | 主角资产，最高优先 |
| **战车改装附件** | 256x256 | 128x128 | 次级资产 |
| **丧尸/虫族** | 256x256 | 128x128 | 中级资产 |
| **克苏鲁生物** | 512x512 | 256x256 | BOSS级资产 |
| **机械单位** | 128x128 | 64x64 | 次要威胁，低调资产 |
| **元素晶石** | 128x128 | 64x64 | 次级资产 |
| **环境背景** | 2048x2048 | 1024x1024 | 背景，可流式加载 |
| **环境细节** | 256x256 | 128x128 | 细节纹理 |
| **UI元素** | 128x128 | 64x64 | UI资产 |
| **天气滤镜** | 512x512 | 256x256 | 全屏效果 |

### LOD Level Expectations

**数字绘画风格LOD**——笔触简化而非分辨率降低：

| LOD层级 | 视觉距离 | 简化方式 | 保留元素 |
|----------|----------|----------|----------|
| **LOD0（全细节）** | 近景（战斗） | 无简化 | 全笔触细节、霓虹发光、蠕动纹理 |
| **LOD1（主要细节）** | 中景（探索） | 笔触简化，颜色增强 | 主要形状、阵营颜色、霓虹轮廓 |
| **LOD2（基础细节）** | 远景（撤退/尸潮） | 极简笔触，形状+颜色 | 基础轮廓、阵营颜色块、霓虹闪光 |
| **LOD3（缩略图）** | 地图视野 | 纯色块+发光 | 色块形状、阵营颜色、发光标识 |

**LOD实现**：使用 VisibilityNotifier 或距离检测切换 Sprite，阵营颜色在所有LOD保持。

### Export Settings Philosophy

**Godot 4.6 导入设置**：

| 资产类型 | 导入设置 | 原因 |
|----------|----------|------|
| **纹理（精灵）** | Filter: Linear（数字绘画） | 平滑笔触，非像素风格 |
| **纹理（UI）** | Filter: Linear | UI平滑边缘 |
| **纹理（背景）** | Filter: Linear + Mipmap: Enabled | 背景距离缩放 |
| **音频（音效）** | Loop: Off, Compress: False | 即时播放 |
| **音频（音乐）** | Loop: On, Stream: True | 流式播放节省内存 |
| **Shader** | Compile: On Load | 着色器预编译 |

### Technical Constraints Alignment

| 约束 | 标准 | 解决方案 |
|------|------|----------|
| **引擎** | Godot 4.6 | 所有资产兼容Godot导入 |
| **目标帧率** | 60fps | Shader简化，限制粒子复杂度 |
| **Draw Calls** | <100 | 精灵图集合并同类资产 |
| **内存上限** | 512MB | 背景流式加载，纹理分辨率分层 |
